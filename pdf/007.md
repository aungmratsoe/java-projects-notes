Yes. Since you're using **Java Swing + Maven + JFreeChart**, there are several ways to print a chart to PDF.

The most useful approach for your project is:

# 4. The important part — export JFreeChart to PDF

JFreeChart can render itself onto a Java `Graphics2D`.

PDFBox can provide a PDF graphics context.

A convenient solution is to use a PDFBox-compatible graphics implementation.

For a production project, however, I recommend another approach:

```text
JFreeChart
    ↓
PNG
    ↓
PDFBox
    ↓
PDF
```

This is very easy to understand and works nicely with Swing.

# 6. Put PNG into a PDF

With PDFBox:

```java
PDDocument document = new PDDocument();

PDPage page = new PDPage(PDRectangle.A4);
document.addPage(page);
```

Load the image:

```java
PDImageXObject image =
        PDImageXObject.createFromFile(
                "student-chart.png",
                document
        );
```

Draw it:

```java
try (PDPageContentStream contentStream =
             new PDPageContentStream(document, page)) {

    contentStream.drawImage(
            image,
            50,
            400,
            500,
            300
    );
}
```

Save:

```java
document.save("student-chart.pdf");
document.close();
```

Now you have:

```text
student-chart.pdf
```

# 7. Complete example

Create a utility class:

```java
public class ChartPdfExporter {

    public static void export(
            JFreeChart chart,
            String outputPath
    ) throws IOException {

        File imageFile = File.createTempFile(
                "jfreechart-",
                ".png"
        );

        try {

            // 1. JFreeChart -> PNG
            ChartUtils.saveChartAsPNG(
                    imageFile,
                    chart,
                    1200,
                    700
            );

            // 2. Create PDF
            try (PDDocument document = new PDDocument()) {

                PDPage page = new PDPage(PDRectangle.A4);
                document.addPage(page);

                // 3. Load PNG
                PDImageXObject image =
                        PDImageXObject.createFromFile(
                                imageFile.getAbsolutePath(),
                                document
                        );

                // 4. Draw image
                try (PDPageContentStream contentStream =
                             new PDPageContentStream(
                                     document,
                                     page
                             )) {

                    contentStream.drawImage(
                            image,
                            40,
                            400,
                            515,
                            300
                    );
                }

                // 5. Save PDF
                document.save(outputPath);
            }

        } finally {

            imageFile.delete();
        }
    }
}
```

Then from your Swing button:

```java
private void btnExportPdfActionPerformed(
        java.awt.event.ActionEvent evt) {

    try {

        ChartPdfExporter.export(
                chart,
                "student-report.pdf"
        );

        JOptionPane.showMessageDialog(
                this,
                "PDF exported successfully!"
        );

    } catch (IOException ex) {

        JOptionPane.showMessageDialog(
                this,
                "PDF export failed: " + ex.getMessage(),
                "Error",
                JOptionPane.ERROR_MESSAGE
        );
    }
}
```

# 10. Direct printing with PrinterJob

If your actual requirement is:

> "I don't want to save PDF. I want to click Print and select my printer."

Then use `PrinterJob`.

JFreeChart provides a `ChartPanel`, but for professional printing I'd print the `JFreeChart` itself.

Conceptually:

```java
PrinterJob job = PrinterJob.getPrinterJob();

job.setPrintable((graphics, pageFormat, pageIndex) -> {

    if (pageIndex > 0) {
        return Printable.NO_SUCH_PAGE;
    }

    Graphics2D g2 = (Graphics2D) graphics;

    chart.draw(
            g2,
            new Rectangle2D.Double(
                    pageFormat.getImageableX(),
                    pageFormat.getImageableY(),
                    pageFormat.getImageableWidth(),
                    pageFormat.getImageableHeight()
            )
    );

    return Printable.PAGE_EXISTS;
});
```

Then:

```java
if (job.printDialog()) {
    job.print();
}
```

This gives you the normal Java printer dialog.
