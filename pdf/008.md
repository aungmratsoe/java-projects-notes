# 4. PDFBox ရဲ့ Graphics2D bridge

Apache PDFBox ecosystem ထဲမှာ `PDFGraphics2D` ကိုသုံးတဲ့ approach ရှိတယ်။

Concept က—

```text
                    JFreeChart
                        |
                        | draw()
                        ↓
                  PDFGraphics2D
                        |
                        ↓
                     PDFBox
                        |
                        ↓
                    PDF File
```

`PDFGraphics2D` က `Graphics2D` ကို implement လုပ်ထားတဲ့အတွက် JFreeChart က သူ့ကို normal `Graphics2D` လို့မြင်တယ်။

# 5. Maven dependency

JFreeChart:

```xml
<dependency>
    <groupId>org.jfree</groupId>
    <artifactId>jfreechart</artifactId>
    <version>1.5.6</version>
</dependency>
```

PDFBox:

```xml
<dependency>
    <groupId>org.apache.pdfbox</groupId>
    <artifactId>pdfbox</artifactId>
    <version>3.0.6</version>
</dependency>
```

ဒါပေမယ့် ဒီနေရာမှာ **သတိထားရမယ့်အချက်တစ်ခုရှိတယ်**။

`PDFGraphics2D` ကို PDFBox 3.x core API ထဲက `PDPageContentStream` လိုပဲ သုံးရမယ်လို့ မယူဆသင့်ဘူး။ PDFBox version နဲ့ graphics bridge library ရဲ့ API ကွာနိုင်ပါတယ်။

Professional project မှာ ဒီ bridge ကို သီးခြား dependency အဖြစ် သုံးတာပိုရှင်းပါတယ်။

# 17. PNG နဲ့ Vector PDF ကွာခြားချက်

|Feature|PNG → PDF|Vector PDF|
|---|---|---|
|Chart|Image|Drawing|
|Zoom|Pixel ဖြစ်နိုင်|Sharp|
|Text|Image pixels|PDF text/vector|
|Line|Pixels|Vector|
|File quality|Resolution dependent|Resolution independent|
