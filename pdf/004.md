# 4. Font Load ကို Method ခွဲမယ်

```java
private PDType0Font loadMyanmarFont(
        PDDocument document)
        throws IOException {

    InputStream fontStream =
            getClass()
                    .getResourceAsStream(
                            "/fonts/NotoSansMyanmar-Regular.ttf"
                    );

    if (fontStream == null) {
        throw new IOException(
                "Myanmar font not found."
        );
    }

    return PDType0Font.load(
            document,
            fontStream
    );
}
```

ဒါဆို `generateA4()` ထဲမှာ—

```java
PDType0Font myanmarFont =
        loadMyanmarFont(document);
```

# 10. Photo Method ကို သီးခြားလုပ်မယ်

Professional ဖြစ်လာပြီဆိုတော့ ဒီလို—

```java
private PDImageXObject createCroppedPhoto(
        PDDocument document,
        String imagePath)
        throws IOException {

    BufferedImage original =
            ImageIO.read(
                    new File(imagePath)
            );

    if (original == null) {
        throw new IOException(
                "Invalid image: " + imagePath
        );
    }

    int width = original.getWidth();
    int height = original.getHeight();

    int size = Math.min(width, height);

    int cropX = (width - size) / 2;
    int cropY = (height - size) / 2;

    BufferedImage cropped =
            original.getSubimage(
                    cropX,
                    cropY,
                    size,
                    size
            );

    return LosslessFactory.createFromImage(
            document,
            cropped
    );
}
```

ဒါဆို `drawCard()` ထဲမှာ—

```java
PDImageXObject photo =
        createCroppedPhoto(
                document,
                student.getPhotoPath()
        );
```

ပြီးပြီ။

# 12. Resource Image ကို Load လုပ်မယ်

```java
private PDImageXObject loadImageFromResource(
        PDDocument document,
        String resourcePath)
        throws IOException {

    try (InputStream inputStream =
                 getClass()
                     .getResourceAsStream(
                             resourcePath
                     )) {

        if (inputStream == null) {
            throw new IOException(
                    "Resource not found: "
                            + resourcePath
            );
        }

        return JPEGFactory.createFromStream(
                document,
                inputStream
        );
    }
}
```

ဒါက JPEG အတွက်သင့်တော်တယ်။

PNG logo ဆိုရင် resource ကို byte data အဖြစ် load ပြီး သင့်တော်တဲ့ PDFBox image factory ကိုသုံးတာကောင်းတယ်။ Image format အလိုက် approach ပြောင်းနိုင်တယ်။
