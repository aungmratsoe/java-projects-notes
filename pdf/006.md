# 3. `getFieldTree()`

Nested field အားလုံးကို ကြည့်ချင်ရင်—

```java
for (PDField field :
        form.getFieldTree()) {

    System.out.println(
        field.getFullyQualifiedName()
    );
}
```

ဒီဟာက အရမ်းအသုံးဝင်တယ်။

ဥပမာ PDF template ထဲမှာ ဘာ fields တွေရှိမှန်း မသိဘူးဆိုပါစို့။

ဒီ code ကို run လိုက်—

```java
private void printFields(
        PDAcroForm form) {

    for (PDField field :
            form.getFieldTree()) {

        System.out.println(
                "Name : "
                + field.getFullyQualifiedName()
        );

        System.out.println(
                "Type : "
                + field.getClass()
                        .getSimpleName()
        );

        System.out.println("----------------");
    }
}
```

```text
----------------

Type : PDRadioButton

Type : PDCheckBox
----------------
Name : major
Type : PDComboBox
----------------
```

# 12. Field Debugger တည်ဆောက်မယ်

ဒီဟာ မင်း Project မှာ တကယ်အသုံးဝင်မယ်။

`PDFFormInspector.java`

```java
import java.io.File;
import java.io.IOException;

import org.apache.pdfbox.Loader;
import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.pdmodel.interactive.form.PDAcroForm;
import org.apache.pdfbox.pdmodel.interactive.form.PDField;

public class PDFFormInspector {

    public void inspect(
            File pdfFile)
            throws IOException {

        try (PDDocument document =
                     Loader.loadPDF(pdfFile)) {

            PDAcroForm form =
                    document
                            .getDocumentCatalog()
                            .getAcroForm();

            if (form == null) {

                System.out.println(
                        "No AcroForm found."
                );

                return;
            }

            for (PDField field :
                    form.getFieldTree()) {

                System.out.println(
                        "Field Name  : "
                        + field
                            .getFullyQualifiedName()
                );

                System.out.println(
                        "Field Type  : "
                        + field
                            .getClass()
                            .getSimpleName()
                );

                System.out.println(
                        "Field Value : "
                        + field.getValueAsString()
                );

                System.out.println(
                        "----------------------------"
                );
            }
        }
    }
}
```

```java
private void setTextField(
        PDAcroForm form,
        String fieldName,
        String value)
        throws IOException {

    PDField field =
            form.getField(fieldName);

    if (field == null) {

        throw new IOException(
                "Field not found: "
                + fieldName
        );
    }

    if (!(field instanceof PDTextField)) {

        throw new IOException(
                "Field is not a text field: "
                + fieldName
        );
    }

    field.setValue(
            value == null ? "" : value
    );
}
```

ဒါဆို—

```java

    form,
    "studentName",
    student.getName()
);
```

# 21. Practical `generate()`

အခု ဒီနေ့သင်တာတွေ ပေါင်းလိုက်မယ်။

```java
public void generate(
        Student student,
        File templateFile,
        File outputFile)
        throws IOException {

    try (PDDocument document =
                 Loader.loadPDF(templateFile)) {

        PDAcroForm form =
                document
                        .getDocumentCatalog()
                        .getAcroForm();

        if (form == null) {

            throw new IOException(
                    "AcroForm not found."
            );
        }

        setTextField(
                form,
                "studentId",
                student.getStudentId()
        );

        setTextField(
                form,
                "studentName",
                student.getName()
        );

        setTextField(
                form,
                "phone",
                student.getPhone()
        );

        setTextField(
                form,
                "major",
                student.getSpecialization()
        );

        PDField activeField =
                form.getField("active");

        if (activeField
                instanceof PDCheckBox checkBox) {

            if (student.isActive()) {
                checkBox.check();
            } else {
                checkBox.unCheck();
            }
        }

        form.refreshAppearances();

        document.save(outputFile);
    }
}
```

ဒီ code ကတော့ **PDF Template → Student Object → Final PDF** အဖြစ် တော်တော်နီးလာပြီ။

# 22. အခု မင်းသိထားသင့်တဲ့ Mental Model

AcroForm ကို ဒီလိုမှတ်။

```text
PDDocument
    │
    ▼
PDAcroForm
    │
    ▼
PDField
    │
    ├── PDTextField
    ├── PDCheckBox
    ├── PDComboBox
    ├── PDListBox
    ├── PDRadioButton
    └── ...
```

ပြီးတော့—

```text
getFields()
    ↓
Root fields

getFieldTree()
    ↓
All fields

getField("name")
    ↓
```

## ဒီနေ့ရဲ့ Practice

မင်းရဲ့ `student-id-card-template.pdf` ကိုယူပြီး ဒီ field တွေရှိတယ်လို့ ယူပါ—

```text
studentId       → TextField
studentName     → TextField
major           → ComboBox
active          → CheckBox
gender          → RadioButton
```

Java Swing မှာ `Inspect Template` button နဲ့ field အားလုံးကို console ထုတ်ပါ။

ပြီးရင် `Generate ID Card` button ကနေ—

```text
studentId
studentName
major
active
gender
```

အားလုံး fill လုပ်ပြီး final PDF ထုတ်ကြည့်ပါ။
