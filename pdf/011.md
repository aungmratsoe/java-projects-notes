# 4. `PdfTable.java`

Package:

```text
com.ams.report.pdf
```

Class:

```java
package com.ams.report.pdf;

import java.io.IOException;
import java.util.List;

import org.apache.pdfbox.pdmodel.PDPageContentStream;
import org.apache.pdfbox.pdmodel.font.PDFont;

public class PdfTable {

    private final float x;
    private final float y;

    private final float rowHeight;

    private final float[] columnWidths;

    private final String[] headers;

    private final List<String[]> rows;

    public PdfTable(
            float x,
            float y,
            float rowHeight,
            float[] columnWidths,
            String[] headers,
            List<String[]> rows) {

        this.x = x;
        this.y = y;
        this.rowHeight = rowHeight;
        this.columnWidths = columnWidths;
        this.headers = headers;
        this.rows = rows;
    }

    public void draw(
            PDPageContentStream content,
            PDFont font,
            float fontSize
    ) throws IOException {

        float currentY = y;

        drawHeader(
                content,
                font,
                fontSize,
                currentY
        );

        currentY -= rowHeight;

        for (String[] row : rows) {

            drawRow(
                    content,
                    font,
                    fontSize,
                    row,
                    currentY
            );

            currentY -= rowHeight;
        }
    }

    private void drawHeader(
            PDPageContentStream content,
            PDFont font,
            float fontSize,
            float y
    ) throws IOException {

        drawCells(
                content,
                font,
                fontSize,
                headers,
                y
        );
    }

    private void drawRow(
            PDPageContentStream content,
            PDFont font,
            float fontSize,
            String[] row,
            float y
    ) throws IOException {

        drawCells(
                content,
                font,
                fontSize,
                row,
                y
        );
    }

    private void drawCells(
            PDPageContentStream content,
            PDFont font,
            float fontSize,
            String[] values,
            float y
    ) throws IOException {

        float currentX = x;

        for (int i = 0; i < columnWidths.length; i++) {

            float width = columnWidths[i];

            // Cell border
            content.addRect(
                    currentX,
                    y - rowHeight,
                    width,
                    rowHeight
            );

            content.stroke();

            // Cell text
            content.beginText();

            content.setFont(
                    font,
                    fontSize
            );

            content.newLineAtOffset(
                    currentX + 5,
                    y - 15
            );

            content.showText(
                    values[i]
            );

            content.endText();

            currentX += width;
        }
    }
}
```

# 15. Pagination ကို နောက် Lesson မှာလုပ်မယ်

```text
currentY = 500

for each row:

    if currentY < bottomMargin:

        createNewPage()

        currentY = topMargin

    drawRow()

    currentY -= rowHeight
```

## နောက် Lesson — အရေးကြီးတယ်

နောက်တစ်ဆင့်မှာ **Pagination + automatic table row handling** ကိုလုပ်မယ်။

ဥပမာ database မှာ Student **1,000 ယောက်**ရှိရင်—

```text
Page 1
 ├── Header
 ├── Chart
 └── Student 1 → 20

Page 2
 ├── Table Header
 └── Student 21 → 50

Page 3
 ├── Table Header
 └── Student 51 → 80

...

Page 20
 ├── Table Header
 └── Student 951 → 1000
```

ဖြစ်အောင် **`PdfPageManager` + `PdfTable` pagination** ကိုရေးမယ်။ ဒီအဆင့်ရောက်ရင် မင်းရဲ့ report system က simple chart export မဟုတ်တော့ဘဲ တကယ်အသုံးချလို့ရတဲ့ **report engine architecture** ဖြစ်လာမယ်။
