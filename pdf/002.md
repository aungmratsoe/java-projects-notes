# Lesson 2 — Professional Student ID Card PDF Generator

အခုတော့ ရိုးရိုး PDF မဟုတ်တော့ဘဲ **Student Management System အတွက် တကယ်အသုံးဝင်မယ့် ID Card Generator** တည်ဆောက်မယ်။

ဒီ Lesson ရဲ့ architecture ကို ဒီလိုထားမယ်—

```text
StudentForm.java
      │
      │ selected Student
      ▼
Student.java
      │
      ▼
StudentIDCardPDFService.java
      │
      ├── Student Photo
      ├── QR Code
      ├── Student Information
      └── Card Design
            │
            ▼
       Student_ID.pdf
```

PDFBox 3.x မှာ PDF creation, page content, image rendering စတာတွေကို `PDDocument`, `PDPage`, `PDPageContentStream`, `PDImageXObject` တို့နဲ့လုပ်နိုင်တယ်။ `PDPageContentStream` က page ပေါ် content ရေးဖို့ အဓိက class ဖြစ်တယ်။ ([Apache PDFBox](https://pdfbox.apache.org/docs/2.0.10/javadocs/org/apache/pdfbox/pdmodel/PDPageContentStream.html?utm_source=chatgpt.com "PDPageContentStream (PDFBox reactor 2.0.10 API)"))

```text

Height ≈ 2.125 inch
```

ဆိုရင်

```text

Height ≈ 153 points
```

package service;

import java.io.File;
import java.io.IOException;

import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.pdmodel.PDPage;
import org.apache.pdfbox.pdmodel.PDPageContentStream;

public class StudentIDCardPDFService {

    private static final float CARD_WIDTH = 243;
    private static final float CARD_HEIGHT = 153;

    public void generate(Student student, File outputFile)
            throws IOException {

        try (PDDocument document = new PDDocument()) {

            PDPage page = new PDPage(
                    new org.apache.pdfbox.pdmodel.common.PDRectangle(
                            CARD_WIDTH,
                            CARD_HEIGHT
                    )
            );

            document.addPage(page);

            try (PDPageContentStream content =
                         new PDPageContentStream(document, page)) {

                drawCard(document, content, student);
            }

            document.save(outputFile);
        }
    }

            PDDocument document,
            PDPageContentStream content,
            Student student)
            throws IOException {

    }
}

# 11. Full `drawCard()` Method

အခု အားလုံးပေါင်းလိုက်မယ်။

```java
private void drawCard(
        PDDocument document,
        PDPageContentStream content,
        Student student)
        throws IOException {

    // Background
    content.setNonStrokingColor(245, 247, 250);

    content.addRect(
            0,
            0,
            CARD_WIDTH,
            CARD_HEIGHT
    );

    content.fill();


    // Border
    content.setStrokingColor(40, 40, 40);

    content.setLineWidth(1);

    content.addRect(
            1,
            1,
            CARD_WIDTH - 2,
            CARD_HEIGHT - 2
    );

    content.stroke();


    // University name
    drawText(
            content,
            "ABC UNIVERSITY",
            15,
            125,
            14
    );


    // Photo
    File photoFile = new File(
            student.getPhotoPath()
    );

    if (photoFile.exists()) {

        PDImageXObject photo =
                PDImageXObject.createFromFile(
                        photoFile.getAbsolutePath(),
                        document
                );

        content.drawImage(
                photo,
                15,
                45,
                65,
                65
        );
    }


    // Student information
    drawText(
            content,
            "Student ID : "
                    + student.getStudentId(),
            90,
            90,
            9
    );

    drawText(
            content,
            "Name : "
                    + student.getName(),
            90,
            75,
            9
    );

    drawText(
            content,
            "Major : "
                    + student.getSpecialization(),
            90,
            60,
            9
    );

    drawText(
            content,
            "Phone : "
                    + student.getPhone(),
            90,
            45,
            9
    );


    // QR
    File qrFile = new File(
            student.getQrPath()
    );

    if (qrFile.exists()) {

        PDImageXObject qr =
                PDImageXObject.createFromFile(
                        qrFile.getAbsolutePath(),
                        document
                );

        content.drawImage(
                qr,
                175,
                5,
                50,
                50
        );
    }
}
```

NetBeans မှာ Button ကို double-click လုပ်။

```java
private void btnGeneratePDFActionPerformed(
        java.awt.event.ActionEvent evt) {

    try {

        Student student = new Student(
                txtStudentId.getText(),
                txtName.getText(),
                txtSpecialization.getText(),
                txtPhone.getText(),
                photoPath,
                qrPath
        );

        JFileChooser chooser =
                new JFileChooser();

        chooser.setSelectedFile(
                new File(
                        student.getStudentId()
                                + "_ID_Card.pdf"
                )
        );

        int result =
                chooser.showSaveDialog(this);

        if (result ==
                JFileChooser.APPROVE_OPTION) {

            File outputFile =
                    chooser.getSelectedFile();

            StudentIDCardPDFService service =
                    new StudentIDCardPDFService();

            service.generate(
                    student,
                    outputFile
            );

            JOptionPane.showMessageDialog(
                    this,
                    "ID Card PDF generated successfully."
            );
        }

    } catch (Exception e) {

        JOptionPane.showMessageDialog(
                this,
                "Failed to generate PDF:\n"
                        + e.getMessage()
        );
    }
}
```
