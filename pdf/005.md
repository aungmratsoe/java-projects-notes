# 9. အခု `Template Service` ဆောက်မယ်

Package—

```text
service/
    StudentIDCardTemplateService.java
```

Code—

```java
package service;

import java.io.File;
import java.io.IOException;

import org.apache.pdfbox.Loader;
import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.pdmodel.interactive.form.PDAcroForm;

public class StudentIDCardTemplateService {

    public void generate(
            Student student,
            File templateFile,
            File outputFile)
            throws IOException {

        try (PDDocument document =
                     Loader.loadPDF(templateFile)) {

            PDAcroForm form =
                    document
                            .getDocumentCatalog()
                            .getAcroForm();

            if (form == null) {
                throw new IOException(
                        "Template has no AcroForm."
                );
            }

            form.getField("studentId")
                    .setValue(
                            student.getStudentId()
                    );

            form.getField("studentName")
                    .setValue(
                            student.getName()
                    );

            form.getField("major")
                    .setValue(
                            student.getSpecialization()
                    );

            form.getField("phone")
                    .setValue(
                            student.getPhone()
                    );

            document.save(outputFile);
        }
    }
}
```

# 11. NetBeans Swing Button

Drag & Drop UI မှာ—

```text
[ Generate ID Card ]
```

Button တစ်ခုရှိတယ်ဆိုပါစို့။

```java
private void btnGenerateActionPerformed(
        java.awt.event.ActionEvent evt) {

    try {

        int row =
                tblStudents.getSelectedRow();

        if (row == -1) {

            JOptionPane.showMessageDialog(
                    this,
                    "Please select a student."
            );

            return;
        }

        String studentId =
                tblStudents.getValueAt(
                        row,
                        0
                ).toString();

        Student student =
                studentDAO.findById(
                        studentId
                );

        if (student == null) {

            JOptionPane.showMessageDialog(
                    this,
                    "Student not found."
            );

            return;
        }

        File template =
                new File(
                    "student-id-card-template.pdf"
                );

        JFileChooser chooser =
                new JFileChooser();

        chooser.setSelectedFile(
                new File(
                    student.getStudentId()
                    + "_ID_Card.pdf"
                )
        );

        if (chooser.showSaveDialog(this)
                == JFileChooser.APPROVE_OPTION) {

            File output =
                    chooser.getSelectedFile();

            StudentIDCardTemplateService service =
                    new StudentIDCardTemplateService();

            service.generate(
                    student,
                    template,
                    output
            );

            JOptionPane.showMessageDialog(
                    this,
                    "ID Card generated successfully."
            );
        }

    } catch (Exception e) {

        e.printStackTrace();

        JOptionPane.showMessageDialog(
                this,
                "Failed:\n"
                + e.getMessage()
        );
    }
}
```

# 13. Missing Field ကို Safe ဖြစ်အောင်လုပ်မယ်

ဒီလို—

```java
form.getField("studentName")
        .setValue(student.getName());
```

ဆိုရင် field မရှိရင် `NullPointerException` ဖြစ်နိုင်တယ်။

Helper method လုပ်မယ်။

```java
private void setField(
        PDAcroForm form,
        String fieldName,
        String value)
        throws IOException {

    PDField field =
            form.getField(fieldName);

    if (field == null) {

        throw new IOException(
                "Missing PDF field: "
                        + fieldName
        );
    }

    field.setValue(
            value == null ? "" : value
    );
}
```

ပြီးတော့—

```java
setField(
    form,
    "studentId",
    student.getStudentId()
);

setField(
    form,
    "studentName",
    student.getName()
);

setField(
    form,
    "major",
    student.getSpecialization()
);
```

ဒါက ပို professional ဖြစ်တယ်။
