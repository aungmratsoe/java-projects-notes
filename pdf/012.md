# 3. အဓိက Algorithm

Pagination ရဲ့ core logic က ဒီလောက်ပဲ—

```text
currentY = top

for each row:

    if currentY < bottom:

        create new page

        currentY = top

    draw row

    currentY -= rowHeight
```

ဒါကို code အဖြစ်ပြောင်းမယ်။

# 4. `PdfPageManager`

Package:

```text
com.ams.report.pdf
```

Class:

```java
public class PdfPageManager {

    private final PDDocument document;

    private PDPage page;

    private PDPageContentStream content;

    private final float pageWidth;
    private final float pageHeight;

    private final float topMargin;
    private final float bottomMargin;

    private float currentY;

    public PdfPageManager(
            PDDocument document,
            float pageWidth,
            float pageHeight,
            float topMargin,
            float bottomMargin
    ) throws IOException {

        this.document = document;

        this.pageWidth = pageWidth;
        this.pageHeight = pageHeight;

        this.topMargin = topMargin;
        this.bottomMargin = bottomMargin;

        createNewPage();
    }

    private void createNewPage()
            throws IOException {

        page = new PDPage(
                new PDRectangle(
                        pageWidth,
                        pageHeight
                )
        );

        document.addPage(page);

        content =
                new PDPageContentStream(
                        document,
                        page
                );

        currentY =
                pageHeight - topMargin;
    }
}
```

# 9. Complete `PdfPageManager`

အခု class ကို တစ်စုတည်းကြည့်မယ်။

```java
package com.ams.report.pdf;

import java.io.IOException;

import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.pdmodel.PDPage;
import org.apache.pdfbox.pdmodel.PDPageContentStream;
import org.apache.pdfbox.pdmodel.common.PDRectangle;

public class PdfPageManager {

    private final PDDocument document;

    private PDPage page;

    private PDPageContentStream content;

    private final float pageWidth;
    private final float pageHeight;

    private final float topMargin;
    private final float bottomMargin;

    private float currentY;

    public PdfPageManager(
            PDDocument document,
            float pageWidth,
            float pageHeight,
            float topMargin,
            float bottomMargin
    ) throws IOException {

        this.document = document;

        this.pageWidth = pageWidth;
        this.pageHeight = pageHeight;

        this.topMargin = topMargin;
        this.bottomMargin = bottomMargin;

        createNewPage();
    }

    private void createNewPage()
            throws IOException {

        page = new PDPage(
                new PDRectangle(
                        pageWidth,
                        pageHeight
                )
        );

        document.addPage(page);

        content =
                new PDPageContentStream(
                        document,
                        page
                );

        currentY =
                pageHeight - topMargin;
    }

    public boolean hasSpace(
            float requiredHeight
    ) {

        return currentY - requiredHeight
                >= bottomMargin;
    }

    public void newPage()
            throws IOException {

        content.close();

        createNewPage();
    }

    public float getCurrentY() {
        return currentY;
    }

    public void moveDown(
            float amount
    ) {

        currentY -= amount;
    }

    public PDPage getPage() {
        return page;
    }

    public PDPageContentStream getContent() {
        return content;
    }

    public void close()
            throws IOException {

        content.close();
    }
}
```

# 13. `PdfTable` ရဲ့ core method

```java
public void draw(
        PdfPageManager manager,
        PDFont headerFont,
        PDFont bodyFont,
        float fontSize
) throws IOException {

    drawHeader(
            manager,
            headerFont,
            fontSize
    );

    for (String[] row : rows) {

        if (!manager.hasSpace(rowHeight)) {

            manager.newPage();

            drawHeader(
                    manager,
                    headerFont,
                    fontSize
            );
        }

        drawRow(
                manager,
                bodyFont,
                fontSize,
                row
        );

        manager.moveDown(
                rowHeight
        );
    }
}
```

# 16. `drawCells()` ပြင်မယ်

```java
        PdfPageManager manager,
        PDFont font,
        float fontSize,
        String[] values
) throws IOException {

    PDPageContentStream content =
            manager.getContent();

    float currentX = x;

    float y =
            manager.getCurrentY();

    for (int i = 0;
         i < columnWidths.length;
         i++) {

        float width =
                columnWidths[i];

        content.addRect(
                currentX,
                y - rowHeight,
                width,
                rowHeight
        );

        content.stroke();

        content.beginText();

        content.setFont(
                font,
                fontSize
        );

        content.newLineAtOffset(
                currentX + 5,
                y - 17
        );

        content.showText(
                values[i]
        );

        content.endText();

        currentX += width;
    }
}
```

# 25. အခုအရေးကြီးတဲ့ design lesson

`PdfTable` က page ဘယ်နှစ်မျက်နှာရှိမလဲ **မသိသင့်ဘူး**။

သူက—

> "ငါ row တစ်ခုဆွဲချင်တယ်။ Space ရှိလား?"

လို့ `PdfPageManager` ကိုမေးတယ်။

```java
if (!manager.hasSpace(rowHeight)) {
    manager.newPage(font);
}
```

ဒီလိုလုပ်တာက **Separation of Responsibility** ဖြစ်တယ်။

### `PdfTable`

```text
Table ဘယ်လိုဆွဲမလဲ?
```

### `PdfPageManager`

```text
ဘယ် page မှာဆွဲမလဲ?
Space ရှိသေးလား?
Page အသစ်ဖန်တီးရမလား?
```

### `StudentReportPdf`

```text
ဘယ်အရာတွေကို report ထဲထည့်မလဲ?
```

ဒီသုံးခုကို မရောထားတာ အရမ်းကောင်းတဲ့ architecture ဖြစ်တယ်။
