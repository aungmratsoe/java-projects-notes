## Gson နဲ့ JSON File ကို Config/Settings Storage အဖြစ် Swing App Preferences မှာ အသုံးချနည်း

Swing desktop app တွေမှာ window size/position, last-used theme (FlatLaf theme), database connection info, language setting, recent file list စတာတွေကို app ပိတ်လိုက်ရင် disappear မဖြစ်စေချင်ဘဲ ထပ်ဖွင့်တဲ့အခါ ပြန်ရအောင် **local JSON file** ထဲ save ထားလို့ရပါတယ်။ Java built-in `Preferences` API လည်းရှိပေမယ့် (registry-based, plain text ကြည့်မရ), JSON file ကတော့ human-readable ဖြစ်ပြီး backup/manual-edit လုပ်ရလွယ်ကူတဲ့ အားသာချက်ရှိပါတယ်။

```java
public class AppSettings {
```

### ၂။ SettingsManager (Singleton Utility Class)

```java
package com.ams.qrcode.utils;

import com.ams.qrcode.model.AppSettings;
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import java.io.*;
import java.nio.file.*;

public class SettingsManager {

    private static final Gson gson = new GsonBuilder().setPrettyPrinting().create();

    // OS user home directory ထဲမှာ hidden folder ဖန်တီးထားတယ် - project root ထဲမှာ မထားသင့်ပါ
    private static final String CONFIG_DIR = System.getProperty("user.home") + File.separator + ".qrcode-app";
    private static final String CONFIG_FILE = CONFIG_DIR + File.separator + "settings.json";

    private static AppSettings cachedSettings;

    private SettingsManager() {}

    public static AppSettings load() {
        if (cachedSettings != null) {
            return cachedSettings; // repeated file I/O မလုပ်စေရန် memory ထဲမှာ cache လုပ်ထားတယ်
        }

        File file = new File(CONFIG_FILE);
        if (!file.exists()) {
            cachedSettings = new AppSettings(); // ပထမဆုံးအကြိမ် run ရင် default value တွေနဲ့ object အသစ်ပြန်ပေးမယ်
            return cachedSettings;
        }

        try (Reader reader = new FileReader(file)) {
            cachedSettings = gson.fromJson(reader, AppSettings.class);
            if (cachedSettings == null) {
                cachedSettings = new AppSettings(); // file ရှိပေမယ့် empty/corrupt ဖြစ်နေရင်
            }
        } catch (IOException e) {
            System.err.println("Settings load error: " + e.getMessage());
            cachedSettings = new AppSettings();
        }
        return cachedSettings;
    }

    public static void save(AppSettings settings) {
        cachedSettings = settings;
        try {
            Files.createDirectories(Paths.get(CONFIG_DIR)); // folder မရှိသေးရင် ဖန်တီးပေး
            try (Writer writer = new FileWriter(CONFIG_FILE)) {
                gson.toJson(settings, writer);
            }
        } catch (IOException e) {
            System.err.println("Settings save error: " + e.getMessage());
        }
    }
}
```

### ၃။ App Startup မှာ Settings Load လုပ်ခြင်း

`Main` class (သို့) `MainFrame` constructor ထဲမှာ:

```java
public class MainFrame extends javax.swing.JFrame {

    public MainFrame() {
        initComponents(); // NetBeans auto-generated GUI init

        AppSettings settings = SettingsManager.load();

        // Window size/position ကို saved value အတိုင်း ပြန်သတ်မှတ်
        this.setSize(settings.getWindowWidth(), settings.getWindowHeight());
        this.setLocation(settings.getWindowX(), settings.getWindowY());

        // FlatLaf theme ကို saved value အတိုင်း apply လုပ်
        applyTheme(settings.getTheme());

        // Last username ကို login field ထဲ pre-fill
        if (settings.isRememberLastUser()) {
            txtUsername.setText(settings.getLastUsername());
        }
    }

    private void applyTheme(String themeName) {
        try {
            if (themeName.equals("FlatLaf Dark")) {
                javax.swing.UIManager.setLookAndFeel(new com.formdev.flatlaf.FlatDarkLaf());
            } else {
                javax.swing.UIManager.setLookAndFeel(new com.formdev.flatlaf.FlatLightLaf());
            }
            javax.swing.SwingUtilities.updateComponentTreeUI(this);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

### ၄။ App Close (Window Closing Event) မှာ Settings Save လုပ်ခြင်း

NetBeans Design mode မှာ JFrame ရဲ့ Properties → `defaultCloseOperation` ကို `DO_NOTHING_ON_CLOSE` ပြောင်းပြီး, `windowClosing` event handler ကို manual ဖြည့်ပါ (Source view ထဲ):

```java
// initComponents() အောက်မှာ, constructor ထဲ ထည့်ပါ
this.setDefaultCloseOperation(javax.swing.WindowConstants.DO_NOTHING_ON_CLOSE);
this.addWindowListener(new java.awt.event.WindowAdapter() {
    @Override
    public void windowClosing(java.awt.event.WindowEvent evt) {
        saveCurrentSettings();
        System.exit(0);
    }
});
```

```java
private void saveCurrentSettings() {
    AppSettings settings = SettingsManager.load(); // cached instance ကနေ update လုပ်မယ်

    settings.setWindowWidth(this.getWidth());
    settings.setWindowHeight(this.getHeight());
    settings.setWindowX(this.getX());
    settings.setWindowY(this.getY());
    settings.setLastUsername(txtUsername.getText());

    SettingsManager.save(settings);
}
```

### ၅။ Settings Dialog ထဲက Save Button ဥပမာ (Theme ပြောင်းခြင်း)

```java
private void btnSaveSettingsActionPerformed(java.awt.event.ActionEvent evt) {
    AppSettings settings = SettingsManager.load();

    String selectedTheme = (String) cmbTheme.getSelectedItem(); // JComboBox
    settings.setTheme(selectedTheme);
    settings.setLanguage((String) cmbLanguage.getSelectedItem());
    settings.setRememberLastUser(chkRememberUser.isSelected());

    SettingsManager.save(settings);

}
```

### ၇။ သတိထားရမယ့်အချက်များ

- **User home directory သုံးခြင်း**: Project folder (`.jar` ဖိုင်ရှိရာနေရာ) ထဲမှာ တိုက်ရိုက်မသိမ်းသင့်ပါ — Windows/Linux အမျိုးမျိုးမှာ write permission မရှိနိုင်တာ၊ app ကို install-directory ထဲ run ထားရင် access denied ဖြစ်နိုင်တာကြောင့် `System.getProperty("user.home")` ကို standard ပုံစံသုံးတာ ပိုစိတ်ချရပါတယ်။
- **Sensitive data**: password/API key ကို plain JSON ထဲ တိုက်ရိုက်မသိမ်းသင့်ပါ — plain text ဖတ်လို့ရနေတဲ့ file ဖြစ်လို့, encrypt လုပ်ရန် (သို့) OS-level credential storage သုံးရန် လိုအပ်ပါတယ်။
- **Corrupt file handling**: `load()` method ထဲမှာ try-catch + null-check ထည့်ထားရတဲ့ အကြောင်းရင်းက user က file ကို manual ဖွင့်ပြီး edit လုပ်ရင်း syntax error ဖြစ်နိုင်လို့ပါ — app crash မဖြစ်စေဘဲ default settings နဲ့ ဆက် run နိုင်အောင်ပါ။
- **Cache pattern**: `SettingsManager` ထဲက `cachedSettings` static field က file I/O ကို app တစ်ခေါက်တည်း run ချိန်မှာ တစ်ကြိမ်ပဲ ဖတ်ဖို့ ရည်ရွယ်ထားပါတယ် — `load()` ကို နေရာမှန်သမျှက ခေါ်နိုင်ပေမယ့် disk access ထပ်ထပ်မဖြစ်တော့ပါ။
