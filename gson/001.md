Gson ဆိုတာ Google ကထုတ်တဲ့ Java library တစ်ခုဖြစ်ပြီး Java object တွေကို JSON string အဖြစ် (serialize) ပြောင်းပေးနိုင်သလို၊ JSON string ကနေ Java object အဖြစ် (deserialize) ပြန်လည်ပြောင်းလဲပေးနိုင်ပါတယ်။ Swing project တစ်ခုမှာ config file သိမ်းတာ၊ API ကနေ data ရယူတာ၊ data local file ထဲမှာ save/load လုပ်တာစတဲ့ အခြေအနေတွေမှာ အသုံးများပါတယ်။

## ၁။ Maven Dependency ထည့်ခြင်း

`pom.xml` ဖိုင်ထဲက `<dependencies>` tag အထဲမှာ အောက်ပါ code ကို ထည့်ပါ:

```xml
<dependency>
    <groupId>com.google.code.gson</groupId>
    <artifactId>gson</artifactId>
    <version>2.11.0</version>
</dependency>
```

NetBeans မှာဆိုရင် `pom.xml` ကို edit လုပ်ပြီးသိမ်းလိုက်ရင် Maven က dependency ကို အလိုအလျောက် download လုပ်ပေးပါလိမ့်မယ် (internet connection လိုပါတယ်)။ manual check လုပ်ချင်ရင် project ပေါ်မှာ right-click → **Reload Project** ကိုနှိပ်ပေးပါ။

## ၃။ Java Object → JSON (Serialize)

```java
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;

Gson gson = new GsonBuilder().setPrettyPrinting().create();

Student student = new Student("STU001", "Aung Aung", 20);
String json = gson.toJson(student);

System.out.println(json);
```

Output:

```json
{
  "studentId": "STU001",
  "name": "Aung Aung",
  "age": 20
}
```

`setPrettyPrinting()` က JSON ကို indent လုပ်ပြီး ဖတ်ရလွယ်အောင် ပြုလုပ်ပေးတာပါ။ Production မှာ တကယ်လိုအပ်မှသာ သုံးပါ၊ file size ကြီးလာနိုင်ပါတယ်။

## ၄။ JSON → Java Object (Deserialize)

```java
String jsonString = "{\"studentId\":\"STU002\",\"name\":\"Su Su\",\"age\":21}";

Student student = gson.fromJson(jsonString, Student.class);
System.out.println(student.getName()); // Su Su
```

## ၅။ List ကို JSON နဲ့ ပြောင်းခြင်း (Swing JTable အတွက် အသုံးဝင်တယ်)

```java
import com.google.gson.reflect.TypeToken;
import java.lang.reflect.Type;
import java.util.List;

// List -> JSON
List<Student> students = getStudentList(); // your DAO method
Type listType = new TypeToken<List<Student>>(){}.getType();
String json = gson.toJson(students, listType);

// JSON -> List
List<Student> loadedStudents = gson.fromJson(json, listType);
```

`List<Student>` လို generic type ကို deserialize လုပ်ချင်ရင် `Class.class` သုံးလို့မရဘဲ `TypeToken` ကို အတိအကျသုံးရပါတယ် — Java ရဲ့ type erasure ကြောင့်ပါ။

## ၆။ Swing App ထဲမှာ File ကို Save/Load လုပ်ခြင်း (Practical Example)

```java
import java.io.FileWriter;
import java.io.FileReader;
import java.io.IOException;
import javax.swing.JOptionPane;

// Save button action
private void btnSaveActionPerformed(java.awt.event.ActionEvent evt) {
    Student student = new Student(txtId.getText(), txtName.getText(),
            Integer.parseInt(txtAge.getText()));

    try (FileWriter writer = new FileWriter("student.json")) {
        gson.toJson(student, writer);
        JOptionPane.showMessageDialog(this, "Save ပြီးပါပြီ");
    } catch (IOException e) {
        JOptionPane.showMessageDialog(this, "Error: " + e.getMessage());
    }
}

// Load button action
private void btnLoadActionPerformed(java.awt.event.ActionEvent evt) {
    try (FileReader reader = new FileReader("student.json")) {
        Student student = gson.fromJson(reader, Student.class);
        txtId.setText(student.getStudentId());
        txtName.setText(student.getName());
        txtAge.setText(String.valueOf(student.getAge()));
    } catch (IOException e) {
        JOptionPane.showMessageDialog(this, "File မတွေ့ပါ");
    }
}
```

`FileWriter`/`FileReader` ကို တိုက်ရိုက် `gson.toJson()` / `gson.fromJson()` ထဲထည့်လိုက်တာက String ကို manual concatenate လုပ်စရာမလိုဘဲ တိုက်ရိုက် file ထဲရေး/ဖတ်နိုင်စေတာပါ။

## ၇။ သတိထားရမယ့်အချက်များ

- **Field name matching**: Gson က default အနေနဲ့ Java field name နဲ့ JSON key name ကို တိုက်စစ်ပါတယ်။ JSON key name မတူချင်ရင် `@SerializedName("json_key")` annotation သုံးနိုင်ပါတယ်။
- **null field**: Gson က default မှာ `null` value ရှိတဲ့ field တွေကို JSON output ထဲမှာ ချန်ထားလေ့ရှိတယ် (skip). ပါချင်ရင် `GsonBuilder().serializeNulls()` သုံးပါ။
- **Date/Time types**: `LocalDate`, `LocalDateTime` စတာတွေကို Gson က default မှာ handle မလုပ်နိုင်ပါဘူး — သင့်ရဲ့ project မှာ date/time class များစွာသုံးနေတာသိထားပါတယ်၊ ဒါအတွက် custom `TypeAdapter` ရေးရပါလိမ့်မယ် (ဒါကို သီးသန့် part တစ်ခုအနေနဲ့ ဆက်သင်ပေးနိုင်ပါတယ်)။

## ၈။ Gson ကို ဘယ်အခါသုံးသင့်လဲ

- Config file (settings.json) local disk မှာ save/load
- Local backup/export data
- Weather API စတဲ့ third-party REST API response ကို parse လုပ်ရာမှာ (REST API lesson မှာ သင်ခဲ့တဲ့ topic ကို ဆက်စပ်သုံးလို့ရပါတယ်)
- RMI project ထဲမှာလည်း data transfer/logging format အနေနဲ့ သုံးလို့ရတယ်
