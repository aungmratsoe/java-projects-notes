## LocalDate / LocalDateTime အတွက် Custom TypeAdapter

### ၁။ ဘာလို့ လိုအပ်လဲ

Gson ရဲ့ default engine က `java.time` package (Java 8+ ရဲ့ `LocalDate`, `LocalDateTime`) ကို native support မလုပ်ပါဘူး — internal structure (year, month, day fields) ကို directly serialize လုပ်ကြည့်ရင် ရှုပ်ထွေးတဲ့ nested JSON object ထွက်လာတတ်ပြီး၊ deserialize ကျတော့ `JsonSyntaxException` တက်တတ်ပါတယ်။ ဒါကြောင့် "ဘယ်လို JSON string format ကို ဘယ်လို LocalDate object ဖြစ်အောင် ပြောင်းမလဲ" ဆိုတာကို ကိုယ်တိုင် သတ်မှတ်ပေးရပါတယ် — ဒါက `TypeAdapter` ရဲ့ အလုပ်ပါ။

### ၂။ LocalDate အတွက် TypeAdapter

```java
import com.google.gson.TypeAdapter;
import com.google.gson.stream.JsonReader;
import com.google.gson.stream.JsonWriter;
import java.io.IOException;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

public class LocalDateAdapter extends TypeAdapter<LocalDate> {

    private final DateTimeFormatter formatter = DateTimeFormatter.ISO_LOCAL_DATE; // "2026-08-14"

    @Override
    public void write(JsonWriter out, LocalDate value) throws IOException {
        if (value == null) {
            out.nullValue();
            return;
        }
        out.value(value.format(formatter));
    }

    @Override
    public LocalDate read(JsonReader in) throws IOException {
        if (in.peek() == com.google.gson.stream.JsonToken.NULL) {
            in.nextNull();
            return null;
        }
        return LocalDate.parse(in.nextString(), formatter);
    }
}
```

`write()` က Java object → JSON (serialize), `read()` က JSON → Java object (deserialize) — နှစ်ခုစလုံး override လုပ်ပေးရပါတယ်။ `null` check ကို သေချာထည့်ပေးရပါတယ်၊ မထည့်ရင် `null` value ကြုံတဲ့အခါ `NullPointerException` တက်နိုင်ပါတယ်။

### ၃။ LocalDateTime အတွက် TypeAdapter

```java
import java.time.LocalDateTime;

public class LocalDateTimeAdapter extends TypeAdapter<LocalDateTime> {

    private final DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd'T'HH:mm:ss");

    @Override
    public void write(JsonWriter out, LocalDateTime value) throws IOException {
        if (value == null) {
            out.nullValue();
            return;
        }
        out.value(value.format(formatter));
    }

    @Override
    public LocalDateTime read(JsonReader in) throws IOException {
        if (in.peek() == com.google.gson.stream.JsonToken.NULL) {
            in.nextNull();
            return null;
        }
        return LocalDateTime.parse(in.nextString(), formatter);
    }
}
```

### ၄။ Gson Instance ထဲမှာ Register လုပ်ခြင်း

```java
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import java.time.LocalDate;
import java.time.LocalDateTime;

Gson gson = new GsonBuilder()
        .registerTypeAdapter(LocalDate.class, new LocalDateAdapter())
        .registerTypeAdapter(LocalDateTime.class, new LocalDateTimeAdapter())
        .setPrettyPrinting()
        .create();
```

Project တစ်ခုလုံးမှာ Gson instance ကို နေရာအနှံ့ manual create မလုပ်ဘဲ, singleton pattern နဲ့ Utility class တစ်ခုထဲ ဗဟိုပြုလို့ရပါတယ် (RMI project မှာသင်ခဲ့တဲ့ Singleton pattern ပုံစံအတိုင်း):

```java
public class GsonUtil {
    private static final Gson instance = new GsonBuilder()
            .registerTypeAdapter(LocalDate.class, new LocalDateAdapter())
            .registerTypeAdapter(LocalDateTime.class, new LocalDateTimeAdapter())
            .create();

    private GsonUtil() {}

    public static Gson getInstance() {
        return instance;
    }
}
```

နောက် Class တွေမှာ `GsonUtil.getInstance().toJson(...)` ဆိုပြီး တစ်နေရာတည်းက Gson config ကို ပြန်သုံးလို့ရသွားပါတယ်။

### ၅။ အသုံးချပုံ ဥပမာ (Student Model)

```java
public class Student {
    private String studentId;
    private String name;
    private LocalDate birthDate;
    private LocalDateTime registeredAt;
    // getters/setters
}
```

```java
Student student = new Student("STU001", "Aung Aung",
        LocalDate.of(2005, 3, 15),
        LocalDateTime.now());

String json = gson.toJson(student);
System.out.println(json);
```

Output:

```json
{
  "studentId": "STU001",
  "name": "Aung Aung",
  "birthDate": "2005-03-15",
  "registeredAt": "2026-08-14T04:30:00"
}
```

Deserialize:

```java
Student loaded = gson.fromJson(json, Student.class);
System.out.println(loaded.getBirthDate()); // LocalDate object အနေနဲ့ ပြန်ရပါတယ်
```

### ၆။ Adapter မသုံးဘဲ Shortcut (JsonSerializer/JsonDeserializer)

`TypeAdapter` က performance ပိုကောင်းပေမယ့်, code ပိုရိုးရှင်းချင်ရင် `JsonSerializer` + `JsonDeserializer` interface ကို alternative အနေနဲ့ သုံးလို့ရပါတယ်:

```java
gson = new GsonBuilder()
    .registerTypeAdapter(LocalDate.class, (com.google.gson.JsonSerializer<LocalDate>)
        (src, typeOfSrc, context) -> new com.google.gson.JsonPrimitive(src.toString()))
    .registerTypeAdapter(LocalDate.class, (com.google.gson.JsonDeserializer<LocalDate>)
        (json, typeOfT, context) -> LocalDate.parse(json.getAsString()))
    .create();
```

Data volume များပြီး performance အရေးကြီးရင် `TypeAdapter` (streaming-based) ကို preferred လုပ်ပါ၊ code readability ပိုအရေးကြီးရင် `JsonSerializer`/`JsonDeserializer` (tree-based) ကို သုံးနိုင်ပါတယ်။

### ၇။ QRCode Project အတွက် သတိပြုစရာ

သင့် Student model မှာ `LocalDate`, `LocalDateTime`, `java.sql.Date`, `Timestamp` စသဖြင့် အမျိုးမျိုးရှိတယ်လို့သိရပါတယ် — DB ဘက်ကို save/load လုပ်တဲ့အခါ DAO layer ထဲမှာ `java.sql.Date` ↔ `LocalDate` convert ပြီးမှသာ Gson serialize ကို ခေါ်သင့်ပါတယ် (Gson adapter ကို `LocalDate`/`LocalDateTime` အတွက်သာ register ထားလို့, `java.sql.Date`/`Timestamp` အတွက် ကို ခွဲပြီး adapter ထပ်ရေးရင် ရပါတယ်၊ ဒါမှမဟုတ် Model layer ထဲမှာ `java.time` type တွေချည်းသာ သုံးအောင် standardize လုပ်ထားရင် ပိုရိုးရှင်းပါလိမ့်မယ်).
