## Weather API Response ကို Gson နဲ့ Parse လုပ်ပြီး Swing UI ထဲပြခြင်း (Practical Example)

REST API lesson မှာ weather API integration ကို ခေါ်ပုံ (HTTP request) သင်ခဲ့ပြီးသားမို့ ဒီနေရာမှာ **response ကို Gson နဲ့ parse လုပ်ပြီး Swing component ထဲ ပြသနည်း** ကို အဓိကထားပါမယ်။ ဥပမာအနေနဲ့ OpenWeatherMap-style JSON format ကို သုံးပါမယ်။

### ၁။ API Response Structure ကို ကြည့်ခြင်း

```json
{
  "name": "Yangon",
  "main": {
    "temp": 32.5,
    "humidity": 78,
    "feels_like": 36.2
  },
  "weather": [
    {
      "description": "scattered clouds",
      "icon": "03d"
    }
  ],
  "wind": {
    "speed": 3.6
  }
}
```

Nested object (`main`, `weather` array, `wind`) ပါတဲ့ JSON ဖြစ်ပါတယ် — Gson က nested structure ကို auto-map လုပ်ပေးနိုင်ပါတယ်၊ Java model class structure ကို JSON structure နဲ့ တူအောင် ရေးရုံပါပဲ။

### ၃။ API ခေါ်ပြီး Parse လုပ်တဲ့ Service Class

```java
package com.ams.qrcode.service;

import com.ams.qrcode.model.WeatherResponse;
import com.google.gson.Gson;
import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class WeatherService {

    private final Gson gson = new Gson();
    private final String apiKey = "YOUR_API_KEY";

    public WeatherResponse fetchWeather(String city) throws IOException, InterruptedException {
        String url = "https://api.openweathermap.org/data/2.5/weather?q="
                + city + "&appid=" + apiKey + "&units=metric";

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(url))
                .GET()
                .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());

        if (response.statusCode() != 200) {
            throw new IOException("API Error: " + response.statusCode());
        }

        // JSON string ကို WeatherResponse object အဖြစ် တိုက်ရိုက် parse လုပ်လိုက်တာပါ
        return gson.fromJson(response.body(), WeatherResponse.class);
    }
}
```

`gson.fromJson()` တစ်ကြောင်းတည်းက nested JSON (main, weather array, wind) အားလုံးကို Java object hierarchy အဖြစ် တစ်ခါတည်း ပြောင်းပေးလိုက်ပါတယ် — manual `JSONObject.getJSONObject("main")` စတဲ့ nested parsing code တွေ ရေးစရာမလိုတော့ပါဘူး။

### ၄။ Swing UI ထဲ ပြသခြင်း (NetBeans GUI Builder ပုံစံ)

NetBeans Design mode မှာ `lblCity`, `lblTemp`, `lblDescription`, `lblHumidity`, `lblWind` ဆိုတဲ့ JLabel တွေနဲ့ `txtCitySearch` (JTextField), `btnSearch` (JButton) ကို drag-and-drop ချထားတယ်လို့ ယူဆပါမယ်:

```java
private void btnSearchActionPerformed(java.awt.event.ActionEvent evt) {
    String city = txtCitySearch.getText().trim();
    if (city.isEmpty()) {
        JOptionPane.showMessageDialog(this, "မြို့နာမည် ရိုက်ထည့်ပါ");
        return;
    }

    // Network call ကို background thread ခွဲထုတ်ပါ - UI freeze မဖြစ်စေရန်
    SwingWorker<WeatherResponse, Void> worker = new SwingWorker<>() {
        @Override
        protected WeatherResponse doInBackground() throws Exception {
            WeatherService service = new WeatherService();
            return service.fetchWeather(city);
        }

        @Override
        protected void done() {
            try {
                WeatherResponse weather = get();
                updateWeatherUI(weather);
            } catch (Exception e) {
                JOptionPane.showMessageDialog(WeatherPanel.this,
                        "Weather data ရယူ၍ မရပါ: " + e.getMessage());
            }
        }
    };
    worker.execute();
}

private void updateWeatherUI(WeatherResponse weather) {
    lblCity.setText(weather.getCityName());
    lblTemp.setText(String.format("%.1f°C", weather.getMain().getTemperature()));
    lblHumidity.setText("Humidity: " + weather.getMain().getHumidity() + "%");
    lblWind.setText(String.format("Wind: %.1f m/s", weather.getWind().getSpeed()));

    if (!weather.getWeather().isEmpty()) {
        lblDescription.setText(weather.getWeather().get(0).getDescription());
    }
}
```

**`SwingWorker` သုံးရတဲ့အကြောင်းရင်း**: Network call (HTTP request) က time ကြာနိုင်ပါတယ်။ Event Dispatch Thread (EDT) ပေါ်မှာ တိုက်ရိုက်ခေါ်ရင် UI က freeze ဖြစ်သွားပါလိမ့်မယ် (window drag/resize မရ, click response မရ). `SwingWorker` က network/parsing work ကို background thread ခွဲထုတ်ပြီး, ပြီးမှ `done()` ထဲမှာ UI update ကို EDT ပေါ်ပြန်ရောက်အောင် လုပ်ပေးပါတယ် (RMI lesson မှာ concurrent client thread safety သင်ခဲ့တဲ့ concept နဲ့ ဆင်တူပါတယ်).

### ၅။ Error Handling ထပ်ဖြည့်ခြင်း (Malformed JSON / null field)

```java
try {
    WeatherResponse weather = gson.fromJson(response.body(), WeatherResponse.class);
    if (weather == null || weather.getMain() == null) {
        throw new IOException("Response format မမှန်ပါ");
    }
    updateWeatherUI(weather);
} catch (com.google.gson.JsonSyntaxException e) {
    JOptionPane.showMessageDialog(this, "JSON parse error: " + e.getMessage());
}
```

API key မှား/expire ဖြစ်တဲ့အခါ response body က `{"cod":401,"message":"Invalid API key"}` စသလို error JSON ပြန်တတ်ပါတယ် — `weather.getMain() == null` check ကနေ ဒီလိုအခြေအနေကို catch လုပ်ပေးနိုင်ပါတယ်။
