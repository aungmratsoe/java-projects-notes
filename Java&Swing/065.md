# PART 9

# Runnable vs Callable

## Runnable

No return value:

```java
Runnable task = () -> {


saveOrder();


};

```

---

## Callable

Returns result:

```java
Callable<Double> task = () -> {


return calculateTotal();


};

```

---

Difference:

|Runnable|Callable|
|---|---|
|No return|Returns value|
|No checked exception|Can throw exception|
|execute task|Get result|

---

# PART 12

# SwingWorker

Swing built-in solution.

Structure:

```
doInBackground()

        ↓

Background Thread


done()

        ↓

EDT

```

---

Example:

```java
SwingWorker<List<Product>,Void> worker =


new SwingWorker<>() {



@Override

protected List<Product> doInBackground(){


return productService.findAll();


}



@Override

protected void done(){


try{


table.setData(
get()
);



}catch(Exception e){



}



}


};



worker.execute();

```

# CompletableFuture

Modern Java asynchronous programming.

Example:

Need:

```
Sales Report

+

Inventory Report

+

Customer Report

```

Run parallel.

---

Code:

```java
CompletableFuture<Long> sales =

salesService.count()


);

inventoryService.count()


);
```

