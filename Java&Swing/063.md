# PART 3

# Strategy Pattern

## Payment System Example

Need:

```text
Payment

    |

 ----------------

 |      |        |

Cash   Card   MobilePay

```

---

# 1. Payment Interface

```java
public interface PaymentStrategy {


void pay(double amount);


}

```

---

# 2. Cash Payment

```java
public class CashPayment

implements PaymentStrategy {


@Override

public void pay(double amount){


System.out.println(

"Cash payment: "

+ amount

);


}


}

```

---

# 3. Card Payment

```java
public class CardPayment

implements PaymentStrategy {


@Override

public void pay(double amount){


System.out.println(

"Card payment: "

+ amount

);


}


}

```

---

# 4. Payment Context

```java
public class PaymentService {


private PaymentStrategy strategy;



public PaymentService(
PaymentStrategy strategy
){

this.strategy = strategy;

}



public void process(
double amount
){


strategy.pay(amount);


}


}

```

---

Usage:

Cash:

```java
PaymentService service =

new PaymentService(

new CashPayment()

);


service.process(10000);

```

---

Card:

```java
PaymentService service =

new PaymentService(

new CardPayment()

);


service.process(10000);

```

---

Benefit:

New Payment:

```text
KBZPayPayment

```

ထည့်ရုံပဲ။

Existing code မပြင်ရပါ။

# PART 4

# Factory Pattern

## Problem

Object Creation နေရာတိုင်းမှာ:

```java
new CashPayment();

new CardPayment();

new MobilePayment();

```

ဖြစ်နေတယ်။

---

Solution:

Factory

```text
Request

  ↓

Factory

  ↓

Object

```

---

# PaymentFactory

```java
public class PaymentFactory {


public static PaymentStrategy create(

String type

){


return switch(type){


case "CASH" ->

new CashPayment();



case "CARD" ->

new CardPayment();



default ->

throw new IllegalArgumentException(

"Unknown payment"

);


};


}


}

```

---

Usage:

```java
PaymentStrategy payment =

PaymentFactory.create(
"CASH"
);

```

---

# PART 5

# Singleton Pattern

## Database Connection Manager

Problem:

Every Repository:

```java
Connection con =
DriverManager.getConnection();

```

creates many connections.

---

Need:

One Connection Pool / Manager.

---

# Singleton Example

```java
public class DatabaseManager {


private static DatabaseManager instance;



private DatabaseManager(){



}



public static DatabaseManager getInstance(){


if(instance == null){


instance =
new DatabaseManager();


}


return instance;


}


}

```

---

Usage:

```java
DatabaseManager db =

DatabaseManager.getInstance();

```

---

# Real Production Note

Modern systems use:

```text
Connection Pool

(HikariCP)

```

instead of simple Singleton.

# Observer Pattern

## Real Café Example

When Stock Low:

Need notify:

```text
Inventory


      ↓

```

---

Observer Concept:

```text
Subject

   |

   |

```

---

# Stock Observer

Interface:

```java
public interface StockObserver {


void update(
String message
);


}

```

---

Dashboard:

```java
public class DashboardObserver

implements StockObserver {



public void update(String message){


System.out.println(
message
);


}


}

```

---

Inventory:

```java
public class InventoryService {


private List<StockObserver> observers;


public void notifyObservers(
String msg
){


for(
StockObserver o:
observers
){


o.update(msg);


}


}


}

```

---

Example:

Stock:

```text
Coffee Bean = 2kg

Minimum = 5kg

```

System:

```text
LOW STOCK ALERT

```

# PART 7

# Repository Pattern Improvement

Already used:

```text
Controller

      ↓

Service

      ↓

Repository

```

Now improve:

---

Generic Repository:

```java
public interface Repository<T,ID>{


T findById(ID id);


List<T> findAll();


void save(T entity);


void delete(ID id);


}

```

---

Product:

```java
class ProductRepository

implements Repository<Product,Long>

```

---

Customer:

```java
class CustomerRepository

implements Repository<Customer,Long>

```

---

Benefit:

Less duplicate code.
