# PART 9

# Configure Tracing

application.yml:

```yaml
management:


 tracing:

  sampling:

   probability:
    1.0



 otlp:

  tracing:

   endpoint:

    http://localhost:4317

```

---

Meaning:

```text
probability: 1.0

```

means:

```
Trace every request

```

Production:

```yaml
probability: 0.1

```

10% sampling.

# PART 13

# Custom Business Span

Example:

Payment processing:

```java
@Service

@RequiredArgsConstructor

public class PaymentService {


private final Tracer tracer;



public void process(){


Span span = tracer.nextSpan()
.name("payment-processing")
.startSpan();


try{


// payment logic


}
finally{


span.end();


}


}


}

```

---

Jaeger:

```
payment-processing

500ms

```
