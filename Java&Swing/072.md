# Why Caching?

Database Query:

```sql

FROM products;

```

အကြိမ် 1000 ခေါ်ရင်:

```text

     |

     |

  MySQL

     |

```

Problem:

```text

Memory ↑

Response Time ↑

```

---

Solution:

Cache:

```text
Application

     |

     |

  Cache

     |

 Database

```

# PART 2

# What is Cache?

Cache ဆိုတာ:

> Frequently Used Data ကို Fast Storage ထဲမှာ ခဏသိမ်းထားခြင်း

Example:

Product:

```
Coffee Latte
Price 5000

```

ဒီ Data ကို:

```
10000 users

```

ကြည့်မယ်ဆိုရင် Database မခေါ်ဘဲ Cache ကနေ Return လုပ်နိုင်ပါတယ်။

# PART 10

# Cache Invalidation

Biggest Cache Problem:

> How to update old data?

Example:

Database:

```
Coffee Price = 5000

```

Redis:

```
Coffee Price = 5000

```

Update:

```
Price = 6000

```

Database:

```
6000

```

Redis:

```
5000 ❌

```

---

Solution:

Remove Cache:

```java
@CacheEvict(
value="products",
key="#id"
)

public void updateProduct(Long id){

}

```
