# PART 7

# Why Maven Multi Module?

Single Project:

```
cafe-app.jar

```

Problem:

```
Change Product

↓

Deploy Everything

```

---

Multi Module:

```
auth-service.jar

product-service.jar

order-service.jar

```

Now:

```
Update Product

↓

Deploy Product Only

```
