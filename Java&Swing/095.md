# Microservice Communication Problem

Traditional:

```text

      |

      |

Payment Service


      |

      |

Inventory Service


```

Order တင်တဲ့အချိန်:

```text

      |

      |
```

```text
❌ Difficult Scaling
```

```json
}
```

# PART 12

# Message Delivery Guarantees

Kafka supports:

## At Most Once

```text
Message may lose

Fast

```

---

## At Least Once

```text
Message delivered

May duplicate

```

---

## Exactly Once

```text
No loss

No duplicate

Most reliable

```

---

Production:

Usually:

```text
At Least Once

+

Idempotency

```

```sql

);
```

```java
if(eventExists){

}
```
