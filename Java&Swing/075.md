# PART 9

# API Gateway Design

Client never calls services directly.

Wrong:

```
Client

 |
 |
Product Service

```

---

Correct:

```
Client

 |

API Gateway

 |

Services

```

---

Routes:

```
/api/auth/**

        ↓

Auth Service


/api/products/**

        ↓

Product Service


/api/orders/**

        ↓

Order Service


/api/payment/**

        ↓

Payment Service

```
