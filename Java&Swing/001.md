# 2. Control Flow

သိထားရမည့်:

## if / else

```java
if(username.equals("admin")){
    System.out.println("Login Success");
}
else{
    System.out.println("Failed");
}
```

## switch

```java
switch(role){

case "ADMIN":
    System.out.println("Admin");
    break;

case "USER":
    System.out.println("User");
}
```

# Class & Object

Example:

```java
public class Customer {

    String name;

    public void display(){
        System.out.println(name);
    }

}
```

Object:

```java
Customer c = new Customer();

c.name="Mg Mg";

c.display();
```

Swing မှာ:

```java
JButton button = new JButton();
```

ဒီမှာ

- JButton = Class
    
- button = Object

# 4. Constructor

Swing မှာ UI Initialize လုပ်တဲ့နေရာမှာ အများဆုံးသုံးပါတယ်။

Example:

```java
public class LoginFrame extends JFrame{


    public LoginFrame(){

        setTitle("Login");

        setSize(400,300);

    }

}
```

Constructor က object create လုပ်တဲ့အချိန် execute ဖြစ်ပါတယ်။

```java
LoginFrame frame = new LoginFrame();
```

ဖြစ်တဲ့အချိန် constructor run ပါတယ်။

# 6. Encapsulation

Professional Swing Application တွေမှာ Data ကို private ထားပါတယ်။

Bad:

```java
public String username;
```

Good:

```java
private String username;


public String getUsername(){

    return username;

}


public void setUsername(String username){

    this.username=username;

}
```

# 8. Exception Handling
