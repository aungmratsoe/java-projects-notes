# PART 5

# Ingredient Table

Ingredients are raw materials.

Examples:

```text
Coffee Bean

Milk

Sugar

Chocolate

Tea Leaf

```

SQL:

```sql
CREATE TABLE ingredients(

id BIGINT PRIMARY KEY AUTO_INCREMENT,


name VARCHAR(100) NOT NULL,


unit VARCHAR(20) NOT NULL,


created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

);

```

# PART 6

# Stock Table

Current quantity:

```sql
CREATE TABLE stocks(

id BIGINT PRIMARY KEY AUTO_INCREMENT,


ingredient_id BIGINT UNIQUE,


quantity DECIMAL(10,2),


minimum_level DECIMAL(10,2),


updated_at TIMESTAMP,


FOREIGN KEY(ingredient_id)

REFERENCES ingredients(id)

);

```

# PART 18

# Stock In Logic

Flow:

```text
Request


 ↓


Find Ingredient


 ↓


Update Quantity


 ↓


Save Transaction


 ↓


Clear Cache


```

---

Code:

```java
@Transactional

public void stockIn(

StockRequest request

){


Stock stock =

stockRepository

.findByIngredientId(
request.ingredientId()
)

.orElseThrow();



stock.setQuantity(

stock.getQuantity()

.add(
request.quantity()
)

);



stockRepository.save(stock);



}

```

# PART 20

# Low Stock Detection

```text
quantity < minimumLevel

```

```text

500ml
```
