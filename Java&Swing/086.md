# PART 6

# Configure Eureka Server

application.yml:

```yaml
server:

 port: 8761



eureka:

 client:

  register-with-eureka: false


  fetch-registry: false

```

---

Explanation:

```
register-with-eureka=false

```

Meaning:

```
Server does not register itself

```

```
fetch-registry=false

```

Meaning:

```
Server does not need another registry

```

# PART 13

# Gateway Integration

Before:

```yaml

http://localhost:8082

```

Problem:

Static URL.

---

After:

```yaml
uri:

lb://product-service

```

---

Example:

```yaml
spring:

 cloud:

  gateway:

   routes:


   - id:
       product-service


     uri:
       lb://product-service


     predicates:


     - Path=/api/products/**

```
