# PART 9

# Deployment

Problem:

Pod crash:

```text
Product Pod

      X

Stopped

```

---

Deployment:

```text
Deployment


      |

      |

Creates Pod


      |

Restart Automatically

```

---

Example:

```yaml
apiVersion: apps/v1

kind: Deployment


metadata:

 name: product-service



spec:

 replicas: 3



 template:

  spec:

   containers:

   - name: product

     image:
     cafe/product:v1

```

---

Meaning:

```text
3 replicas


Pod 1

Pod 2

Pod 3

```
