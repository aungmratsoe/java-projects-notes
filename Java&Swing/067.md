# PART 10

# Mock Repository

Real:

```
OrderService

    |

ProductRepository

    |

MySQL

```

---

Test:

```
OrderService

    |

Mock ProductRepository

```

---

Example:

```java
@ExtendWith(MockitoExtension.class)

class OrderServiceTest {


@Mock

ProductRepository repository;



@InjectMocks

OrderService service;



@Test

void createOrderTest(){


when(
repository.findById(1L)
)

.thenReturn(
new Product(
1L,
"Coffee"
)
);



service.createOrder();



verify(
repository
)
.findById(1L);



}

}

```

---
