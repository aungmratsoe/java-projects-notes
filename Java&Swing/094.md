# PART 8

# Create Replication User

Primary:

```sql
CREATE USER 
'replica'
@
'%'
IDENTIFIED BY
'password';


GRANT REPLICATION SLAVE
ON *.*
TO
'replica'
@
'%';

```

# PART 9

# Replica Connection

Replica:

```sql
CHANGE REPLICATION SOURCE TO

SOURCE_PASSWORD='password';


```

---

```sql

```

---

Check:

```sql
SHOW REPLICA STATUS;

```

---

Yes
