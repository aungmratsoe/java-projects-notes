# PART 10

# Cache Aside Pattern

Most popular pattern.

Flow:

```text
Request


 |

Check Cache


 |

----------------

|              |

Hit            Miss


|              |


Return        Database


                |


             Save Cache


```

---

Example:

```java
public Product getProduct(Long id){


String key =
"product:"+id;



Product product =
redis.get(key);



if(product != null){

return product;

}



product =
repository.findById(id);



redis.set(
key,
product
);



return product;


}

```

# PART 11

# Cache Expiration (TTL)

Problem:

Old data remains forever.

Solution:

TTL.

Example:

```java
redis.opsForValue()
.set(
"product:100",
product,
10,
TimeUnit.MINUTES
);

```

---

Meaning:

```text
Cache lifetime:

10 minutes

```
