# PART 1

# Authentication vs Authorization

လူအများဆုံးမှားတဲ့ Concept:

## Authentication

Question:

> "မင်းဘယ်သူလဲ?"

Example:

```text
Username

Password

OTP

```

Result:

```text
User Identity Confirmed

```

---

## Authorization

Question:

> "မင်းဘာလုပ်ခွင့်ရှိလဲ?"

Example:

```text
Admin

Manager

Cashier

Customer

```

---

Example:

Login:

```
John
```

Authentication:

```
✅ John is valid user

```

Authorization:

```
Can John delete products?

```

Answer:

```
❌ No

```

# PART 5

# JWT Structure

JWT:

```
xxxxx.yyyyy.zzzzz

```

Three parts:

```
Header.Payload.Signature

```

---

Example:

Header:

```json
{
"alg":"RS256",
"typ":"JWT"
}

```

---

Payload:

```json
{
"userId":1001,
"role":"ADMIN",
"exp":1720000000
}

```

---

Signature:

```
Private Key

+

Payload

```

# PART 12

# Security Configuration

Example:

```java
@Configuration

@EnableWebSecurity

public class SecurityConfig {



@Bean

SecurityFilterChain filterChain(
HttpSecurity http
)
throws Exception{


return http

.csrf(csrf -> csrf.disable())


.authorizeHttpRequests(auth -> auth


.requestMatchers(
"/public/**"
)
.permitAll()


.anyRequest()
.authenticated()


)


.oauth2ResourceServer(

oauth ->
oauth.jwt()

)


.build();


}

}
```

# PART 14

# Role Based Access Control (RBAC)

Roles:

```
ADMIN

MANAGER

CASHIER

CUSTOMER

```

---

Example:

Product Delete:

```java
@PreAuthorize(
"hasRole('ADMIN')"
)

@DeleteMapping("/{id}")

public void delete(){

}

```

---

Customer:

```
❌ Forbidden

```

---

Admin:

```
✅ Allowed

```
