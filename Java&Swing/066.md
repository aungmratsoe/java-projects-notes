# PART 2

# Stack Memory

Stack မှာ:

```text
Local Variables

Method Calls

Primitive Values

References

```

တွေ သိမ်းပါတယ်။

---

Example:

```java
public void createOrder(){


int quantity = 5;


double total = 10000;


}

```

Memory:

```text
Stack


quantity = 5

total = 10000

```

---

Method ပြီးသွားရင်:

```text
Stack Frame Removed

Memory Released

```

---

Example:

```java

```

Now:

```text
Product Object

(no reference)

↓

Eligible for GC

```

# PART 8

# Resource Management

Wrong JDBC:

```java
Connection con =
DriverManager.getConnection();


PreparedStatement ps =
con.prepareStatement(sql);


```

Close မလုပ်ရင်:

```text
Connection Leak

↓

Database Crash

```

---

Correct:

Use try-with-resource:

```java
try(
Connection con =
dataSource.getConnection();

PreparedStatement ps =
con.prepareStatement(sql)

){


ps.executeQuery();


}

```

---

Automatically:

```text
Connection Closed

Statement Closed

ResultSet Closed

```

# PART 12

# Batch Insert

Problem:

Insert 100 orders:

```java
for(Order o:orders){

insert(o);

}

```

100 Database Calls.

---

Better:

```java
PreparedStatement ps;


for(Order o:orders){

ps.addBatch();

}


ps.executeBatch();

```

---

Result:

```text
100 Queries

↓

1 Batch

```

---

# PART 13

# PreparedStatement Reuse

Wrong:

```java
for(Product p:list){


connection.prepareStatement(sql);


}

```

---

Better:

```java
PreparedStatement ps =

connection.prepareStatement(sql);


for(Product p:list){


ps.setString(1,p.name());


ps.addBatch();


}

```

# Pagination

```sql

FROM orders;
```

```sql

FROM orders
```
