# PART 9

# Request Validation

Problem:

User sends:

```json
{
"name":"",
"price":-100
}

```

---

Need Validation.

DTO:

```java
public class ProductRequest {


@NotBlank
private String name;


@Min(1)
private BigDecimal price;


}

```

---

Controller:

```java
@PostMapping

public Product create(
@Valid
@RequestBody ProductRequest request
){

return service.save(request);

}

```

# PART 10

# Global Exception Handling

Instead of:

```
500 Error

```

Return:

```json
{
"status":400,

"message":
"Invalid Product Data"

}

```

---

Code:

```java
@RestControllerAdvice

public class GlobalExceptionHandler{


@ExceptionHandler(
MethodArgumentNotValidException.class
)

public ResponseEntity<?> handle(){

return ResponseEntity
.badRequest()
.build();

}

}

```

# PART 18

# GraphQL Concept

REST:

Need:

```
GET /products

GET /categories

GET /reviews

```

---

Three Requests.

---

GraphQL:

Single Request:

```graphql
query {

 product(id:100){

  name

  price

  category

 }

}

```

---

Response:

```json
{
"name":"Coffee",
"price":5000,
"category":"Drink"
}

```

---

# PART 19

# REST vs GraphQL

|REST|GraphQL|
|---|---|
|Multiple endpoints|Single endpoint|
|Over fetching|Exact data|
|Simple|Flexible|
|Caching easier|Complex caching|

---

Use:

REST:

```
Public APIs

Simple CRUD

```

GraphQL:

```
Mobile Apps

Dashboard

Complex UI

```
