```java
setTitle(
"Café POS System"
);

1200,
700
);

new BorderLayout()
);



add(
new SidebarPanel(this),
BorderLayout.WEST

new JPanel();

contentPanel,
BorderLayout.CENTER

panel
);



contentPanel.revalidate();


contentPanel.repaint();
```

# PART 5

# Navigation Architecture

Wrong:

```java
button.addActionListener(e -> {


new ProductPanel();


});

```

Problem:

Every button knows everything.

---

Better:

```
Button

 ↓

Navigator

 ↓

Panel

```

---

Create:

```
navigation

NavigationManager.java

```

---

Code:

```java
public class NavigationManager {


private MainFrame frame;



public NavigationManager(
MainFrame frame
){

this.frame = frame;

}



public void navigate(
JPanel panel
){


frame.showPanel(panel);


}


}

```

---

Usage:

```java
navigation.navigate(

new ProductPanel()

);

```

```java

public static final Color PRIMARY =

new Color(52,152,219);



public static final Color BACKGROUND =

new Color(245,245,245);

"Arial",
Font.BOLD,
22
);
```

# PART 14

# Swing Threading Rule

Very Important:

Swing UI runs on:

```
EDT

(Event Dispatch Thread)

```

---

Wrong:

```java
button.addActionListener(e -> {


load100000Products();


});

```

UI freezes.

---

Correct:

Use:

```java
SwingWorker

```

---

Example:

```java
new SwingWorker<List<Product>,Void>(){


protected List<Product> doInBackground(){


return service.findAll();


}


protected void done(){


updateTable();


}


}.execute();

```
