# PART 1

# Monolith Architecture Review

Current Café POS:

```text
                 Client


                   |


            Spring Boot App


                   |


        ----------------------

        |        |           |

     User    Product     Order


        |        |           |


              MySQL

```

---

Everything inside one application.

Advantages:

```text
Simple

Easy Development

Easy Deployment

```

---

Problems:

## 1. Scaling Problem

Example:

Order API traffic:

```text
10000 requests/sec

```

Need scale Order only.

But:

```text
Scale entire application

```

---

## 2. Deployment Problem

Small change:

```text
Product Module Update

```

Need:

```text
Restart Entire Application

```

---

# PART 2

# Microservices Architecture

Idea:

> Split one large application into small independent services

Architecture:

```text
                 Client


                   |


             API Gateway


                   |


 ---------------------------------

 |          |          |          |


User     Product     Order    Inventory

Service  Service     Service   Service


 |          |          |          |


DB         DB         DB         DB

```

---

# PART 3

# Microservices Principles

## 1. Single Responsibility

One service:

```text
One Business Function

```

Example:

Product Service:

```text
Products Only

```

---

## 2. Independent Deployment

Update:

```text
Product Service v2

```

Only deploy Product Service.

---

## 3. Independent Scaling

Order Traffic:

```text
Order Service

10 instances

```

Product:

```text
2 instances

```

# When NOT to Use Microservices

Microservices are not always better.

```
2 developers

1 restaurant

Low traffic

```

Use:

```
Modular Monolith

```

---

Large System:

```
100 developers

100 branches

Millions orders

```

Use:

```
Microservices

```
