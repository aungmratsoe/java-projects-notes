# Lesson 85: Centralized Configuration Management

## Spring Cloud Config Server + External Configuration + Secret Management + Environment Profiles

### (Java 25 + Spring Boot + Spring Cloud Config + Git + Vault Concept)

ဒီ Lesson မှာ CaféPro Platform ရဲ့ **Configuration Management Layer** ကို တည်ဆောက်ပါမယ်။

Microservice System ကြီးလာတဲ့အခါ Configuration တွေများလာပါတယ်။

Example:

Product Service:

```yaml
database:
  url: localhost:3306/product_db

redis:
  host: localhost

kafka:
  server: localhost:9092

```

Order Service:

```yaml
database:
  url: localhost:3306/order_db

kafka:
  server: localhost:9092

```

Payment Service:

```yaml
database:
  url: localhost:3306/payment_db

kafka:
  server: localhost:9092

```

Problem:

Service တစ်ခုချင်းစီမှာ config file တွေ copy လုပ်ထားရပါတယ်။
