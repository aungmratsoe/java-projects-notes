# PART 9

# Access Token vs Refresh Token

## Access Token

Short life:

```text
5 - 15 minutes

```

Purpose:

```text
API Access

```

---

## Refresh Token

Long life:

```text
Days / Weeks

```

Purpose:

```text
Get new Access Token

```

---

Flow:

```text
Access Token Expired


        |


Refresh Token


        |


New Access Token

```

# PART 13

# Security Configuration

Example:

```java
@Configuration

@EnableWebSecurity

public class SecurityConfig {


@Bean

SecurityFilterChain filterChain(
HttpSecurity http
)
throws Exception {


return http

.oauth2ResourceServer(
oauth ->
oauth.jwt()
)


.authorizeHttpRequests(
auth -> auth


.requestMatchers(
"/public/**"
)
.permitAll()


.requestMatchers(
"/admin/**"
)
.hasRole("ADMIN")


.anyRequest()
.authenticated()

)


.build();


}

}

```
