# PART 1

# What is ORM?

ORM:

Object Relational Mapping

ဆိုတာ:

> Java Object နဲ့ Database Table ကို Mapping လုပ်တဲ့ Technology

ဖြစ်ပါတယ်။

---

Without ORM:

Java:

```java
Product product;

```

Database:

```sql
SELECT *

FROM products;

```

Developer ကိုယ်တိုင် Mapping လုပ်ရပါတယ်။

---

With ORM:

```java
productRepository.findAll();

```

Hibernate က:

```sql
SELECT *

FROM products;

```

အလိုအလျောက် Generate လုပ်ပေးပါတယ်။

# PART 4

# @OneToOne Relationship

Example:

Order တစ်ခုမှာ Payment တစ်ခုရှိမယ်။

```text
Order

 |

 |

Payment

```

---

Database:

orders:

```sql
id

customer_id

```

payments:

```sql
id

order_id

amount

```

---

Entity:

## Order

```java
@Entity
public class Order {


@Id
@GeneratedValue
private Long id;



@OneToOne(
mappedBy = "order"
)

private Payment payment;


}

```

---

## Payment

```java
@Entity
public class Payment {


@Id
@GeneratedValue
private Long id;



@OneToOne
@JoinColumn(
name="order_id"
)

private Order order;



private BigDecimal amount;


}

```

---

Meaning:

Payment table မှာ:

```text
order_id

FK

```

ရှိမယ်။

# PART 8

# Fetch Strategy

Very Important.

Two Types:

```text
EAGER

LAZY

```

---

# EAGER

Load immediately.

Example:

```java
@OneToMany(
fetch=FetchType.EAGER
)

```

---

When:

```java
Order order =
repository.findById(1);

```

Hibernate:

```text
Load Order

+

Load Items

+

Load Products

```

---

Problem:

Large Data:

```text
10000 Orders

100000 Items

```

Memory Problem.

---

# LAZY

Load only when needed.

Default:

```java
@OneToMany

```

is:

```text
LAZY

```

---

Example:

```java
Order order =
repository.findById(1);

```

Only:

```text
Order

```

loaded.

---

Later:

```java
order.getItems();

```

Then:

```text
Load Items

```

---

# PART 9

# Lazy Loading Problem

Example:

Controller:

```java
@GetMapping
public Order getOrder(){

return orderRepository.findById(1);

}

```

---

After Service closes:

```text
Session Closed

```

---

Access:

```java
order.getItems();

```

Error:

```text
LazyInitializationException

```

---

Solution:

Use DTO:

```text

Entity

 ↓

DTO

 ↓

JSON

```

# PART 14

# Hibernate Query Optimization

Problem:

N+1 Query.

Example:

Load Orders:

```java
List<Order> orders =
orderRepository.findAll();

```

Hibernate:

```sql
SELECT * FROM orders;


SELECT * FROM items WHERE order_id=1;

SELECT * FROM items WHERE order_id=2;

SELECT * FROM items WHERE order_id=3;

```

---

100 Orders:

100 queries.

---

Solution:

Fetch Join:

```java
@Query(
"SELECT o FROM Order o JOIN FETCH o.items"
)

List<Order> findAllWithItems();

```
