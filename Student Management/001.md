# Student Management System — Java Swing Project (Business Idea + Technical Guide)

## အပိုင်း ၁ — Business Idea ရှင်းလင်းချက်

### ဘာကြောင့် Student Management System (SMS) ကို ရွေးချယ်သင့်သလဲ

ကျောင်းများ၊ Training Center များ၊ Tuition Center များနှင့် Coaching Institute များတွင် ကျောင်းသား/သူများရဲ့ အချက်အလက် (personal info, attendance, grades, fees) များကို စာရွက်စာတမ်း (paper-based) သို့မဟုတ် Excel ဖြင့် စီမံနေကြသေးတဲ့ နေရာတွေ အများကြီးရှိပါတယ်။ ဒီလိုနေရာတွေမှာ -

- **အချိန်ကုန်မြောက်စွာ ကုန်ကျ** – manual data entry, error များ
- **Fee collection မှတ်တမ်းများ ရှုပ်ထွေး** – ဘယ်သူ ဘယ်လောက်ကျန်ကြွေးရှိလဲ ခြေရာခံရခက်
- **Report ထုတ်ရခက်ခဲ** – attendance %, grade summary စသည်
- **Data လုံခြုံမှုနည်း** – paper records ပျောက်ဆုံးနိုင်၊ backup မရှိ

ဒီလိုပြဿနာတွေကို ဖြေရှင်းပေးနိုင်တဲ့ **Desktop-based Student Management System** တစ်ခုကို Java Swing နဲ့ တည်ဆောက်ခြင်းက Business Idea အနေနဲ့ အလားအလာကောင်းပါတယ်။

### Target Market (ဖောက်သည်အုပ်စု)

|Segment|ဖော်ပြချက်|
|---|---|
|Private Schools|ကျောင်းသား ၂၀၀–၅၀၀ ဝန်းကျင်ရှိသော ကျောင်းငယ်များ|
|Tuition/Coaching Centers|Attendance + Fee tracking အဓိကလိုအပ်|
|Vocational Training Institutes|Course enrollment + Certificate issuance|
|Universities (Small Departments)|Department-level student records|

### Business Model Options

1. **One-time License Sale** – ကျောင်းတစ်ကျောင်းချင်းစီကို Software တစ်ခါတည်း ရောင်း (installation + setup fee ပါ)
2. **Subscription (SaaS-like, Desktop + Cloud sync)** – လစဉ်/နှစ်စဉ် maintenance fee
3. **Customization Service** – School logo, report format, language (Myanmar/English) အလိုက် customize လုပ်ပေးပြီး fee ယူ
4. **Freemium** – Basic version အခမဲ့၊ Advanced features (SMS notification, report export, multi-branch) အတွက် ငွေပေးဆောင်

### Competitive Advantage

- Offline-first (Internet မလိုအပ်ဘဲ အလုပ်လုပ်နိုင်) — Myanmar ကျေးလက်ဒေသ internet မတည်ငြိမ်မှုအတွက် အားသာချက်
- Myanmar language support ထည့်နိုင်
- Low-cost deployment (Java = cross-platform, license fee မလို)

## အပိုင်း ၂ — System Features (Modules)

### Core Modules

1. **User Authentication & Role Management**
    - Admin, Teacher, Staff (Accountant) — role-based access
2. **Student Registration Module**
    - Add/Edit/Delete/Search student profile (Name, DOB, Class, Guardian info, Photo)
3. **Class & Subject Management**
    - Class create, Subject assign, Teacher assign
4. **Attendance Module**
    - Daily attendance mark, monthly attendance report, % calculation
5. **Examination & Grading Module**
    - Marks entry, grade calculation, report card generation (PDF export)
6. **Fee Management Module**
    - Fee structure setup, payment recording, outstanding balance tracking, receipt printing
7. **Reports & Analytics**
    - Student list report, attendance summary, fee collection summary (chart-based, JFreeChart သုံးနိုင်)
8. **Backup & Restore**
    - Database backup (.sql export), restore function

### Optional Advanced Features (Premium)

- SMS/Email notification (absent alert, fee reminder)
- Multi-branch support (branch-wise data)
- Timetable/Schedule generator
- ID Card generator (barcode/QR)
- Data export to Excel/PDF

|Column|Type|
|---|---|

**fees**

|Column|Type|
|---|---|

|amount_due|DECIMAL(10,2)|
|amount_paid|DECIMAL(10,2)|
|payment_date|DATE|
|status|ENUM('Paid','Pending','Partial')|

**exams**

|Column|Type|
|---|---|
|exam_id (PK)|INT|
|student_id (FK)|INT|
|subject|VARCHAR(50)|
|marks|INT|

|Column|Type|
|---|---|

Relationship: `classes` 1—N `students`, `students` 1—N `attendance`, `students` 1—N `fees`, `students` 1—N `exams`.

### DBConnection.java

```java
package studentmanagementsystem.dao;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class DBConnection {
    private static final String URL = "jdbc:mysql://localhost:3306/student_db";
    private static final String USER = "root";
    private static final String PASSWORD = "yourpassword";

    public static Connection getConnection() {
        try {
            return DriverManager.getConnection(URL, USER, PASSWORD);
        } catch (SQLException e) {
            e.printStackTrace();
            return null;
        }
    }
}
```

### StudentDAO.java (CRUD Example)

```java
package studentmanagementsystem.dao;

import studentmanagementsystem.model.Student;
import java.sql.*;
import java.util.ArrayList;
import java.util.List;

public class StudentDAO {

    public boolean addStudent(Student s) {
        String sql = "INSERT INTO students (name, dob, gender, class_id, guardian_name, phone, address) VALUES (?,?,?,?,?,?,?)";
        try (Connection conn = DBConnection.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, s.getName());
            ps.setDate(2, java.sql.Date.valueOf(s.getDob()));
            ps.setString(3, s.getGender());
            ps.setInt(4, s.getClassId());
            ps.setString(5, s.getGuardianName());
            ps.setString(6, s.getPhone());
            ps.setString(7, s.getAddress());
            return ps.executeUpdate() > 0;
        } catch (SQLException e) {
            e.printStackTrace();
            return false;
        }
    }

    public List<Student> getAllStudents() {
        List<Student> list = new ArrayList<>();
        String sql = "SELECT * FROM students";
        try (Connection conn = DBConnection.getConnection();
             Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery(sql)) {
            while (rs.next()) {
                Student s = new Student();
                s.setId(rs.getInt("student_id"));
                s.setName(rs.getString("name"));
                s.setGender(rs.getString("gender"));
                s.setPhone(rs.getString("phone"));
                list.add(s);
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return list;
    }
}
```
