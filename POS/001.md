## Part 1: System Overview & Feature List (Cafe POS System)

### POS System ဆိုတာ ဘာလဲ

POS (Point of Sale) system ဆိုတာ ဆိုင်တစ်ခုမှာ **ရောင်းချမှု (Sale transaction) ကို လက်တွေ့ process လုပ်တဲ့ software** ပါ။ Customer တစ်ယောက် coffee တစ်ခွက် order လိုက်တာကနေ, cashier က item ကို select လုပ်, payment ယူ, receipt ထုတ်ပေးတဲ့ အထိ process တစ်ခုလုံးကို handle လုပ်ပေးတာပါ။

### Cafe POS System ရဲ့ Core Actors (Users)

Business logic ကို နားလည်ဖို့ user roles ကို အရင်သိထားရမှာပါ:

1. **Admin (ဆိုင်ပိုင်ရှင် / Manager)**
    
    - Product/Menu management (ADD, EDIT, DELETE)
    - User account management (cashier account တွေ create/disable)
    - Reports ကြည့်ခွင့် (sales report, inventory report)
    - Discount/Tax setting
    - Full system access
2. **Cashier (ဝန်ထမ်း)**
    
    - Order taking (POS screen ကနေ order process)
    - Payment ယူတာ
    - Receipt print
    - သူ့ shift အတွင်း sales history ကိုပဲ ကြည့်ခွင့်ရှိ
3. **(Optional) Manager role** — Admin နဲ့ Cashier ကြားက permission level, discount approve လုပ်ခွင့်စတာမျိုး
    

### Core Features List

**A. Authentication & Session**

- Login (username/password)
- Session tracking (ဘယ်သူ login ဝင်နေလဲ, ဘယ် shift လဲ)
- Auto logout (idle timeout)
- Role-based menu (Admin ကျရင် Admin dashboard ပြမယ်၊ Cashier ကျရင် POS screen ချည်းပဲ ပြမယ်)

**B. Product & Category Management**

- Category (e.g. Coffee, Tea, Pastry, Snacks)
- Product (name, price, category, image, stock qty)
- CRUD operations

**C. Order / POS Core**

- Product grid ကနေ item ရွေး → Cart ထဲ ထည့်
- Quantity adjust, remove item
- Subtotal, Tax, Discount, Total calculation
- Order type (Dine-in / Takeaway) — ဒါလည်း business logic တစ်ခု

**D. Payment**

- Cash payment (change calculation)
- Card payment (simulate)
- Split payment (optional advanced feature)

**E. Inventory Management**

- Order confirm လုပ်တာနဲ့ stock auto-deduct
- Low stock alert

**F. Receipt & Reporting**

- Receipt print (order details, total, cashier name, datetime)
- Daily sales report
- Best-selling item report
- X-Report (mid-shift snapshot) / Z-Report (end-of-day, resets counters)

**G. Shift / Cash Drawer**

- Shift start (opening cash balance ထည့်)
- Shift end (closing balance count, expected vs actual difference)

### Database ရဲ့ Core Entities (Part 2 မှာ အသေးစိတ် design လုပ်မှာပါ)

- `users` — login accounts
- `sessions` / `shifts` — login session, shift tracking
- `categories`
- `products`
- `orders`
- `order_items`
- `payments`
- `inventory_logs`
- `discounts`
