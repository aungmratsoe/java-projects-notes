# Database (JDBC) နဲ့ Shift/Session Data Persist လုပ်ပုံ

Session (in-memory only, RAM ထဲမှာပဲ ရှိတယ်) နဲ့ Shift (database ထဲ persist ဖြစ်ရမယ်) ကွာတဲ့အချက်ကို အရင်ပြန်သတိရပါ — User login state ကို database ထဲ save စရာမလိုပေမယ့် **Shift data ကတော့ app ပိတ်သွားလည်း၊ crash သွားလည်း data မပျောက်ဖို့ database ထဲ ချက်ချင်း write ထားရမယ်** (cash reconciliation record ဖြစ်လို့)။

## ၁. Database Schema Design

```sql
CREATE TABLE users (
    user_id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(100),
    role VARCHAR(20) NOT NULL  -- ADMIN, MANAGER, CASHIER
);

CREATE TABLE shifts (
    shift_id INT PRIMARY KEY AUTO_INCREMENT,
    cashier_id INT NOT NULL,
    start_time DATETIME NOT NULL,
    end_time DATETIME NULL,           -- open shift ဆိုရင် NULL
    opening_cash_float DECIMAL(10,2) NOT NULL,
    closing_cash_counted DECIMAL(10,2) NULL,
    expected_cash DECIMAL(10,2) NULL,
    variance DECIMAL(10,2) NULL,
    status VARCHAR(10) NOT NULL,      -- OPEN, CLOSED
    FOREIGN KEY (cashier_id) REFERENCES users(user_id)
);

CREATE TABLE sales (
    sale_id INT PRIMARY KEY AUTO_INCREMENT,
    shift_id INT NOT NULL,            -- ဒီ sale က ဘယ် shift အောက်ကလဲ
    sale_time DATETIME NOT NULL,
    total_amount DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (shift_id) REFERENCES shifts(shift_id)
);
```

**အဓိက point**: `sales` table ထဲမှာ `shift_id` foreign key ထားတာက traceability အတွက် — "ဒီ sale ကို ဘယ် shift/ဘယ် cashier လုပ်ခဲ့လဲ" ဆိုတာ query လုပ်နိုင်ဖို့။

## ၂. DAO Pattern (Data Access Object) သုံးမယ်

Business logic (SessionManager) ထဲမှာ raw SQL တွေ တိုက်ရိုက်ရေးမယ့်အစား, database operation တွေကို **DAO layer** ခွဲထားတယ်။ ဒါက maintainable ဖြစ်အောင်၊ testable ဖြစ်အောင်။

```java
public class ShiftDAO {
    private DataSource dataSource; // connection pool (e.g. HikariCP)
    
    public ShiftDAO(DataSource dataSource) {
        this.dataSource = dataSource;
    }
    
    public Shift openShift(int cashierId, BigDecimal openingFloat) throws SQLException {
        String sql = "INSERT INTO shifts (cashier_id, start_time, opening_cash_float, status) "
                   + "VALUES (?, ?, ?, 'OPEN')";
        
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {
            
            ps.setInt(1, cashierId);
            ps.setTimestamp(2, Timestamp.valueOf(LocalDateTime.now()));
            ps.setBigDecimal(3, openingFloat);
            ps.executeUpdate();
            
            try (ResultSet keys = ps.getGeneratedKeys()) {
                if (keys.next()) {
                    int shiftId = keys.getInt(1);
                    return findShiftById(shiftId); // reload full object
                }
            }
        }
        throw new SQLException("Shift ဖန်တီးလို့ မရပါ");
    }
    
    public void closeShift(int shiftId, BigDecimal closingCash, BigDecimal expected, BigDecimal variance) 
            throws SQLException {
        String sql = "UPDATE shifts SET end_time = ?, closing_cash_counted = ?, "
                   + "expected_cash = ?, variance = ?, status = 'CLOSED' WHERE shift_id = ?";
        
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            
            ps.setTimestamp(1, Timestamp.valueOf(LocalDateTime.now()));
            ps.setBigDecimal(2, closingCash);
            ps.setBigDecimal(3, expected);
            ps.setBigDecimal(4, variance);
            ps.setInt(5, shiftId);
            ps.executeUpdate();
        }
    }
    
    public Shift findShiftById(int shiftId) throws SQLException {
        String sql = "SELECT * FROM shifts WHERE shift_id = ?";
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            
            ps.setInt(1, shiftId);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return mapRowToShift(rs);
                }
            }
        }
        return null;
    }
    
    // App startup မှာ "open ထားတဲ့ shift ရှိသေးလား" စစ်ဖို့
    public Shift findOpenShiftForCashier(int cashierId) throws SQLException {
        String sql = "SELECT * FROM shifts WHERE cashier_id = ? AND status = 'OPEN' LIMIT 1";
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            
            ps.setInt(1, cashierId);
            try (ResultSet rs = ps.executeQuery()) {
                return rs.next() ? mapRowToShift(rs) : null;
            }
        }
        return null;
    }
    
    private Shift mapRowToShift(ResultSet rs) throws SQLException {
        Shift shift = new Shift();
        shift.setShiftId(rs.getInt("shift_id"));
        shift.setStartTime(rs.getTimestamp("start_time").toLocalDateTime());
        Timestamp end = rs.getTimestamp("end_time");
        shift.setEndTime(end != null ? end.toLocalDateTime() : null);
        shift.setOpeningCashFloat(rs.getBigDecimal("opening_cash_float"));
        shift.setStatus(ShiftStatus.valueOf(rs.getString("status")));
        return shift;
    }
}
```

**အရေးကြီးတဲ့ point တွေ**:

- **PreparedStatement** ကိုပဲ သုံးပါ — string concatenation နဲ့ SQL ရေးရင် SQL injection risk ရှိတယ်
- **try-with-resources** သုံးထားတာ Connection/PreparedStatement/ResultSet တွေကို auto-close လုပ်ဖို့ (memory leak မဖြစ်အောင်)
- `findOpenShiftForCashier()` က အရေးကြီးတယ် — app crash သွားလို့ shift ကို close မလုပ်ရသေးရင်၊ login ပြန်ဝင်တဲ့အခါ "open shift ရှိနေသေးတယ်" ဆိုတာကို detect လုပ်ပြီး ဆက်သုံးလို့ရအောင်

## ၃. Connection Pool သုံးရမယ့်အကြောင်း

`DriverManager.getConnection()` ကို operation တိုင်းအတွက် အသစ်ခေါ်နေရင် connection ဖွင့်/ပိတ်တာက slow ဖြစ်တယ်။ **HikariCP** လို connection pool library သုံးရင် connection ကို reuse လုပ်ပေးတယ်:

```xml
<!-- pom.xml -->
<dependency>
    <groupId>com.zaxxer</groupId>
    <artifactId>HikariCP</artifactId>
    <version>5.1.0</version>
</dependency>
```

```java
HikariConfig config = new HikariConfig();
config.setJdbcUrl("jdbc:mysql://localhost:3306/cafe_pos");
config.setUsername("root");
config.setPassword("yourpassword");
config.setMaximumPoolSize(10);
DataSource dataSource = new HikariDataSource(config);
```

## ၄. SessionManager ထဲမှာ DAO ကို ချိတ်ပုံ

```java
public class SessionManager {
    private User currentUser;
    private Shift currentShift;
    private ShiftDAO shiftDAO;
    
    public void login(User user) {
        this.currentUser = user;
    }
    
    public void openShift(BigDecimal openingFloat) throws SQLException {
        Shift shift = shiftDAO.openShift(currentUser.getUserId(), openingFloat);
        this.currentShift = shift;
    }
    
    public ShiftSummary closeShift(BigDecimal closingCashCounted) throws SQLException {
        BigDecimal totalSales = getSalesDAO().getTotalSalesForShift(currentShift.getShiftId());
        BigDecimal expected = currentShift.getOpeningCashFloat().add(totalSales);
        BigDecimal variance = closingCashCounted.subtract(expected);
        
        shiftDAO.closeShift(currentShift.getShiftId(), closingCashCounted, expected, variance);
        
        ShiftSummary summary = new ShiftSummary(currentShift, expected, variance);
        this.currentShift = null;
        return summary;
    }
    
    // App startup / login အချိန်မှာ "ဆက်သုံးရမလား" စစ်ဖို့
    public void resumeOpenShiftIfExists() throws SQLException {
        Shift existing = shiftDAO.findOpenShiftForCashier(currentUser.getUserId());
        if (existing != null) {
            this.currentShift = existing;
        }
    }
}
```

Login flow မှာ:

```java
SessionManager.getInstance().login(authenticatedUser);
SessionManager.getInstance().resumeOpenShiftIfExists();

if (SessionManager.getInstance().getCurrentShift() == null) {
    showOpenShiftDialog(); // shift အသစ်ဖွင့်ခိုင်း
} else {
    showResumedShiftNotice(); // "Shift #23 ကို ဆက်လက်အသုံးပြုနေပါသည်"
}
```

## ၅. Data Integrity — Transaction သုံးရမယ့်အချိန်

Shift ပိတ်တဲ့အချိန်မှာ operation တစ်ခုထက်ပိုပြီး database ကို write လုပ်ရင် (ဥပမာ - shift update + report table ထဲ insert), **atomic** ဖြစ်ဖို့ transaction သုံးသင့်တယ်:

```java
public void closeShiftWithReport(int shiftId, BigDecimal closingCash, ...) throws SQLException {
    try (Connection conn = dataSource.getConnection()) {
        conn.setAutoCommit(false);
        try {
            // 1. shifts table update
            updateShiftRecord(conn, shiftId, closingCash, ...);
            // 2. shift_reports table insert
            insertShiftReport(conn, shiftId, ...);
            
            conn.commit();
        } catch (SQLException e) {
            conn.rollback();
            throw e;
        }
    }
}
```

Operation တစ်ခုလုပ်တုန်း ကြားထဲမှာ error တက်ရင်, အားလုံး rollback ဖြစ်သွားမယ် — data inconsistent ဖြစ်ခြင်း (shift ပိတ်ပေမယ့် report မရှိတာမျိုး) မဖြစ်အောင် ကာကွယ်ပေးတယ်။
