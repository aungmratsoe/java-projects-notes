# WebSocket Server (Backend) — Spring Boot နဲ့ Setup လုပ်နည်း

## Dependency ထည့်ခြင်း (Maven)

Spring Boot project မှာ WebSocket support အတွက် dependency ထည့်ရပါမယ်:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-websocket</artifactId>
</dependency>
```

## WebSocket Setup — ၂ မျိုးရွေးလို့ရပါတယ်

Spring မှာ WebSocket implement လုပ်ဖို့ approach ၂ ခုရှိပါတယ်:

1. **Raw WebSocket** (`WebSocketHandler`) — low-level, simple message ပို့ချင်ရင်
2. **STOMP over WebSocket** — pub/sub pattern, chat/notification app တွေအတွက် popular

ရိုးရှင်းအောင် **Raw WebSocket** ကနေစပြီး ရှင်းပြပေးမယ်။

## Step 1: WebSocket Configuration Class

```java
import org.springframework.context.annotation.Configuration;
import org.springframework.web.socket.config.annotation.EnableWebSocket;
import org.springframework.web.socket.config.annotation.WebSocketConfigurer;
import org.springframework.web.socket.config.annotation.WebSocketHandlerRegistry;

@Configuration
@EnableWebSocket
public class WebSocketConfig implements WebSocketConfigurer {

    @Override
    public void registerWebSocketHandlers(WebSocketHandlerRegistry registry) {
        registry.addHandler(new StockPriceHandler(), "/stock-stream")
                .setAllowedOrigins("*"); // production မှာ specific origin ပဲ ခွင့်ပြုသင့်
    }
}
```

## Step 2: WebSocket Handler (Server Logic)

```java
import org.springframework.web.socket.*;
import org.springframework.web.socket.handler.TextWebSocketHandler;
import java.util.concurrent.CopyOnWriteArrayList;

public class StockPriceHandler extends TextWebSocketHandler {

    // Connect ထားတဲ့ client (session) အားလုံးကို track လုပ်ဖို့
    private static final CopyOnWriteArrayList<WebSocketSession> sessions = 
            new CopyOnWriteArrayList<>();

    // Client connect ဖြစ်တဲ့အခါ run
    @Override
    public void afterConnectionEstablished(WebSocketSession session) throws Exception {
        sessions.add(session);
        System.out.println("Client connected: " + session.getId());
    }

    // Client ကနေ message ရောက်လာတဲ့အခါ run
    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) 
            throws Exception {
        String payload = message.getPayload();
        System.out.println("Received: " + payload);

        // ဥပမာ - client က subscribe request ပို့ရင် acknowledge ပြန်ပို့
        session.sendMessage(new TextMessage("Subscribed successfully"));
    }

    // Client disconnect ဖြစ်တဲ့အခါ run
    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) 
            throws Exception {
        sessions.remove(session);
        System.out.println("Client disconnected: " + session.getId());
    }

    // ဒီ method ကို server ရဲ့ တခြားနေရာ (ဥပမာ - scheduled task) ကနေ ခေါ်ပြီး
    // client အားလုံးဆီ broadcast လုပ်နိုင်ပါတယ်
    public static void broadcastToAll(String message) {
        for (WebSocketSession session : sessions) {
            try {
                if (session.isOpen()) {
                    session.sendMessage(new TextMessage(message));
                }
            } catch (Exception e) {
                e.printStackTrace();
            }
        }
    }
}
```

## Step 3: Real-Time Data Push (Scheduled Task ဥပမာ)

Stock price လို data ကို periodically update ပြီး client တွေဆီ broadcast လုပ်ချင်ရင်:

```java
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;
import java.util.Random;

@Component
public class StockPriceBroadcaster {

    private final Random random = new Random();

    @Scheduled(fixedRate = 3000) // ၃ စက္ကန့်တစ်ခါ run
    public void pushPriceUpdate() {
        double price = 100 + random.nextDouble() * 10;
        String message = String.format("{\"symbol\":\"AAPL\",\"price\":%.2f}", price);
        StockPriceHandler.broadcastToAll(message);
    }
}
```

Main application class မှာ `@EnableScheduling` ထည့်ဖို့ မမေ့ပါနဲ့:

```java
@SpringBootApplication
@EnableScheduling
public class WebSocketDemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(WebSocketDemoApplication.class, args);
    }
}
```

## STOMP Approach (Alternative — Chat App အတွက် ပိုအသင့်တော်)

Chat application လို client အများကြီးကို "topic" (channel) အလိုက် message ပို့ချင်ရင် **STOMP + SockJS** ကို သုံးလေ့ရှိပါတယ်:

```java
import org.springframework.context.annotation.Configuration;
import org.springframework.messaging.simp.config.MessageBrokerRegistry;
import org.springframework.web.socket.config.annotation.*;

@Configuration
@EnableWebSocketMessageBroker
public class StompConfig implements WebSocketMessageBrokerConfigurer {

    @Override
    public void configureMessageBroker(MessageBrokerRegistry config) {
        config.enableSimpleBroker("/topic"); // client တွေ subscribe လုပ်မယ့် prefix
        config.setApplicationDestinationPrefixes("/app"); // client ပို့မယ့် prefix
    }

    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        registry.addEndpoint("/ws").setAllowedOrigins("*").withSockJS();
    }
}
```

```java
@Controller
public class ChatController {

    @MessageMapping("/chat.send")       // client က /app/chat.send ကို ပို့ရင်
    @SendTo("/topic/messages")          // /topic/messages ကို subscribe လုပ်ထားသူအားလုံးဆီ ပြန်ပို့
    public String sendMessage(String message) {
        return message;
    }
}
```

## Raw WebSocket vs STOMP — ဘယ်အချိန်သုံးမလဲ

||Raw WebSocket|STOMP|
|---|---|---|
|Setup|ရိုးရှင်း|ပိုရှုပ်ထွေး (broker concept)|
|Use case|Simple stream (stock price, single-purpose)|Multi-channel messaging (chat rooms, topics)|
|Message routing|Manual (code ထဲမှာ handle)|Built-in (`@MessageMapping`, `@SendTo`)|
|Client library|Java-WebSocket (Swing ဘက်)|STOMP.js (web) / stomp client (Java)|

Swing client (Java-WebSocket library) နဲ့ ချိတ်ဆက်မယ်ဆိုရင် **Raw WebSocket** approach ကို သုံးတာ ပိုရိုးရှင်းပါတယ် — STOMP protocol ကို Java client ဘက်က handle လုပ်ဖို့ ပိုရှုပ်ထွေးလို့ပါ။

## Security အကြောင်း အနည်းငယ်

Production မှာ WebSocket endpoint ကို authentication check လုပ်ချင်ရင် `HandshakeInterceptor` ကို သုံးနိုင်ပါတယ်:

```java
registry.addHandler(new StockPriceHandler(), "/stock-stream")
        .addInterceptors(new AuthHandshakeInterceptor())
        .setAllowedOrigins("*");
```

`AuthHandshakeInterceptor` ထဲမှာ token validate လုပ်ပြီး connection ကို accept/reject လုပ်နိုင်ပါတယ်။

ဒါက backend (Spring) ဘက်ကနေ ကြည့်ရင် WebSocket server setup အခြေခံပါ။ Swing client (ရှေ့မှာ ရေးပြီးသား `StockPriceClient`) ကို ဒီ server နဲ့ တကယ်ချိတ်ပြီး end-to-end test လုပ်ကြည့်ချင်ရင် ပြောပါ — connection URL ချိန်ညှိပေးပြီး full flow ရှင်းပြပေးနိုင်ပါတယ်။
