# WebSocket API — Java Swing App မှာ အသုံးပြုနည်း

## Concept ပြန်သုံးသပ်ချက်

REST API က request/response တစ်ခါချင်း ဖြစ်ပေမယ့် WebSocket က connection ကို **ဖွင့်ထားခဲ့ပြီး** server ဘက်က event ဖြစ်တိုင်း client ဆီ **push** လုပ်နိုင်ပါတယ်။ Swing app အနေနဲ့ ဆိုရင် live chat, real-time price update, notification စတာတွေအတွက် အသုံးဝင်ပါတယ်။

## Library ရွေးချယ်ခြင်း

Java မှာ WebSocket client implement လုပ်ဖို့ popular library က **Java-WebSocket** (org.java_websocket) ဖြစ်ပါတယ်။

```xml
<dependency>
    <groupId>org.java-websocket</groupId>
    <artifactId>Java-WebSocket</artifactId>
    <version>1.5.6</version>
</dependency>
```

## WebSocket Client Class ဖန်တီးခြင်း

```java
import org.java_websocket.client.WebSocketClient;
import org.java_websocket.handshake.ServerHandshake;
import java.net.URI;
import javax.swing.SwingUtilities;

public class StockPriceClient extends WebSocketClient {

    private final PriceUpdateListener listener;

    // Callback interface — UI ကို notify လုပ်ဖို့
    public interface PriceUpdateListener {
        void onPriceUpdate(String message);
        void onConnected();
        void onDisconnected();
        void onError(String error);
    }

    public StockPriceClient(URI serverUri, PriceUpdateListener listener) {
        super(serverUri);
        this.listener = listener;
    }

    // Connection ဖွင့်အောင်မြင်တဲ့အခါ run
    @Override
    public void onOpen(ServerHandshake handshake) {
        // ဒီ method က WebSocket thread ပေါ်မှာ run ပါတယ်
        // Swing UI update လုပ်ချင်ရင် SwingUtilities.invokeLater() လိုအပ်
        SwingUtilities.invokeLater(() -> listener.onConnected());
    }

    // Server ကနေ message ရောက်လာတဲ့အခါ run (ဒါက main event)
    @Override
    public void onMessage(String message) {
        SwingUtilities.invokeLater(() -> listener.onPriceUpdate(message));
    }

    // Connection ပြတ်တဲ့အခါ run
    @Override
    public void onClose(int code, String reason, boolean remote) {
        SwingUtilities.invokeLater(() -> listener.onDisconnected());
    }

    // Error ဖြစ်တဲ့အခါ run
    @Override
    public void onError(Exception ex) {
        SwingUtilities.invokeLater(() -> listener.onError(ex.getMessage()));
    }
}
```

## အရေးကြီးတဲ့ Point — Thread Safety

WebSocket library ရဲ့ callback methods (`onMessage`, `onOpen`, etc.) တွေဟာ **WebSocket ရဲ့ ကိုယ်ပိုင် thread** ပေါ်မှာ run ပါတယ် — Swing EDT မဟုတ်ပါ။ ဒါကြောင့် UI component (JLabel, JTable) ကို update လုပ်ချင်ရင် **`SwingUtilities.invokeLater()`** နဲ့ ပေါ်ပါတဲ့အတိုင်း wrap ချရပါမယ်။ မလုပ်ရင် thread-safety violation ဖြစ်ပြီး UI bug (flickering, exception) ဖြစ်နိုင်ပါတယ်။

## Swing Form ထဲမှာ ချိတ်ဆက်အသုံးပြုခြင်း

```java
import javax.swing.*;
import java.net.URI;

public class StockTickerFrame extends JFrame 
        implements StockPriceClient.PriceUpdateListener {

    private JLabel priceLabel;
    private JLabel statusLabel;
    private JButton connectButton;
    private StockPriceClient wsClient;

    public StockTickerFrame() {
        priceLabel = new JLabel("Price: --");
        statusLabel = new JLabel("Disconnected");
        connectButton = new JButton("Connect");

        connectButton.addActionListener(e -> connectToServer());

        // ... layout setup (GUI Builder ကနေ auto-generate ဖြစ်နိုင်)
    }

    private void connectToServer() {
        try {
            URI serverUri = new URI("wss://example.com/stock-stream");
            wsClient = new StockPriceClient(serverUri, this);
            wsClient.connect(); // asynchronous — background thread မှာ connect
            statusLabel.setText("Connecting...");
            connectButton.setEnabled(false);
        } catch (Exception e) {
            JOptionPane.showMessageDialog(this, 
                    "Invalid server URL: " + e.getMessage());
        }
    }

    // Interface method များ — ဒီမှာ UI update လုပ်ရုံပါပဲ
    // (invokeLater ထဲက ခေါ်ထားပြီးသားမို့ ဒီနေရာမှာ UI touch လုပ်လို့ ရပါပြီ)
    @Override
    public void onPriceUpdate(String message) {
        priceLabel.setText("Price: " + message);
    }

    @Override
    public void onConnected() {
        statusLabel.setText("Connected");
    }

    @Override
    public void onDisconnected() {
        statusLabel.setText("Disconnected");
        connectButton.setEnabled(true);
    }

    @Override
    public void onError(String error) {
        statusLabel.setText("Error: " + error);
        connectButton.setEnabled(true);
    }

    // App ပိတ်တဲ့အခါ connection ကို clean up
    @Override
    public void dispose() {
        if (wsClient != null && wsClient.isOpen()) {
            wsClient.close();
        }
        super.dispose();
    }
}
```

## Message ပို့ခြင်း (Client → Server)

```java
JButton sendButton = new JButton("Subscribe to AAPL");
sendButton.addActionListener(e -> {
    if (wsClient != null && wsClient.isOpen()) {
        wsClient.send("{\"action\":\"subscribe\",\"symbol\":\"AAPL\"}");
    } else {
        JOptionPane.showMessageDialog(this, "Not connected to server");
    }
});
```

## Reconnection Logic (Connection ပြတ်ရင် ပြန်ချိတ်ခြင်း)

Real app တွေမှာ network fluctuation ကြောင့် connection ပြတ်တတ်လို့ auto-reconnect logic ထည့်ဖို့ အရေးကြီးပါတယ်:

```java
@Override
public void onClose(int code, String reason, boolean remote) {
    SwingUtilities.invokeLater(() -> {
        listener.onDisconnected();
        if (remote) { // server ဘက်က ပြတ်သွားရင်
            Timer reconnectTimer = new Timer(5000, evt -> connectToServer());
            reconnectTimer.setRepeats(false);
            reconnectTimer.start();
        }
    });
}
```

## REST vs WebSocket — Swing App မှာ ဘယ်အချိန်သုံးမလဲ

|Scenario|Recommendation|
|---|---|
|User action based data (search, form submit)|REST API|
|Live price/notification/chat|WebSocket|
|App စတင်တဲ့အခါ data တစ်ခါတည်း load|REST API|
|Server-initiated update (client ကမတောင်းဘဲ push)|WebSocket|
