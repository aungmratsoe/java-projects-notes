# `SOAPConnection` API — Raw SOAP Request ကို Java ကနေ တည်ဆောက်ခြင်း

## ဘယ်အခါ ဒီ Approach သုံးလဲ

`wsimport` (WSDL auto-generate) က convenient ဖြစ်ပေမယ့် တခါတလေ:

- WSDL file မရှိဘူး ဒါမှမဟုတ် access မရဘူး
- SOAP message structure ကို manual control လိုချင်တယ်
- Simple/one-off SOAP call ဖြစ်လို့ code generation setup မလိုချင်ဘူး

ဒီလိုအခါမျိုးမှာ **`SOAPConnection`** (javax.xml.soap / jakarta.xml.soap package) ကို တိုက်ရိုက်သုံးပြီး SOAP envelope ကို manually build လို့ရပါတယ်။

## Step-by-Step: SOAP Request ဖန်တီးခြင်း

### Step 1: SOAPConnection ဖန်တီးခြင်း

```java
import jakarta.xml.soap.*;

SOAPConnectionFactory soapConnectionFactory = SOAPConnectionFactory.newInstance();
SOAPConnection soapConnection = soapConnectionFactory.createConnection();
```

### Step 2: SOAP Message (Envelope) Build လုပ်ခြင်း

```java
import jakarta.xml.soap.*;

MessageFactory messageFactory = MessageFactory.newInstance();
SOAPMessage soapMessage = messageFactory.createMessage();

SOAPPart soapPart = soapMessage.getSOAPPart();
SOAPEnvelope envelope = soapPart.getEnvelope();

// Namespace prefix သတ်မှတ်ခြင်း (WSDL/service documentation ကို ကြည့်ပြီး ချိန်ညှိပါ)
envelope.addNamespaceDeclaration("web", "http://example.com/webservice");

// --- SOAP Body ဖန်တီးခြင်း ---
SOAPBody soapBody = envelope.getBody();
SOAPElement soapBodyElem = soapBody.addChildElement("GetUser", "web");
SOAPElement soapBodyElem1 = soapBodyElem.addChildElement("UserId", "web");
soapBodyElem1.addTextNode("123");

// --- SOAP Header (optional — authentication လိုအပ်ရင်) ---
SOAPHeader soapHeader = envelope.getHeader();
SOAPElement authHeader = soapHeader.addChildElement("Authentication", "web");
SOAPElement tokenElem = authHeader.addChildElement("Token", "web");
tokenElem.addTextNode("your-auth-token-here");

// --- HTTP header ထည့်ခြင်း (SOAPAction — service အလိုက် လိုအပ်ချက် ကွာနိုင်) ---
MimeHeaders headers = soapMessage.getMimeHeaders();
headers.addHeader("SOAPAction", "http://example.com/webservice/GetUser");

soapMessage.saveChanges();
```

ဒါက build လုပ်ထားတဲ့ SOAP message ရဲ့ XML structure (ကြည့်ချင်ရင် `soapMessage.writeTo()` နဲ့ print လို့ရ):

```xml
<soap:Envelope xmlns:soap="http://www.w3.org/2003/05/soap-envelope" xmlns:web="http://example.com/webservice">
  <soap:Header>
    <web:Authentication>
      <web:Token>your-auth-token-here</web:Token>
    </web:Authentication>
  </soap:Header>
  <soap:Body>
    <web:GetUser>
      <web:UserId>123</web:UserId>
    </web:GetUser>
  </soap:Body>
</soap:Envelope>
```

### Step 3: Request ပို့ခြင်းနဲ့ Response လက်ခံခြင်း

```java
String endpointUrl = "http://example.com/soap-service";
SOAPMessage soapResponse = soapConnection.call(soapMessage, endpointUrl);

// Response ကို print/parse လုပ်ခြင်း
soapResponse.writeTo(System.out);
```

### Step 4: Response ထဲက Data ကို Parse ခြင်း

```java
SOAPBody responseBody = soapResponse.getSOAPBody();

// Fault check — အရင်ဆုံး error ရှိမရှိ စစ်ရပါမယ်
if (responseBody.hasFault()) {
    SOAPFault fault = responseBody.getFault();
    System.out.println("SOAP Fault: " + fault.getFaultString());
} else {
    // Response XML ထဲက value ကို extract လုပ်ခြင်း
    NodeList nameNodes = responseBody.getElementsByTagName("Name");
    if (nameNodes.getLength() > 0) {
        String userName = nameNodes.item(0).getTextContent();
        System.out.println("User Name: " + userName);
    }
}

soapConnection.close();
```

## အားလုံးပေါင်း — Complete Method

```java
import jakarta.xml.soap.*;
import org.w3c.dom.NodeList;

public class SoapClient {

    public static String getUserName(int userId) throws Exception {
        SOAPConnectionFactory soapConnectionFactory = SOAPConnectionFactory.newInstance();
        SOAPConnection soapConnection = soapConnectionFactory.createConnection();

        try {
            MessageFactory messageFactory = MessageFactory.newInstance();
            SOAPMessage soapMessage = messageFactory.createMessage();

            SOAPEnvelope envelope = soapMessage.getSOAPPart().getEnvelope();
            envelope.addNamespaceDeclaration("web", "http://example.com/webservice");

            SOAPBody soapBody = envelope.getBody();
            SOAPElement getUserElem = soapBody.addChildElement("GetUser", "web");
            getUserElem.addChildElement("UserId", "web").addTextNode(String.valueOf(userId));

            MimeHeaders headers = soapMessage.getMimeHeaders();
            headers.addHeader("SOAPAction", "http://example.com/webservice/GetUser");
            soapMessage.saveChanges();

            SOAPMessage response = soapConnection.call(soapMessage,
                    "http://example.com/soap-service");

            SOAPBody responseBody = response.getSOAPBody();
            if (responseBody.hasFault()) {
                throw new RuntimeException("SOAP Fault: " 
                        + responseBody.getFault().getFaultString());
            }

            NodeList nameNodes = responseBody.getElementsByTagName("Name");
            if (nameNodes.getLength() == 0) {
                throw new RuntimeException("Name field not found in response");
            }
            return nameNodes.item(0).getTextContent();

        } finally {
            soapConnection.close(); // connection ကို ပိတ်ဖို့ မမေ့ပါနဲ့
        }
    }
}
```

## Swing App မှာ SwingWorker ထဲ ချိတ်ဆက်ခြင်း

```java
public class SoapUserWorker extends SwingWorker<String, Void> {
    private final int userId;
    private final JLabel resultLabel;

    public SoapUserWorker(int userId, JLabel resultLabel) {
        this.userId = userId;
        this.resultLabel = resultLabel;
    }

    @Override
    protected String doInBackground() throws Exception {
        return SoapClient.getUserName(userId); // SOAPConnection call ဒီမှာ
    }

    @Override
    protected void done() {
        try {
            String name = get();
            resultLabel.setText("User: " + name);
        } catch (Exception e) {
            resultLabel.setText("Error: " + e.getMessage());
        }
    }
}
```

## `wsimport` (auto-generate) vs `SOAPConnection` (manual) — ဘယ်အချိန်သုံးမလဲ

||wsimport (JAX-WS stub)|SOAPConnection (manual)|
|---|---|---|
|WSDL လိုအပ်မှု|Required|မလိုအပ်|
|Type safety|Strong (compile-time check)|Weak (XML string manual build)|
|Setup effort|Code generation step လိုအပ်|Dependency ထည့်ရုံနဲ့ ချက်ချင်းစလို့ရ|
|Maintainability|ပိုကောင်း (service change ရင် stub ပြန် generate)|Manual update ရ|
|Use case|Well-documented enterprise service|Quick test, WSDL မရ, custom control လိုအပ်|

Production project တွေမှာတော့ WSDL ရှိရင် **wsimport** approach ကို ပိုအကြံပြုပါတယ် — type safety နဲ့ maintainability ပိုကောင်းလို့ပါ။ `SOAPConnection` ကတော့ WSDL မရရင် ဒါမှမဟုတ် quick prototype အတွက် သင့်တော်ပါတယ်။
