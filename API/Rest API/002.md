# Swing App မှာ REST API ကို SwingWorker နဲ့ ခေါ်ခြင်း

## ဘာလို့ SwingWorker လိုအပ်လဲ

Swing app တွေမှာ **Event Dispatch Thread (EDT)** ဆိုတာ UI update အားလုံးကို handle လုပ်တဲ့ thread ဖြစ်ပါတယ်။ REST API call (network request) ဟာ **time ကြာနိုင်တဲ့ operation** ဖြစ်လို့ EDT ပေါ်မှာ တိုက်ရိုက်လုပ်ရင် **UI freeze** (windows lock, button ကလစ်မရ) ဖြစ်သွားပါတယ်။

ဒါကို ဖြေရှင်းဖို့ **SwingWorker** ကို သုံးပြီး API call ကို background thread မှာ run ပါတယ်၊ ပြီးရင် result ကို EDT ဆီပြန်ပို့ပြီး UI update လုပ်ပါတယ်။

## Code ဥပမာ — User List ကို JTable မှာ ပြခြင်း

```java
import javax.swing.*;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.List;
import java.util.concurrent.ExecutionException;

public class UserFetchWorker extends SwingWorker<List<User>, Void> {

    private final JTable table;
    private final JLabel statusLabel;

    public UserFetchWorker(JTable table, JLabel statusLabel) {
        this.table = table;
        this.statusLabel = statusLabel;
    }

    // ၁။ doInBackground() — background thread မှာ run (network call ဒီမှာ)
    @Override
    protected List<User> doInBackground() throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.example.com/users"))
                .GET()
                .build();

        HttpResponse<String> response = client.send(request,
                HttpResponse.BodyHandlers.ofString());

        ObjectMapper mapper = new ObjectMapper();
        return mapper.readValue(response.body(),
                mapper.getTypeFactory().constructCollectionType(List.class, User.class));
    }

    // ၂။ done() — EDT ပေါ်ပြန်ရောက်လာတဲ့အခါ run (UI update ဒီမှာ)
    @Override
    protected void done() {
        try {
            List<User> users = get(); // doInBackground ရဲ့ result ကို ရယူ
            
            DefaultTableModel model = new DefaultTableModel(
                    new Object[]{"ID", "Name", "Email"}, 0);
            for (User u : users) {
                model.addRow(new Object[]{u.getId(), u.getName(), u.getEmail()});
            }
            table.setModel(model);
            statusLabel.setText("Loaded " + users.size() + " users");

        } catch (InterruptedException | ExecutionException e) {
            statusLabel.setText("Error: " + e.getMessage());
            JOptionPane.showMessageDialog(null,
                    "API Error: " + e.getMessage(),
                    "Error", JOptionPane.ERROR_MESSAGE);
        }
    }
}
```

## User Model Class (Jackson အတွက်)

```java
public class User {
    private int id;
    private String name;
    private String email;

    // Getter/Setter (Jackson မှာ လိုအပ်)
    public int getId() { return id; }
    public void setId(int id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
}
```

## Button Click ကနေ Worker ကို Trigger လုပ်ခြင်း

```java
JButton loadButton = new JButton("Load Users");
loadButton.addActionListener(e -> {
    statusLabel.setText("Loading...");
    loadButton.setEnabled(false); // double-click ကာကွယ်

    UserFetchWorker worker = new UserFetchWorker(userTable, statusLabel);
    worker.execute(); // ဒီမှာ doInBackground() စလုပ်

    // Worker ပြီးတာနဲ့ button ပြန်ဖွင့်ချင်ရင် PropertyChangeListener သုံးနိုင်
    worker.addPropertyChangeListener(evt -> {
        if ("state".equals(evt.getPropertyName()) 
                && SwingWorker.StateValue.DONE == evt.getNewValue()) {
            loadButton.setEnabled(true);
        }
    });
});
```

## SwingWorker ရဲ့ Flow အကျဉ်းချုပ်

|Method|Run လုပ်တဲ့ Thread|Purpose|
|---|---|---|
|`doInBackground()`|Background thread|Network call, heavy computation|
|`process()` (optional)|EDT|Progress update (partial result)|
|`done()`|EDT|Final UI update, error handling|

## အရေးကြီးတဲ့ Point များ

1. **`doInBackground()` ထဲမှာ UI component (JTable, JLabel) ကို တိုက်ရိုက် touch လုပ်ခြင်း မလုပ်ရ** — thread-safety ပျက်နိုင်ပါတယ်
2. **`done()` ထဲမှာပဲ UI update လုပ်ပါ** — SwingWorker က `done()` ကို EDT ပေါ်မှာ auto-run ပေးပါတယ်
3. **Error handling** — `get()` က `ExecutionException` throw နိုင်လို့ try-catch မလွတ်ပါစေနဲ့
4. **Timeout သတ်မှတ်ချင်ရင်** `HttpRequest.newBuilder().timeout(Duration.ofSeconds(10))` ထည့်နိုင်ပါတယ်
