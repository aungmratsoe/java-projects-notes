# Third-Party API ဥပမာ — Weather Application (OpenWeatherMap)

## OpenWeatherMap API အကြောင်း

**OpenWeatherMap** ဆိုတာ free tier ပါတဲ့ popular weather REST API တစ်ခုဖြစ်ပါတယ်။ Account register လုပ်ပြီး free **API key** ရယူရပါမယ် (https://openweathermap.org/api).

## API Endpoint ဥပမာ

```
GET https://api.openweathermap.org/data/2.5/weather?q=Yangon&appid=YOUR_API_KEY&units=metric
```

**Response (JSON):**

```json
{
  "weather": [
    { "main": "Clouds", "description": "scattered clouds" }
  ],
  "main": {
    "temp": 32.5,
    "feels_like": 38.2,
    "humidity": 65
  },
  "name": "Yangon"
}
```

## Model Classes (Jackson အတွက်)

```java
public class WeatherResponse {
    private List<Weather> weather;
    private Main main;
    private String name;

    public List<Weather> getWeather() { return weather; }
    public void setWeather(List<Weather> weather) { this.weather = weather; }
    public Main getMain() { return main; }
    public void setMain(Main main) { this.main = main; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}

public class Weather {
    private String main;
    private String description;

    public String getMain() { return main; }
    public void setMain(String main) { this.main = main; }
    public String getDescription() { return description; }
    public void setDescription(String description) { this.description = description; }
}

public class Main {
    private double temp;
    @JsonProperty("feels_like")
    private double feelsLike;
    private int humidity;

    public double getTemp() { return temp; }
    public void setTemp(double temp) { this.temp = temp; }
    public double getFeelsLike() { return feelsLike; }
    public void setFeelsLike(double feelsLike) { this.feelsLike = feelsLike; }
    public int getHumidity() { return humidity; }
    public void setHumidity(int humidity) { this.humidity = humidity; }
}
```

> **Note:** JSON field name (`feels_like`) နဲ့ Java field name (`feelsLike`) မတူရင် `@JsonProperty` annotation ထည့်ပေးရပါတယ်။

## SwingWorker — Weather Fetch Logic

```java
import javax.swing.*;
import java.net.URI;
import java.net.URLEncoder;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import com.fasterxml.jackson.databind.ObjectMapper;

public class WeatherFetchWorker extends SwingWorker<WeatherResponse, Void> {

    private static final String API_KEY = "YOUR_API_KEY";
    private final String cityName;
    private final JLabel resultLabel;
    private final JLabel statusLabel;

    public WeatherFetchWorker(String cityName, JLabel resultLabel, JLabel statusLabel) {
        this.cityName = cityName;
        this.resultLabel = resultLabel;
        this.statusLabel = statusLabel;
    }

    @Override
    protected WeatherResponse doInBackground() throws Exception {
        String encodedCity = URLEncoder.encode(cityName, StandardCharsets.UTF_8);
        String url = String.format(
            "https://api.openweathermap.org/data/2.5/weather?q=%s&appid=%s&units=metric",
            encodedCity, API_KEY
        );

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(url))
                .GET()
                .build();

        HttpResponse<String> response = client.send(request,
                HttpResponse.BodyHandlers.ofString());

        // 200 မဟုတ်ရင် error (ဥပမာ - city မတွေ့, API key မှား)
        if (response.statusCode() != 200) {
            throw new RuntimeException("API Error: " + response.statusCode() 
                    + " - " + response.body());
        }

        ObjectMapper mapper = new ObjectMapper();
        return mapper.readValue(response.body(), WeatherResponse.class);
    }

    @Override
    protected void done() {
        try {
            WeatherResponse weather = get();
            String description = weather.getWeather().get(0).getDescription();
            double temp = weather.getMain().getTemp();
            int humidity = weather.getMain().getHumidity();

            resultLabel.setText(String.format(
                "<html>%s<br>Temperature: %.1f°C<br>Condition: %s<br>Humidity: %d%%</html>",
                weather.getName(), temp, description, humidity
            ));
            statusLabel.setText("Updated successfully");

        } catch (Exception e) {
            statusLabel.setText("Error: City not found or network issue");
            JOptionPane.showMessageDialog(null,
                    "Weather fetch failed: " + e.getMessage(),
                    "Error", JOptionPane.ERROR_MESSAGE);
        }
    }
}
```

## Search Button Integration

```java
JTextField cityInput = new JTextField(15);
JButton searchButton = new JButton("Search");
JLabel resultLabel = new JLabel(" ");
JLabel statusLabel = new JLabel(" ");

searchButton.addActionListener(e -> {
    String city = cityInput.getText().trim();
    if (city.isEmpty()) {
        JOptionPane.showMessageDialog(null, "Please enter a city name");
        return;
    }

    statusLabel.setText("Loading...");
    searchButton.setEnabled(false);

    WeatherFetchWorker worker = new WeatherFetchWorker(city, resultLabel, statusLabel);
    worker.addPropertyChangeListener(evt -> {
        if ("state".equals(evt.getPropertyName())
                && SwingWorker.StateValue.DONE == evt.getNewValue()) {
            searchButton.setEnabled(true);
        }
    });
    worker.execute();
});
```

## API Key ကို Hardcode မလုပ်ဘဲ Secure ထားနည်း

Production app မှာ API key ကို code ထဲမှာ တိုက်ရိုက် ထည့်မထားသင့်ပါ (GitHub push လုပ်ရင် leak ဖြစ်နိုင်)။

```java
// properties file ကနေ load လုပ်နည်း
Properties props = new Properties();
try (InputStream input = new FileInputStream("config.properties")) {
    props.load(input);
}
String apiKey = props.getProperty("openweathermap.api.key");
```

`config.properties` file ကို `.gitignore` ထဲ ထည့်ထားပါ။

## Real-World Considerations

|Point|Detail|
|---|---|
|**Rate limiting**|Free tier မှာ request/minute ကန့်သတ်ချက်ရှိပါတယ် (OpenWeatherMap free = 60 calls/min)|
|**Timeout handling**|`HttpRequest.newBuilder().timeout(Duration.ofSeconds(10))` ထည့်ထားရင် network slow ဖြစ်ရင် hang မဖြစ်ပါ|
|**Caching**|City တစ်ခုတည်းကို ခဏခဏ query လုပ်ရင် result ကို local cache (HashMap) ထဲ ခဏသိမ်းထားရင် API call လျော့နိုင်|
|**Error UI**|City name မှား/network မရှိ ဖြစ်ရင် user ကို clear message ပြပေးရမယ်|

---

Weather API အစား သင့်ရဲ့ Swing project မှာ တခြား third-party API (payment, SMS, map) ကို integrate လုပ်ချင်ရင်လည်း ဒီ pattern အတိုင်းပဲ လိုက်လုပ်လို့ရပါတယ် — `doInBackground()` မှာ API call, `done()` မှာ UI update။ တခြား API type နဲ့ ဥပမာ ဆက်ကြည့်ချင်ရင် ပြောပါ။
