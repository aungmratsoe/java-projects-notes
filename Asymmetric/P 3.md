Token expiry/refresh logic ကို အပြည့်အစုံ ရေးပြပါမယ်။

## Concept

Token exchange မှာ ပုံမှန်အားဖြင့် **Token နှစ်မျိုး** ရလေ့ရှိတယ်:

- **Access Token** — အချိန်တိုပဲ ရှင်သန်တယ် (ဥပမာ 15 မိနစ်၊ 1 နာရီ)
- **Refresh Token** — အချိန်ပိုကြာကြာ ရှင်သန်တယ် (ဥပမာ ရက်သတ္တပတ်၊ လ)

Access Token expire ဖြစ်သွားရင် login ပြန်လုပ်စရာမလိုဘဲ **Refresh Token** ကိုသုံးပြီး Access Token အသစ်ကို "silent" လဲထုတ်နိုင်တယ်။

## Full Implementation

### 1️⃣ Token holder class (expiry time ကို track လုပ်ဖို့)

```java
public class TokenInfo {
    private String accessToken;
    private String refreshToken;
    private long expiryTimeMillis; // access token expire ဖြစ်မယ့် absolute time
    
    public TokenInfo(String accessToken, String refreshToken, int expiresInSeconds) {
        this.accessToken = accessToken;
        this.refreshToken = refreshToken;
        // buffer 30 စက္ကန့် ထားတယ် - network delay အတွက် margin
        this.expiryTimeMillis = System.currentTimeMillis() + (expiresInSeconds - 30) * 1000L;
    }
    
    public boolean isExpired() {
        return System.currentTimeMillis() >= expiryTimeMillis;
    }
    
    public String getAccessToken() { return accessToken; }
    public String getRefreshToken() { return refreshToken; }
}
```

### 2️⃣ Token Manager (login, refresh, auto-check အားလုံးကို handle လုပ်မယ်)

```java
import java.net.HttpURLConnection;
import java.net.URL;
import java.io.*;
import org.json.JSONObject;

public class TokenManager {
    private static TokenInfo currentToken;
    private static final String BASE_URL = "https://api.example.com";
    
    // ===== LOGIN =====
    public static synchronized void login(String username, String password) throws IOException {
        JSONObject body = new JSONObject();
        body.put("username", username);
        body.put("password", password);
        
        JSONObject response = postJson(BASE_URL + "/auth/login", body);
        
        currentToken = new TokenInfo(
            response.getString("access_token"),
            response.getString("refresh_token"),
            response.getInt("expires_in") // server ကနေ ပေးတဲ့ စက္ကန့်ပေါင်း
        );
    }
    
    // ===== REFRESH =====
    private static synchronized void refreshAccessToken() throws IOException {
        if (currentToken == null || currentToken.getRefreshToken() == null) {
            throw new IllegalStateException("Refresh token မရှိပါ - login ပြန်လုပ်ပါ");
        }
        
        JSONObject body = new JSONObject();
        body.put("refresh_token", currentToken.getRefreshToken());
        
        try {
            JSONObject response = postJson(BASE_URL + "/auth/refresh", body);
            
            currentToken = new TokenInfo(
                response.getString("access_token"),
                // တချို့ API တွေက refresh token အသစ် ပြန်ပေးတယ်, တချို့က မပေးဘူး
                response.has("refresh_token") 
                    ? response.getString("refresh_token") 
                    : currentToken.getRefreshToken(),
                response.getInt("expires_in")
            );
        } catch (IOException e) {
            // refresh token ပါ expire/invalid ဖြစ်နေရင် login ပြန်လုပ်ဖို့ လိုတယ်
            currentToken = null;
            throw new IOException("Refresh token မမှန်ကန်တော့ပါ - login အသစ်လုပ်ပါ", e);
        }
    }
    
    // ===== VALID TOKEN ရယူခြင်း (auto-refresh built-in) =====
    public static synchronized String getValidAccessToken() throws IOException {
        if (currentToken == null) {
            throw new IllegalStateException("Login မလုပ်ရသေးပါ");
        }
        
        if (currentToken.isExpired()) {
            refreshAccessToken(); // expire ဖြစ်ရင် အလိုအလျောက် refresh လုပ်တယ်
        }
        
        return currentToken.getAccessToken();
    }
    
    // ===== Helper: JSON POST request =====
    private static JSONObject postJson(String urlString, JSONObject body) throws IOException {
        URL url = new URL(urlString);
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("POST");
        conn.setRequestProperty("Content-Type", "application/json");
        conn.setDoOutput(true);
        
        try (OutputStream os = conn.getOutputStream()) {
            os.write(body.toString().getBytes("utf-8"));
        }
        
        int code = conn.getResponseCode();
        InputStream is = (code < 400) ? conn.getInputStream() : conn.getErrorStream();
        
        BufferedReader reader = new BufferedReader(new InputStreamReader(is));
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) sb.append(line);
        reader.close();
        
        if (code >= 400) {
            throw new IOException("HTTP " + code + ": " + sb.toString());
        }
        
        return new JSONObject(sb.toString());
    }
}
```

### 3️⃣ API Call တိုင်းမှာ Token automatic သုံးခြင်း

```java
public class ApiClient {
    
    public static String callProtectedApi(String urlString) throws IOException {
        // Request ခေါ်တိုင်း token valid/expired စစ်ပြီး လိုရင် auto-refresh
        String token = TokenManager.getValidAccessToken();
        
        URL url = new URL(urlString);
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");
        conn.setRequestProperty("Authorization", "Bearer " + token);
        
        int code = conn.getResponseCode();
        
        // 401 ရရင် token invalid ဖြစ်နေနိုင်တယ် (server clock skew စသဖြင့်) - တစ်ခါ ထပ်ကြိုးစားမယ်
        if (code == 401) {
            token = TokenManager.getValidAccessToken(); // force refresh logic ချဲ့ထည့်လို့ရတယ်
            conn = (HttpURLConnection) url.openConnection();
            conn.setRequestProperty("Authorization", "Bearer " + token);
            code = conn.getResponseCode();
        }
        
        BufferedReader reader = new BufferedReader(new InputStreamReader(conn.getInputStream()));
        StringBuilder response = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) response.append(line);
        reader.close();
        
        return response.toString();
    }
}
```

### 4️⃣ Swing UI ထဲမှာ သုံးပုံ

```java
loginBtn.addActionListener(e -> {
    new SwingWorker<Void, Void>() {
        protected Void doInBackground() throws Exception {
            TokenManager.login(
                usernameField.getText(),
                new String(passwordField.getPassword())
            );
            return null;
        }
        protected void done() {
            try {
                get(); // exception ရှိရင် ဒီမှာ throw ဖြစ်မယ်
                JOptionPane.showMessageDialog(LoginFrame.this, "Login အောင်မြင်ပါတယ်");
            } catch (Exception ex) {
                JOptionPane.showMessageDialog(LoginFrame.this, "Login မအောင်မြင်ပါ: " + ex.getMessage());
            }
        }
    }.execute();
});

// နောက်ပိုင်း API ခေါ်တဲ့နေရာတိုင်းမှာ
fetchDataBtn.addActionListener(e -> {
    new SwingWorker<String, Void>() {
        protected String doInBackground() throws Exception {
            // ApiClient.callProtectedApi() က token expire/refresh ကို အလိုအလျောက် handle လုပ်ပေးမယ်
            return ApiClient.callProtectedApi("https://api.example.com/data");
        }
        protected void done() {
            try {
                String data = get();
                resultArea.setText(data);
            } catch (Exception ex) {
                resultArea.setText("Error: " + ex.getMessage());
            }
        }
    }.execute();
});
```

## Flow Diagram (logic အနှစ်ချုပ်)

```
API Call ခေါ်မယ်
     ↓
Token ရှိလား? → မရှိဘူး → Exception (Login ဦးစွာလုပ်ပါ)
     ↓ ရှိတယ်
Token expired ဖြစ်နေလား?
     ↓ Yes                    ↓ No
Refresh Token သုံးပြီး      Token ကို တန်းသုံး
Access Token အသစ်ယူမယ်
     ↓
Refresh success?
  ↓ Yes        ↓ No
Token အသစ်    Login ပြန်လုပ်ဖို့
နဲ့ဆက်သုံး     Exception ပေးမယ်
```

## အရေးကြီးတဲ့ အချက်များ

- **`synchronized`** keyword တွေ သုံးထားတာ — Swing app မှာ thread များစွာက တစ်ပြိုင်နက် token ကို access/refresh မလုပ်မိအောင် (race condition ကာကွယ်ဖို့)
- **30 စက္ကန့် buffer** ထားတာ — network latency ကြောင့် token expire ဖြစ်ပြီးမှ request ရောက်တာမျိုး မဖြစ်အောင်
- Refresh token ကိုလည်း expire ဖြစ်နိုင်တယ် — ဒီအခါ user ကို login page ပြန်ပို့ရမယ်
- Production မှာ token တွေကို memory ထဲမှာသာ ထားသင့်တယ် (plaintext file ထဲ မသိမ်းသင့်ဘူး) — security risk ရှိလို့ပါ
