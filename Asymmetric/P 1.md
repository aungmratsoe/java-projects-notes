**Asymmetric (Asymmetric Encryption/Cryptography) ဆိုတာ Java မှာ ဒေတာကို encrypt/decrypt လုပ်ဖို့ key နှစ်ခု (key pair) သုံးတဲ့ cryptography နည်းလမ်း တစ်ခုပါ။**

## အခြေခံသဘောတရား

**Symmetric** ကတော့ key တစ်ခုတည်းနဲ့ encrypt/decrypt နှစ်ခုစလုံးကို လုပ်တယ်။ **Asymmetric** ကတော့ key **နှစ်ခု** သုံးတယ်:

- **Public Key** — လူတိုင်းကို ဝေမျှလို့ရတယ်၊ encrypt လုပ်ဖို့ (သို့) signature verify လုပ်ဖို့ သုံးတယ်
- **Private Key** — ကိုယ့်ဆီမှာပဲ လျှို့ဝှက်ထားရမယ်၊ decrypt လုပ်ဖို့ (သို့) sign လုပ်ဖို့ သုံးတယ်

**Public key** နဲ့ encrypt လုပ်ထားတဲ့ ဒေတာကို **private key** နဲ့ပဲ ဖွင့်လို့ရတယ် — ဒီလို reverse ဖြစ်တဲ့ relationship ကြောင့် "Asymmetric" လို့ခေါ်တာပါ။

## Java မှာ ဘယ်လို implement လုပ်လဲ

Java ရဲ့ `javax.crypto` နဲ့ `java.security` package တွေမှာ Asymmetric algorithm တွေ (အများဆုံးသုံးတာက **RSA**) ကို support လုပ်ပါတယ်။

### 1. Key Pair ဖန်တီးခြင်း

```java
import java.security.*;

KeyPairGenerator generator = KeyPairGenerator.getInstance("RSA");
generator.initialize(2048); // key size (bits)
KeyPair pair = generator.generateKeyPair();

PublicKey publicKey = pair.getPublic();
PrivateKey privateKey = pair.getPrivate();
```

### 2. Encrypt (Public Key နဲ့)

```java
import javax.crypto.Cipher;

Cipher cipher = Cipher.getInstance("RSA");
cipher.init(Cipher.ENCRYPT_MODE, publicKey);
byte[] encrypted = cipher.doFinal("Hello".getBytes());
```

### 3. Decrypt (Private Key နဲ့)

```java
cipher.init(Cipher.DECRYPT_MODE, privateKey);
byte[] decrypted = cipher.doFinal(encrypted);
System.out.println(new String(decrypted)); // "Hello"
```

## ဘယ်နေရာတွေမှာ သုံးလဲ

- **HTTPS/SSL/TLS** — website connection secure ဖြစ်ဖို့
- **Digital Signature** — file/message ကို တကယ်ပို့သူဆီကလား verify လုပ်ဖို့
- **Login/Authentication** systems တချို့
- **API Key exchange** — REST API တွေမှာ secure token exchange လုပ်တဲ့အခါ

## Symmetric vs Asymmetric နှိုင်းယှဉ်ချက်

||Symmetric|Asymmetric|
|---|---|---|
|Key အရေအတွက်|၁ ခု|၂ ခု (public + private)|
|Speed|မြန်တယ်|နှေးတယ်|
|Security|key ဝေမျှရတာ risk ရှိ|key ဝေမျှစရာမလိုဘူး|
|ဥပမာ Algorithm|AES, DES|RSA, ECC|
