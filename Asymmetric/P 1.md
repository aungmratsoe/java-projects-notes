**Asymmetric (Asymmetric Encryption/Cryptography) ဆိုတာ Java မှာ ဒေတာကို encrypt/decrypt လုပ်ဖို့ key နှစ်ခု (key pair) သုံးတဲ့ cryptography နည်းလမ်း တစ်ခုပါ။**

## အခြေခံသဘောတရား

**Symmetric** ကတော့ key တစ်ခုတည်းနဲ့ encrypt/decrypt နှစ်ခုစလုံးကို လုပ်တယ်။ **Asymmetric** ကတော့ key **နှစ်ခု** သုံးတယ်:

- **Public Key** — လူတိုင်းကို ဝေမျှလို့ရတယ်၊ encrypt လုပ်ဖို့ (သို့) signature verify လုပ်ဖို့ သုံးတယ်
- **Private Key** — ကိုယ့်ဆီမှာပဲ လျှို့ဝှက်ထားရမယ်၊ decrypt လုပ်ဖို့ (သို့) sign လုပ်ဖို့ သုံးတယ်

**Public key** နဲ့ encrypt လုပ်ထားတဲ့ ဒေတာကို **private key** နဲ့ပဲ ဖွင့်လို့ရတယ် — ဒီလို reverse ဖြစ်တဲ့ relationship ကြောင့် "Asymmetric" လို့ခေါ်တာပါ။

## Java မှာ ဘယ်လို implement လုပ်လဲ

Java ရဲ့ `javax.crypto` နဲ့ `java.security` package တွေမှာ Asymmetric algorithm တွေ (အများဆုံးသုံးတာက **RSA**) ကို support လုပ်ပါတယ်။

### 1. Key Pair ဖန်တီးခြင်း

```java
import java.security.*;

KeyPairGenerator generator = KeyPairGenerator.getInstance("RSA");
generator.initialize(2048); // key size (bits)
KeyPair pair = generator.generateKeyPair();

PublicKey publicKey = pair.getPublic();
PrivateKey privateKey = pair.getPrivate();
```

### 2. Encrypt (Public Key နဲ့)

```java
import javax.crypto.Cipher;

Cipher cipher = Cipher.getInstance("RSA");
cipher.init(Cipher.ENCRYPT_MODE, publicKey);
byte[] encrypted = cipher.doFinal("Hello".getBytes());
```

### 3. Decrypt (Private Key နဲ့)

```java
cipher.init(Cipher.DECRYPT_MODE, privateKey);
byte[] decrypted = cipher.doFinal(encrypted);
System.out.println(new String(decrypted)); // "Hello"
```

## ဘယ်နေရာတွေမှာ သုံးလဲ

- **HTTPS/SSL/TLS** — website connection secure ဖြစ်ဖို့
- **Digital Signature** — file/message ကို တကယ်ပို့သူဆီကလား verify လုပ်ဖို့
- **Login/Authentication** systems တချို့
- **API Key exchange** — REST API တွေမှာ secure token exchange လုပ်တဲ့အခါ

## Symmetric vs Asymmetric နှိုင်းယှဉ်ချက်

ဟုတ်ပါတယ်။ အဲဒီ Table က မှန်ပါတယ်။ ဒါပေမယ့် Interview အတွက်ဆိုရင် နည်းနည်းပိုပြည့်စုံအောင် ဒီလိုမှတ်ထားရင် ပိုကောင်းပါတယ်။

|Feature|**Symmetric Encryption**|**Asymmetric Encryption**|
|---|---|---|
|**Key အရေအတွက်**|**၁ ခု (Same Key)**|**၂ ခု (Public Key + Private Key)**|
|**Encryption / Decryption Key**|Encryption နဲ့ Decryption အတွက် Key တူတူသုံးတယ်|Encryption နဲ့ Decryption အတွက် Key မတူဘူး|
|**Speed**|✅ အရမ်းမြန်တယ်|❌ Symmetric ထက် နှေးတယ်|
|**Security**|Key ကို နှစ်ဖက်လုံး share လုပ်ရလို့ risk ရှိတယ်|Public Key ကိုသာ share လုပ်တာဖြစ်လို့ ပိုလုံခြုံတယ်|
|**Key Distribution**|ခက်ခဲတယ် (Secret Key ပို့ရမယ်)|လွယ်တယ် (Public Key ကိုပဲ ပေးရတယ်)|
|**အသုံးပြုရာ**|File Encryption, Database Encryption, VPN|Digital Signature, SSL/TLS, Key Exchange|
|**Algorithm ဥပမာ**|AES, DES, 3DES, Blowfish|RSA, ECC, DSA|

## လွယ်လွယ်မှတ်ရန်

### 🔐 Symmetric Encryption

```
Plain Text
     |
     | Encrypt (Secret Key)
     V
Cipher Text
     |
     | Decrypt (Secret Key)
     V
Plain Text
```

**တူညီတဲ့ Key ကိုပဲ နှစ်ကြိမ်သုံးတယ်။**

---

### 🔑 Asymmetric Encryption

```
Public Key  ---> Encrypt
                    |
               Cipher Text
                    |
Private Key ---> Decrypt
```

**Public Key နဲ့ Encrypt လုပ်ပြီး Private Key နဲ့ Decrypt လုပ်တယ်။**

```java
Cipher.getInstance("AES/ECB/PKCS5Padding");
```

ကို သုံးထားတာဖြစ်လို့

> **AES (Advanced Encryption Standard)**

ဖြစ်ပြီး **Symmetric Encryption** အမျိုးအစား ဖြစ်ပါတယ်။

အကြောင်းကတော့

- Encryption လုပ်တဲ့ Key နဲ့
    
- Decryption လုပ်တဲ့ Key
    

**တူညီတဲ့ Secret Key** ကိုပဲ အသုံးပြုထားလို့ ဖြစ်ပါတယ်။

### Interview မှာ မေးလေ့ရှိတဲ့ Question

**Q: Why is AES faster than RSA?**

**Answer:**

- **AES** သည် Symmetric Algorithm ဖြစ်ပြီး Key တစ်ခုတည်းကို အသုံးပြုသဖြင့် တွက်ချက်မှုနည်းပြီး မြန်ဆန်သည်။
    
- **RSA** သည် Asymmetric Algorithm ဖြစ်ပြီး Public Key နှင့် Private Key ကို အသုံးပြုကာ ကြီးမားသော သင်္ချာတွက်ချက်မှုများ (modular arithmetic) ပြုလုပ်ရသဖြင့် AES ထက် နှေးသည်။

### အရေးကြီးတဲ့ မှတ်ချက်

လက်တွေ့ Software တွေ (ဥပမာ HTTPS, Banking App, WhatsApp) မှာ **AES နဲ့ RSA ကို တစ်ခုတည်းရွေးသုံးတာ မဟုတ်ပါဘူး**။

- **RSA / ECC** ➜ Secret Key ကို လုံခြုံစွာ လဲလှယ်ဖို့ (Key Exchange)
    
- **AES** ➜ အမှန်တကယ် Data တွေကို မြန်မြန်ဆန်ဆန် Encrypt/Decrypt လုပ်ဖို့
    

ဒီ Hybrid နည်းလမ်းက **Security လည်းကောင်း၊ Performance လည်းမြန်** တာကြောင့် ယနေ့ခေတ် Secure Communication စနစ်အများစုမှာ အသုံးပြုကြပါတယ်။
