REST API integration project အတွက် **API Key / Token exchange** ကို Java Swing ကနေ ဘယ်လို implement လုပ်ရမလဲ ဆိုတာ code example နဲ့ ရှင်းပြပါမယ်။

## Pattern အဓိက ၂ မျိုး

### 1️⃣ API Key ကို Header ထဲမှာ ထည့်ပို့ခြင်း (ရိုးရှင်းဆုံး)

```java
import java.net.HttpURLConnection;
import java.net.URL;
import java.io.*;

public class ApiKeyExample {
    private static final String API_KEY = "your-api-key-here";
    
    public static String callApi(String urlString) throws IOException {
        URL url = new URL(urlString);
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");
        
        // API Key ကို header ထဲထည့်တယ်
        conn.setRequestProperty("x-api-key", API_KEY);
        // သို့မဟုတ် တချို့ API တွေက Authorization header သုံးတယ်
        // conn.setRequestProperty("Authorization", "Bearer " + API_KEY);
        
        int responseCode = conn.getResponseCode();
        BufferedReader reader = new BufferedReader(
            new InputStreamReader(conn.getInputStream())
        );
        
        StringBuilder response = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            response.append(line);
        }
        reader.close();
        
        return response.toString();
    }
}
```

### 2️⃣ Token-based Exchange (OAuth-style — Login → Token ယူ → Token နဲ့ Request ပို့)

Token exchange ဆိုတာ **ခြေလှမ်း ၂ ခု** ရှိတယ်:

- **Step 1**: Username/Password (သို့) Client credentials ပို့ပြီး Token တောင်းတယ်
- **Step 2**: ရလာတဲ့ Token ကို နောက်ထပ် request တိုင်းမှာ ထည့်ပို့တယ်

```java
import java.net.HttpURLConnection;
import java.net.URL;
import java.io.*;
import org.json.JSONObject; // org.json library သုံးမယ်

public class TokenExchangeExample {
    private static String accessToken;
    
    // Step 1: Login လုပ်ပြီး Token ယူတယ်
    public static void login(String username, String password) throws IOException {
        URL url = new URL("https://api.example.com/auth/login");
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("POST");
        conn.setRequestProperty("Content-Type", "application/json");
        conn.setDoOutput(true);
        
        String jsonBody = String.format(
            "{\"username\":\"%s\",\"password\":\"%s\"}", 
            username, password
        );
        
        try (OutputStream os = conn.getOutputStream()) {
            os.write(jsonBody.getBytes("utf-8"));
        }
        
        BufferedReader reader = new BufferedReader(
            new InputStreamReader(conn.getInputStream())
        );
        StringBuilder response = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            response.append(line);
        }
        reader.close();
        
        // Response ထဲက token ကို ဆွဲထုတ်တယ်
        JSONObject json = new JSONObject(response.toString());
        accessToken = json.getString("access_token");
    }
    
    // Step 2: Token ကို သုံးပြီး protected API ကို ခေါ်တယ်
    public static String callProtectedApi(String urlString) throws IOException {
        if (accessToken == null) {
            throw new IllegalStateException("Login လုပ်ပါဦး, token မရှိသေးဘူး");
        }
        
        URL url = new URL(urlString);
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");
        conn.setRequestProperty("Authorization", "Bearer " + accessToken);
        
        BufferedReader reader = new BufferedReader(
            new InputStreamReader(conn.getInputStream())
        );
        StringBuilder response = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            response.append(line);
        }
        reader.close();
        
        return response.toString();
    }
}
```

## Swing UI ထဲမှာ သုံးပုံ (ဥပမာ)

```java
import javax.swing.*;
import java.awt.event.*;

public class LoginFrame extends JFrame {
    private JTextField usernameField = new JTextField(15);
    private JPasswordField passwordField = new JPasswordField(15);
    private JButton loginBtn = new JButton("Login");
    
    public LoginFrame() {
        setLayout(new java.awt.FlowLayout());
        add(new JLabel("Username:"));
        add(usernameField);
        add(new JLabel("Password:"));
        add(passwordField);
        add(loginBtn);
        
        loginBtn.addActionListener(e -> {
            // UI thread ကို block မဖြစ်အောင် SwingWorker သုံးတယ်
            new SwingWorker<Void, Void>() {
                protected Void doInBackground() throws Exception {
                    TokenExchangeExample.login(
                        usernameField.getText(),
                        new String(passwordField.getPassword())
                    );
                    return null;
                }
                protected void done() {
                    JOptionPane.showMessageDialog(LoginFrame.this, "Login အောင်မြင်ပါတယ်!");
                }
            }.execute();
        });
        
        setSize(300, 150);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
        setVisible(true);
    }
}
```

## အရေးကြီးတဲ့ Security Practice များ

- ⚠️ API Key/Password ကို code ထဲမှာ **hardcode မလုပ်ပါနဲ့** — production မှာ `.properties` file (သို့) environment variable သုံးပါ
- Token ရဲ့ **expiry time** ကို check လုပ်ပြီး expired ဖြစ်ရင် **refresh token** နဲ့ token အသစ်တောင်းရမယ်
- HTTP မဟုတ်ဘဲ **HTTPS** ကိုပဲ သုံးပါ (Man-in-the-middle attack ကာကွယ်ဖို့)
- SwingWorker (သို့) Thread သုံးပြီး API call ကို **background** မှာလုပ်ပါ — UI freeze မဖြစ်အောင်
