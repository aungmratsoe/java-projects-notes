Java Swing တွင် Drag and Drop (Mouse ဖြင့် ဆွဲချပြီး ဒီဇိုင်းဆွဲခြင်း) ကို အသုံးပြု၍ **Slide Menu (ဘေးဘက်မှ ထွက်လာသော မီနူး)** တစ်ခု ဖန်တီးရန်အတွက် **Maven** နှင့် GUI Builder (ဥပမာ- NetBeans IDE သို့မဟုတ် Eclipse ၏ WindowBuilder) တို့ကို ပူးတွဲအသုံးပြုရပါမည်။

  

အောက်ပါအဆင့်များအတိုင်း အသေးစိတ် လေ့လာကြည့်ကြရအောင်-

  

### အဆင့် ၁ - Maven Project ဖန်တီးခြင်း

သင်အသုံးပြုနေသော IDE (ဥပမာ- NetBeans) တွင် Maven Project အသစ်တစ်ခုကို တည်ဆောက်ပါ။ `pom.xml` ထဲတွင် UI ပုံစံလှပစေရန် **FlatLaf** ကဲ့သို့သော Look and Feel Library ကို ထည့်သွင်းနိုင်သည် (သို့မဟုတ် မူလ Swing ဖြင့်လည်း တည်ဆောက်နိုင်သည်)။

  

`pom.xml` တွင် အောက်ပါအတိုင်း Dependencies ထည့်ပါ-

  

XML

```
<dependencies>
    <!-- FlatLaf UI Library (Optional - မီနူးဒီဇိုင်းလှပစေရန်) -->
    <script></script>
    <dependency>
        <groupId>com.formdev</groupId>
        <artifactId>flatlaf</artifactId>
        <version>3.2.5</version>
    </dependency>
</dependencies>
```

### အဆင့် ၂ - Drag and Drop (GUI Builder) ဖြင့် Form တည်ဆောက်ခြင်း

၁။ IDE (ဥပမာ- NetBeans) တွင် `JFrame Form` အသစ်တစ်ခုကို Drag and Drop (Design View) ဖြင့် ဖန်တီးပါ။

၂။ ဤနေရာတွင် Slide Menu (ဘေးဘက်မှ ပေါ်လာ/ပျောက်သွားမည့် မီနူး) ဖန်တီးရန် အကောင်းဆုံးနည်းလမ်းမှာ **`JPanel`** နှစ်ခုကို အသုံးပြုရန် ဖြစ်သည်:

  

- **Main Panel (`jPanelMain`):** ပင်မစာမျက်နှာအတွက် (BorderLayout.CENTER တွင် ထားပါ)။
    
      
    
- **Menu Panel (`jPanelMenu`):** ဘေးဘက်မှ ထွက်လာမည့် မီနူးအတွက် (Preferred Size ကို ဥပမာ နှုတ်ခမ်းပြား `200px` ခန့် ပေးထားပြီး BorderLayout.WEST တွင် ထားပါ)။
    
      
    

### အဆင့် သုံး - Slide Animation ပြုလုပ်ရန် ကုဒ်ရေးသားခြင်း (Code View)

Drag and Drop ဖြင့် Design ဆွဲပြီးပါက မီနူးကို ခလုတ်နှိပ်၍ ပေါ်လာ/ပျောက်သွားအောင် (Slide Animation ဖြစ်အောင်) Button တစ်ခုပေါ်တွင် Mouse Click Event ထည့်သွင်းပေးရပါမည်။

  

`JFrame` ၏ Source Code ထဲတွင် အောက်ပါအတိုင်း Animation Logic ကို ထည့်သွင်းပါ-

  

Java

```
import javax.swing.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class SlideMenuFrame extends javax.swing.JFrame {

    // မီနူးပွင့်နေလား၊ ပိတ်နေလား စစ်ဆေးရန်
    private boolean menuExpanded = true;

    public SlideMenuFrame() {
        initComponents(); // GUI Builder မှ ဖန်တီးထားသော UI များကို ချိတ်ဆက်ပေးသည်
    }

    // Menu ကို Slide လုပ်ပေးမည့် Method
    private void toggleMenu() {
        // Menu Panel ၏ အကျယ် (Width) ကို ယူရန်
        int maxMenuWidth = jPanelMenu.getWidth();
        
        // Thread ဖြင့် Animation ပုံစံ တဖြည်းဖြည်း ပေါ်လာ/ပျောက်သွားစေရန် ပြုလုပ်ခြင်း
        new Thread(new Runnable() {
            @Override
            public void run() {
                try {
                    for (int i = 0; i <= maxMenuWidth; i++) {
                        Thread.sleep(2); // အမြန်နှုန်းကို ထိန်းရန်
                        if (menuExpanded) {
                            // ပိတ်မည်ဆိုပါက တဖြည်းဖြည်း သေးသွားစေရန်
                            jPanelMenu.setPreferredSize(new java.awt.Dimension(maxMenuWidth - i, jPanelMenu.getHeight()));
                        } else {
                            // ဖွင့်မည်ဆိုပါက တဖြည်းဖြည်း ကြီးလာစေရန်
                            jPanelMenu.setPreferredSize(new java.awt.Dimension(i, jPanelMenu.getHeight()));
                        }
                        jPanelMenu.revalidate();
                    }
                    // အခြေအနေကို ပြောင်းပြန်လှန်လိုက်သည်
                    menuExpanded = !menuExpanded;
                } catch (Exception e) {
                    e.printStackTrace();
                }
            }
        }).start();
    }

    // Drag and Drop လုပ်ထားသော Menu Toggle Button ၏ Action Event ထဲတွင် ဤသို့ခေါ်ပါ
    private void jButtonToggleActionPerformed(java.awt.event.ActionEvent evt) {
        toggleMenu();
    }

    // --- GUI Builder မှ အလိုအလျောက် ဆွဲသားပေးမည့် Components များ (ဥပမာ) ---
    private void initComponents() {
        // NetBeans / GUI Builder က Drag and Drop လုပ်ထားသည်များကို ဤနေရာတွင် အလိုအလျောက် ကုဒ်ရေးပေးပါလိမ့်မည်။
    }

    public static void main(String args[]) {
        // FlatLaf ဖြင့် Theme လှလှလေး သုံးချင်ပါက
        try {
            UIManager.setLookAndFeel(new com.formdev.flatlaf.FlatLightLaf());
        } catch (Exception ex) {
            ex.printStackTrace();
        }

        java.awt.EventQueue.invokeLater(new Runnable() {
            public void run() {
                new SlideMenuFrame().setVisible(true);
            }
        });
    }
}
```

### အနှစ်ချုပ် လုပ်ဆောင်ချက်

- **Drag and Drop (GUI Builder):** ဖြင့် `JFrame` ပေါ်တွင် `JPanel` များနှင့် `JButton` များကို မိမိကြိုက်နှစ်သက်သလို ဆွဲချ တည်ဆောက်ပါ။
    
      
    
- **Maven:** ဖြင့် လိုအပ်သော Libraries များကို ထည့်သွင်းပါ။
    
      
    
- **Slide Effect:** အတွက် ဖွင့်/ပိတ် ခလုတ် (Button) တွင် နှိပ်လိုက်ပါက `Thread` နှင့် `setPreferredSize` ကို အသုံးပြု၍ ဘေးဘက် မီနူးဘောင်ကြီး တဖြည်းဖြည်း ဝင်သွား/ထွက်လာ ဖြစ်အောင် စီမံပေးရပါမည်။
