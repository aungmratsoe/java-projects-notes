ဒီတစ်ခါ explanation ပဲမလုပ်တော့ဘူး။ **မင်း Student Management System အတွက် Dashboard Shell တစ်ခုကို code နဲ့ တကယ်ဆောက်မယ်**။

# 2. Main Dashboard Panel

NetBeans GUI Builder မှာ outer `JPanel` တစ်ခုထားပြီး—

```java
panelDashboard
```

လို့ name ပေး။

ပြီးတော့—

```java
panelDashboard.setLayout(
    new MigLayout(
        "fill, insets 0",
        "[220!] [grow]",
        "[60!] [grow]"
    )

```

ဒီ line ကို နားလည်ဖို့ အရေးကြီးတယ်။

```text

```

```text
Rows:

[60!]       → Header
[grow]      → Main content
```

# 18. Full Content Code

```java
private void setupContent() {

    panelContent.setLayout(
        new MigLayout(
            "fill, insets 20",
            "[grow][]",
            "[]15[]15[grow]10[]"
        )
    );

    // Page title
    panelContent.add(
        lblPageTitle,
        "growx"
    );

    panelContent.add(
        btnAddStudent,
        "wrap"
    );


    // Search panel
    JPanel searchPanel =
            new JPanel(
                new MigLayout(
                    "fillx, insets 0",
                    "[][grow][]",
                    "[]"
                )
            );

    searchPanel.add(
        new JLabel("Search:")
    );

    searchPanel.add(
        txtSearch,
        "growx"
    );

    searchPanel.add(
        btnSearch
    );

    panelContent.add(
        searchPanel,
        "span 2, growx, wrap"
    );


    // Table
    panelContent.add(
        scrollPaneStudents,
        "span 2, grow, push, wrap"
    );


    // Footer
    panelContent.add(
        lblRecordCount,
        "span 2, growx"
    );
}
```

# 23. Better Architecture — CardLayout + MigLayout

ဒီနေရာမှာ **MigLayout တစ်ခုတည်းပဲ မသုံးရဘူး**။

Dashboard content switching အတွက် `CardLayout` က သင့်တော်တယ်။

```text
Dashboard
│
├── Header
├── Sidebar
└── Content
      │
      └── CardLayout
            ├── DashboardPage
            ├── StudentPage
            ├── TeacherPage
            └── ReportPage
```

အဲဒီ page တစ်ခုချင်းစီအတွင်းမှာတော့ **MigLayout** သုံးမယ်။

ဒါဟာ professional architecture ပိုဖြစ်တယ်။

# 24. CardLayout နဲ့ Screen Switching

```java
private final CardLayout cardLayout =
        new CardLayout();

private final JPanel pageContainer =
        new JPanel(cardLayout);
```

Add pages—

```java
pageContainer.add(
    dashboardPage,
    "dashboard"
);

pageContainer.add(
    studentPage,
    "students"
);

pageContainer.add(
    teacherPage,
    "teachers"
);
```

Switch—

```java
cardLayout.show(
    pageContainer,
    "students"
);
```

ဒီ architecture ကို သေချာနားလည်ထား။

```text
CardLayout
     ↓
Which page?

MigLayout
     ↓
How page is arranged?
```

# 25. ဒါက အရမ်းအရေးကြီးတဲ့ Architecture Lesson

Layout manager တစ်မျိုးတည်းကို အကုန်လုံးအတွက် မသုံးရဘူး။

### `MigLayout`

Page ထဲက components relationship

### `CardLayout`

ဘယ် page ကိုပြမလဲ

### `JScrollPane`

Scrollable content

### `BorderLayout`

တချို့ simple container structures

ဒါတွေကို **role အလိုက်ပေါင်းသုံးလို့ရတယ်**။

# 30. ဒီ Lesson ရဲ့ အဓိက Concept

အခု မင်း MigLayout ကို ဒီလိုမြင်ရမယ်—

```text
MigLayout is NOT just:

"put component here"

It is:

"define relationships between components"
```

ဥပမာ—

```java
"[220!] [grow]"
```

ဆိုတာ—

> Sidebar fixed, Content flexible

```java
"span 2"
```

ဆိုတာ—

> Header uses both columns

```java
"grow, push"
```

ဆိုတာ—

> Table gets remaining space

```java
"[]10[]"
```

ဆိုတာ—

> Row spacing 10

ဒီလို **requirement → relationship → constraint** ပြောင်းစဉ်းစားရမယ်။
