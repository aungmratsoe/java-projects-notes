```java
public class StudentTableModel
        extends AbstractTableModel {

    private final String[] columns = {
        "ID",
        "Name",
        "Phone",
        "Major",
        "Status"
    };

    private List<Student> students =
            new ArrayList<>();

    public void setStudents(
            List<Student> students) {

        this.students =
                new ArrayList<>(students);

        fireTableDataChanged();
    }

    public Student getStudentAt(int row) {

        return students.get(row);
    }

    @Override
    public int getRowCount() {

        return students.size();
    }

    @Override
    public int getColumnCount() {

        return columns.length;
    }

    @Override
    public String getColumnName(int column) {

        return columns[column];
    }

    @Override
    public Object getValueAt(
            int row,
            int column) {

        Student student =
                students.get(row);

        return switch (column) {

            case 0 -> student.getStudentId();
            case 1 -> student.getName();
            case 2 -> student.getPhone();
            case 3 -> student.getSpecialization();
            case 4 -> student.isActive()
                    ? "Active"
                    : "Inactive";

            default -> null;
        };
    }
}
```

ဒီ class က JTable ကို data ကို ဘယ်လိုပြမလဲဆိုတာ တာဝန်ယူတယ်။

# 12. Search

```java
private void searchStudents() {

    String keyword =
            txtSearch.getText()
                    .trim();

    try {

        List<Student> students;

        if (keyword.isBlank()) {

            students =
                    studentService.findAll();

        } else {

            students =
                    studentService.search(
                            keyword
                    );
        }

        tableModel.setStudents(
                students
        );

        updateRecordCount();

    } catch (Exception e) {

        showError(
                "Search failed.",
                e
        );
    }
}
```

ဒီ flow—

```text
User types
   ↓
StudentPage
   ↓

   ↓
DAO
   ↓
Database
   ↓
List<Student>
   ↓
TableModel
   ↓
JTable
```

ဖြစ်တယ်။

# 16. Selected Student

```java
private Student getSelectedStudent() {

    int viewRow =
            tblStudents.getSelectedRow();

    if (viewRow == -1) {
        return null;
    }

    int modelRow =
            tblStudents
                .convertRowIndexToModel(
                        viewRow
                );

    return tableModel.getStudentAt(
            modelRow
    );
}
```

ဒီ line ကို သတိထား—

```java
convertRowIndexToModel(...)
```

ဘာလို့လဲ?

```java
private void deleteStudent(
        Student student) {

    int result =
            JOptionPane.showConfirmDialog(
                    this,
                    "Delete "
                    + student.getName()
                    + "?",
                    "Confirm Delete",
                    JOptionPane.YES_NO_OPTION
            );

    if (result !=
            JOptionPane.YES_OPTION) {

        return;
    }

    try {

        studentService.delete(
                student.getStudentId()
        );

        loadStudents();

        JOptionPane.showMessageDialog(
                this,
                "Student deleted successfully."
        );

    } catch (Exception e) {

        showError(
                "Delete failed.",
                e
        );
    }
}
```


```sql
SELECT *
FROM students

   OR name LIKE ?
   OR phone LIKE ?
```

ဒါက architecture မှာ **data should be filtered close to where it lives** ဆိုတဲ့ concept နဲ့ချိတ်တယ်။

ပြီးတော့—

```java

```

လုပ်တယ်။

ဒါဆို JTable refresh ဖြစ်မယ်။

ဒီနေရာမှာ JTable ကို manual repaint အများကြီးလုပ်ဖို့ မလိုဘူး။

# 33. UI Thread သတိထား

Database query ကြာရင်—

```java
loadStudents();
```

ကို Event Dispatch Thread ပေါ်မှာ တိုက်ရိုက် run လုပ်တာက UI freeze ဖြစ်စေနိုင်တယ်။

ဥပမာ—

```text
User clicks Search
       ↓
Database query 5 sec
       ↓
Swing UI frozen for 5 sec
```

ဒါကြောင့် production app မှာ `SwingWorker` သုံးသင့်တယ်။

# 34. `SwingWorker` Basic Pattern

```java
private void loadStudentsAsync() {

    new SwingWorker<
            List<Student>,
            Void>() {

        @Override
        protected List<Student>
        doInBackground()
                throws Exception {

            return studentService.findAll();
        }

        @Override
        protected void done() {

            try {

                List<Student> students =
                        get();

                tableModel.setStudents(
                        students
                );

                updateRecordCount();

            } catch (Exception e) {

                showError(
                        "Failed to load students.",
                        e
                );
            }
        }

    }.execute();
}
```

ဒီဟာက Swing application မှာ အရမ်းအရေးကြီးတယ်။
