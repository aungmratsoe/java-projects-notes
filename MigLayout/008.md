JTable/JList တွေကို MigLayout မှာ ထည့်သုံးတာက component တစ်ခုအနေနဲ့ တခြား component တွေနဲ့ အတူတူပဲ layout ထဲ ထည့်ရုံပါပဲ။ ဒါပေမယ့် **scroll bar** ပါလာအောင် `JScrollPane` နဲ့ ပတ်ပြီးမှ ထည့်ရတာ အရေးကြီးပါတယ်။ Cafe POS app အတွက် Order list ကို JTable နဲ့ ပြရမယ်ဆိုပြီး နမူနာနဲ့ တစ်ဆင့်ချင်း သင်ပေးပါမယ်။

## အခြေခံ သဘောတရား

JTable တစ်ခုကို panel ထဲ ထည့်တဲ့အခါ **JTable ကို တိုက်ရိုက်** `add()` မလုပ်ပါနဲ့။ အမြဲတမ်း `JScrollPane` ထဲ ထည့်ပြီးမှ ၄င်း scroll pane ကို MigLayout panel ထဲ ထည့်ပါတယ်။

```java
JTable table = new JTable(model);
JScrollPane scrollPane = new JScrollPane(table);

panel.setLayout(new MigLayout("fill", "[grow]", "[grow]"));
panel.add(scrollPane, "grow, push");
```

- `"grow"` — column/row space ကို scrollPane က အပြည့်ယူ
- `"push"` — window resize လုပ်ရင် ဒီ component အရွယ်အစားကို လိုက်ချဲ့ခိုင်း
- panel layout မှာလည်း `[grow]` column/row constraint ထည့်ပေးဖို့ လိုပါတယ်

## Cafe POS Order Table နမူနာ

```java
public class OrderPanel extends JPanel {
    private JTable orderTable;
    private DefaultTableModel model;

    public OrderPanel() {
        setLayout(new MigLayout("fill, insets 10", "[grow]", "[][grow][]"));

        // Header
        JLabel titleLabel = new JLabel("Current Order");
        add(titleLabel, "wrap");

        // Table
        String[] columns = {"Item", "Qty", "Price", "Subtotal"};
        model = new DefaultTableModel(columns, 0) {
            @Override
            public boolean isCellEditable(int row, int col) {
                return false; // user ကို cell edit မခွင့်ပြု
            }
        };
        orderTable = new JTable(model);
        JScrollPane scrollPane = new JScrollPane(orderTable);
        add(scrollPane, "grow, wrap");

        // Total row
        JLabel totalLabel = new JLabel("Total: $0.00");
        add(totalLabel, "align right");
    }
}
```

**Row constraint** `"[][grow][]"` က ဘာလုပ်လဲဆိုတော့-

- row 1 (title) — fixed height
- row 2 (table) — `grow` ဆိုတော့ ကျန်တဲ့ space အားလုံးယူ
- row 3 (total) — fixed height

## JList ကိုလည်း ပုံစံတူပါပဲ

```java
DefaultListModel<String> listModel = new DefaultListModel<>();
JList<String> menuList = new JList<>(listModel);
JScrollPane listScroll = new JScrollPane(menuList);

panel.add(listScroll, "grow, wrap, height 200:300:400");
```

`"height 200:300:400"` က min:preferred:max height သတ်မှတ်နည်း — JList ရဲ့ height ကို control ချင်ရင် ဒီလို syntax သုံးလို့ရပါတယ်။

## Table + Detail Panel ဆီလို layout (POS မှာ အသုံးများ)

Order table ကို ဘေးမှာ item detail/buttons ထားချင်ရင်:

```java
setLayout(new MigLayout("fill", "[grow][200]", "[grow]"));

add(orderScrollPane, "grow");           // ဘယ်ဘက် - table, grow
add(detailPanel, "grow, wrap");         // ညာဘက် - fixed 200px width panel
```

Column constraint `"[grow][200]"` က ဘယ်ဘက် column ကို flexible ထားပြီး ညာဘက်ကို 200px fixed ထားတာပါ။
