## သင်ခန်းစာ ၄ — grow vs fill (အရေးအကြီးဆုံး concept)

ဒါက student အများစု ရှုပ်တတ်တဲ့ concept ပါ — သေချာနားလည်အောင် ခွဲခြင်းပြပါမယ်:

|Constraint|ဘာလုပ်လဲ|
|---|---|
|**grow**|**Cell size** ကို ချဲ့ပေး (space ကျန်ရင် ဒီ column/component ကို ချဲ့)|
|**fill**|Component ကို **cell အပြည့်** ဖြစ်အောင် ဆန့် (cell ကြီးနေပေမယ့် component က ကျဉ်းနေရင် fill လိုက်တာ)|

**Analogy:** Cell ဆိုတာ "အခန်း" တစ်ခန်းလို့ တွေးပါ။

- `grow` = အခန်းကို ကျယ်အောင်ချဲ့
- `fill` = အခန်းထဲက ပရိဘောဂ (component) ကို အခန်းအပြည့်ဖြစ်အောင် ဆန့်

### Practice — 3 မျိုးယှဉ်ကြည့်ရအောင်:

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class Lesson4 extends JFrame {
    public Lesson4() {
        setLayout(new MigLayout("wrap 1", "[300]"));  // column width 300 (preferred)

        add(new JLabel("1) No grow, no fill:"));
        add(new JButton("Button"));

        add(new JLabel("2) grow only:"));
        add(new JButton("Button"), "grow");

        add(new JLabel("3) growx, fillx:"));
        add(new JButton("Button"), "growx, fillx");

        pack();
        setSize(400, 300);
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson4().setVisible(true));
    }
}
```

Window ကို mouse နဲ့ **ကျယ်အောင် resize** လုပ်ကြည့်ပါ (drag လုပ်ပါ) — button 3 ခုစလုံးရဲ့ behavior ဘယ်လိုကွာလဲ observe လုပ်ပါ။

## အဖြေ — Lesson 4

**Button 3 ("growx, fillx") ပဲ window ကျယ်တာနဲ့အမျှ တိုးချဲ့သွားမှာပါ။**

ဘာလို့လဲဆိုတော့:

- **Button 1** — constraint မရှိလို့ **preferred size** အတိုင်းပဲ ရပ်နေမယ် (column က 300px ရှိနေပေမယ့် button က မချဲ့ဘူး)
- **Button 2** (`grow` သီးသန့်) — **cell/column** ကတော့ resize အခါ ကျယ်ချဲ့ပေမယ့် (grow ဆိုတာ column ရဲ့ extra space ကို ဘယ်သူယူမလဲ ဆုံးဖြတ်တာ)၊ `fill` မပါလို့ **button ကိုယ်တိုင်က cell ထဲမှာ preferred size အတိုင်းပဲ ကျန်နေမယ်** (center မှာရပ်နေမယ်)
- **Button 3** (`growx, fillx`) — column resize ဖြစ်ရင် **column ကလည်း ကျယ်၊ button ကလည်း column အပြည့်ဖြစ်အောင် fill** ဖြစ်လို့ button က window ကျယ်သလောက် တကယ်ကျယ်သွားမှာပါ

**Key point:** `grow` = space ခွဲဝေခံခွင့်ရ၊ `fill` = ရလာတဲ့ space ကို ကိုယ်တိုင် ဖြည့်သုံး။ ၂ ခုစလုံး ပေါင်းမှ "အပြည့်ကျယ်တဲ့ button" ဖြစ်ပါတယ်။

## သင်ခန်းစာ ၅ — Real-world Form ဆောက်ကြည့်ရအောင် (Combine လုပ်ခြင်း)

အခုအထိ သင်ခဲ့တဲ့ concept တွေ (`wrap`, `grow`, `fill`, `span`, `split`) ကို ပေါင်းသုံးပြီး **Registration Form** အစစ်ဆောက်ကြည့်ရအောင်:

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class Lesson5 extends JFrame {
    public Lesson5() {
        setLayout(new MigLayout(
            "insets 20, wrap 2",
            "[right][grow,fill]"     // column1=right align, column2=grow+fill
        ));

        // Title — column 2 ခုလုံးယူ၊ အလယ်ညှိ
        add(new JLabel("Registration Form"), "span 2, align center, gapbottom 15");

        add(new JLabel("Full Name:"));
        add(new JTextField());

        add(new JLabel("Email:"));
        add(new JTextField());

        add(new JLabel("Country:"));
        add(new JComboBox<>(new String[]{"Myanmar", "Singapore", "Others"}));

        // Checkbox — column 2 ခုလုံးယူ
        add(new JCheckBox("I agree to terms"), "span 2");

        // Button ၂ ခု တစ်တန်းထဲ
        add(new JButton("Submit"), "span 2, split 2, align center");
        add(new JButton("Cancel"));

        pack();
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson5().setVisible(true));
    }
}
```

### ဒီ code ထဲက constraint တွေကို ပြန်ခွဲခြမ်းကြည့်ရအောင် — သင် ဖြေကြည့်ပါ:

1. `"span 2, align center, gapbottom 15"` — Title label ကို ဘာလို့ ဒီလို constraint ၃ ခု ထည့်ရတာလဲ (တစ်ခုချင်းစီရဲ့ အလုပ်က ဘာလဲ)?
2. `"span 2, split 2, align center"` — Submit button မှာ `span` နဲ့ `split` ၂ ခုလုံး ဘာလို့ လိုအပ်တာလဲ (တစ်ခုတည်းနဲ့ မရဘူးလား)?

ဒီ code ကို run ကြည့်ပြီး၊ အထက်က မေးခွန်း ၂ ခုကို ကိုယ်တိုင် စဉ်းစားဖြေကြည့်ပါ — ဒါမှ concept တွေ စွဲမှာပါ။
