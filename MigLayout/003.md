# MigLayout သင်ခန်းစာ — အခြေခံမှ အဆင့်ဆင့်

## ၁. MigLayout ရဲ့ အခြေခံသဘောတရား

MigLayout constraint ၃ မျိုးနဲ့ အလုပ်လုပ်ပါတယ်:

```java
new MigLayout(layoutConstraints, columnConstraints, rowConstraints)
```

- **Layout Constraints** — layout တစ်ခုလုံးအတွက် (insets, wrap, fillx...)
- **Column Constraints** — column တစ်ခုချင်းစီအတွက် (width, align...)
- **Row Constraints** — row တစ်ခုချင်းစီအတွက် (height, gap...)
- **Component Constraints** — `add()` လုပ်တဲ့အခါ component တစ်ခုချင်းစီအတွက်

## ၂. အလွယ်ဆုံး Example

```java
setLayout(new MigLayout());
add(new JLabel("Name:"));
add(new JTextField(10));
```

Constraint ဘာမှမပါရင်တောင် component တွေကို default flow layout လို တန်းချထားပေးပါတယ်။

## ၃. "wrap" — Row အသစ်ပြောင်းနည်း

```java
setLayout(new MigLayout("wrap 2"));  // column 2 ခု ပြည့်ရင် row အသစ်

add(new JLabel("Name:"));
add(new JTextField(10));
add(new JLabel("Email:"));
add(new JTextField(10));
```

ရလဒ်: Label/Field စုံစုံလိုက် ၂ တန်းပေါ်ပါလိမ့်မယ်။

## ၄. "grow" / "fill" — Component ချဲ့ခြင်း

```java
setLayout(new MigLayout("wrap 2", "[right][grow,fill]"));

add(new JLabel("Name:"));
add(new JTextField());       // window ကျယ်ရင် ဒီ field ကျယ်လိုက်ပါလိမ့်မယ်
```

- `grow` — space ကျန်ရင် ယူပေး
- `fill` — cell အပြည့် ဖြစ်အောင် ဆွဲချဲ့ပေး
- `[right]` — column ၁ ကို ညာဘက်ချိန်

## ၅. "span" — Column များစွာ ယူခြင်း

```java
setLayout(new MigLayout("wrap 2"));
add(new JLabel("Title"), "span 2, align center");  // column ၂ခုလုံးယူ
add(new JLabel("Name:"));
add(new JTextField());
```

## ၆. "split" — Row တစ်ခုထဲ Component ၂ ခုထားခြင်း

```java
add(new JButton("OK"), "split 2");
add(new JButton("Cancel"));  // OK ဘေးမှာတန်း ပေါ်ပါလိမ့်မယ်
```

## ၇. "gap" — Space ထိန်းခြင်း

```java
add(comp1, "gapright 20");   // ညာဘက် gap 20px
add(comp2, "gaptop 10");     // အပေါ်ဘက် gap 10px
```

## ၈. Practice — Login Form ဆောက်ကြည့်ရအောင်

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class LoginForm extends JFrame {
    public LoginForm() {
        setTitle("Login");
        setLayout(new MigLayout(
            "insets 20, wrap 2",     // margin 20px, column 2 ပြည့်ရင် wrap
            "[right][grow,fill 200]" // column1 = right align, column2 = grow+fill, width 200
        ));

        add(new JLabel("Username:"));
        add(new JTextField());

        add(new JLabel("Password:"));
        add(new JPasswordField());

        add(new JButton("Login"), "span 2, split 2, align center");
        add(new JButton("Cancel"));

        pack();
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new LoginForm().setVisible(true));
    }
}
```

## ၉. Debug Mode — Layout ကြည့်လို့ရအောင်

Layout မှားနေရင် grid line တွေ visual ပြချင်ရင်:

```java
setLayout(new MigLayout("debug"));
```

## ၁၀. Constraint အားလုံး Quick Reference

|Constraint|ဘယ်နေရာမှာသုံး|ဖော်ပြချက်|
|---|---|---|
|`wrap N`|Layout|column N ပြည့်ရင် row အသစ်|
|`insets T L B R`|Layout|panel edge margin|
|`fillx` / `filly`|Layout|width/height အပြည့်ဖြန့်|
|`grow`|Component|space ကျန်ရင် ချဲ့|
|`growx` / `growy`|Component|horizontal/vertical ချဲ့ပဲ|
|`span N`|Component|column N ခုယူ|
|`split N`|Component|row ထဲ N ခု တန်းချ|
|`align center/left/right`|Component|ညှိချက်|
|`gapleft/right/top/bottom N`|Component|space ထားခြင်း|
|`width N` / `height N`|Component|size ပြတ်ပြတ်သားသား သတ်မှတ်|
