# Lesson 5 — MigLayout ကို Debug + Polish လုပ်မယ်

အခုတော့ responsive basic layout ရပြီ။ ဒီ lesson မှာ **layout ဘာကြောင့် ဒီနေရာရောက်သွားလဲဆိုတာ debug လုပ်နည်း** နဲ့ **form ကို polished ဖြစ်အောင် spacing/alignment ပေးနည်း** ကို လေ့လာမယ်။

ဒီ lesson ပြီးရင် MigLayout ကို “constraint တွေ copy/paste လုပ်သုံးတာ” မဟုတ်ဘဲ **ကိုယ်တိုင် layout ဆုံးဖြတ်နိုင်တဲ့အဆင့်** ကို တက်မယ်။

---

## 1. `debug` — MigLayout ရဲ့ X-Ray

Layout မမှန်ဘူးဆိုပါစို့။

```text
Name:     [__________]
Phone:          [__________]
```

ဘာကြောင့် မညီတာလဲ မသိဘူး။

MigLayout မှာ debug mode ထည့်လို့ရတယ်။

```java
panelForm.setLayout(
    new MigLayout(
        "debug",
        "[][grow]20[][grow]",
        "[]10[]10[]"
    )
);
```

ဒါမှမဟုတ်—

```java
new MigLayout(
    "debug 500",
    "[][grow]",
    "[]10[]"
);
```

လိုသုံးနိုင်တယ်။

Debug border / grid information တွေမြင်ရလို့ **ဘယ် column ဘယ် row မှာ component ရှိနေလဲ** ရှင်းသွားမယ်။

Development အချိန်မှာပဲသုံးပြီး production မှာ ဖယ်လိုက်ပါ။

---

# 2. `insets` — Panel အပြင် padding

ဒီဟာ—

```java
"insets 20"
```

ဆိုတာ panel edge နဲ့ component ကြား gap ပေးတာ။

```text
┌──────────────────────────────┐
│  ← 20px →                    │
│      Student ID: [______]    │
│                              │
└──────────────────────────────┘
```

`insets 20` က လေးဖက်လုံး 20။

ပို control ချင်ရင် top/right/bottom/left ကို သီးခြားသတ်မှတ်နိုင်တယ်။

Conceptually—

```text
top
right
bottom
left
```

အလိုက် သတ်မှတ်နိုင်တယ်။

# 3. `gap` — Component နှစ်ခုကြား spacing

ဥပမာ—

```java
new MigLayout(
    "gap 10",
    "[][grow]",
    "[]"
);
```

ဒီဟာက component gaps ကို default အနေနဲ့ ထိန်းနိုင်တယ်။

ဒါပေမယ့် form တွေမှာ row/column အလိုက် ပို control ချင်လို့—

```java
"[][grow]20[][grow]"
```

လိုရေးတာ ပိုရှင်းတယ်။

ဒီမှာ `20` က column gap။

# 4. Form ကို Baseline Align လုပ်မယ်

ဒါက professional form တွေအတွက် အရမ်းအသုံးဝင်တယ်။

ဥပမာ—

```text
Student ID:  [__________]
Name:        [__________]
```

TextField နဲ့ Label တွေရဲ့ vertical position မညီတာမျိုး ဖြစ်နိုင်တယ်။

Text baseline ကို align ချင်ရင်—

```java
panelForm.add(
    new JLabel("Student ID:")
);

panelForm.add(
    txtStudentId,
    "growx, wrap"
);
```

MigLayout က form layout တွေအတွက် baseline alignment ကို အကောင်းဆုံးလုပ်ပေးနိုင်တယ်။

လိုအပ်ရင် component constraint တွေမှာ alignment ကို explicitly သတ်မှတ်နိုင်တယ်။

ဥပမာ—

```java
"aligny baseline"
```

ကို စဉ်းစားနိုင်တယ်။

အဓိက mental model က—

> Label နဲ့ TextField ကို top edge နဲ့မဟုတ်ဘဲ **စာရေးတဲ့ baseline** နဲ့ညှိတာ။

# 5. Label Width မညီတဲ့ Problem

ဥပမာ—

```text
Student ID:
Name:
Date of Birth:
Specialization:
```

Label lengths မတူဘူး။

MigLayout ကို—

```java
"[][grow]"
```

နဲ့ထားရင် first column က preferred width အလိုက် အလိုအလျောက်တွက်ပေးမယ်။

ဒါက ပိုကောင်းတယ်။

**Label width ကို `setPreferredSize()` နဲ့ hard-code လုပ်စရာ မလိုဘူး။**

မကောင်း—

```java
lblName.setPreferredSize(
    new Dimension(120, 30)
);
```

ဒီလို layout responsibility ကို component အတွင်းထည့်မထားသင့်ဘူး။

# 8. Button Width ကို Standardize လုပ်မယ်

```text

[ Update ]
[ Clear ]
```

width မတူရင် မသပ်ရပ်ဘူး။

```java

    btnSave,
    "sg buttons"
);

panelActions.add(
    btnUpdate,
    "sg buttons"

    btnClear,
    "sg buttons"
```

ဒါဆို—

```text

```

# 10. `split`

အခု interesting constraint တစ်ခု။

Button တစ်ခုတည်းရဲ့နေရာမှာ components အများကြီးကို same cell ထဲထားချင်တယ်ဆို `split` ကို သုံးနိုင်တယ်။

ဥပမာ—

```java
panelForm.add(
    new JLabel("Status:")
);

panelForm.add(
    cmbStatus,
    "split 2"
);

panelForm.add(
    lblStatusHint,
    "gapleft 10, wrap"
);
```

Concept:

```text
Status: [Active ▼]   Current student
```

ဆိုပြီး same logical position မှာ component နှစ်ခုထပ်တိုးနိုင်တယ်။

# 26. MigLayout + FlatLaf + Architecture

မင်းရဲ့ Swing application အတွက် အခု separation က ဒီလိုဖြစ်လာပြီ—

```text
                  StudentRegistration
                         │
        ┌────────────────┼────────────────┐
        │                │                │
     MigLayout         FlatLaf          Logic
        │                │                │
    Position          Appearance       Actions
```

ဥပမာ—

```java
panel.add(
    txtName,
    "growx, wrap"
);
```

MigLayout → **where / how size**

```java
txtName.putClientProperty(
    "FlatLaf.style",
    "arc:10"
);
```

FlatLaf → **how it looks**

```java
btnSave.addActionListener(...);
```

Business/UI behavior → **what happens**

ဒီ separation ကို နားလည်လာရင် Swing project တွေကို professional ပုံစံနဲ့ စဉ်းစားနိုင်ပြီ။

# 27. ဒီနေ့ရဲ့ Final Layout Pattern

မင်း Student Registration screen အတွက် ဒီ pattern ကို base အဖြစ်သုံးနိုင်တယ်—

```java
JPanel panelContent =
        new JPanel(
            new MigLayout(
                "insets 10, fill",
                "[grow]20[180!]",
                "[grow]"
            )
        );
```

Form—

```java
panelForm.setLayout(
    new MigLayout(
        "insets 20, fillx",
        "[][100:grow:500]15[][100:grow:500]",
        "[]8[]8[]8[]15[]"
    )
);
```

Photo—

```java
panelPhoto.setLayout(
    new MigLayout(
        "insets 10, fill",
        "[grow]",
        "[]10[grow]10[]"
    )
);
```

Actions—

```java
panelActions.setLayout(
    new MigLayout(
        "insets 10",
        "push[sg buttons][sg buttons][sg buttons]",
        "[]"
    )
);
```

Table—

```java
panelTable.setLayout(
    new MigLayout(
        "insets 10, fill"
    )
);

panelTable.add(
    scrollPaneStudents,
    "grow, push"
);
```

# 28. နောက်ဆုံး Mental Model

MigLayout ကို ဒီလိုပဲ အမြဲစဉ်းစား—

```text
1. Panel ရဲ့ structure ဘာလဲ?
       ↓
2. Column/row ဘယ်လိုခွဲမလဲ?
       ↓
3. ဘယ်ဟာ flexible?
       ↓
4. ဘယ်ဟာ fixed?
       ↓
5. Space ဘယ်လောက်ထားမလဲ?
       ↓
6. Window သေးရင် ဘယ်ဟာ shrink?
       ↓
7. Window ကြီးရင် ဘယ်ဟာ grow?
```

ဒီ 7 ခုကို စဉ်းစားတတ်ရင် MigLayout syntax ကို အကုန်မှတ်ထားစရာ မလိုဘူး။

## ဒီနေ့ လက်တွေ့ Challenge

မင်း `StudentRegistration` UI မှာ `debug` mode ဖွင့်ပြီး အောက်ပါ requirements ကို ကိုယ်တိုင် layout ချပါ—

```text
PERSONAL INFORMATION
─────────────────────

Student ID    Name

Date of Birth Gender

CONTACT INFORMATION
─────────────────────

Phone         Email

Address
[                    ]

                    [Save] [Update] [Clear]
```

ပြီးတော့ **window ကို 1200px → 900px → 700px** အထိ resize လုပ်ကြည့်ပါ။

ရည်ရွယ်ချက်က code ကို အလျင်လိုမရေးဘဲ **“ဒီ column က ဘာကြောင့် grow ရတာလဲ၊ ဒီ component က ဘာကြောင့် wrap ဖြစ်တာလဲ”** ဆိုတာကို ကိုယ်တိုင်ရှင်းပြနိုင်ဖို့ပါ။

နောက် Lesson မှာ **MigLayout ကို အသုံးပြုပြီး Login, Dashboard, CRUD Form ဆိုတဲ့ screen ၃ မျိုးကို တစ်ခုတည်းသော layout principles နဲ့ design လုပ်နည်း** ကို ဆက်သွားမယ်။
