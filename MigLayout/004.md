# ကောင်းပါပြီ! ကျွန်တော် Teacher အနေနဲ့ စနစ်တကျ သင်ပေးပါမယ်

## သင်ခန်းစာ ၁ — Layout ဆိုတာဘာလဲ (Foundation)

MigLayout ကို နားလည်ဖို့ **grid** (ဇယား) သဘောတရားနဲ့ စဉ်းစားရပါမယ်။ ဇယားတစ်ခုမှာ:

```
+----------+----------+
| Column 1 | Column 2 |
+----------+----------+
|  Row 1                |
+----------+----------+
|  Row 2                |
+----------+----------+
```

Component တစ်ခုကို `add()` လုပ်တိုင်း — default အနေနဲ့ **left → right** အစဉ်လိုက် ထည့်သွားပါတယ်။ `wrap` ဆိုတဲ့ constraint က "ဒီနေရာမှာ row အသစ် ပြောင်းပါ" လို့ ပြောတာပါ။

---

## လက်တွေ့ လေ့ကျင့်ခန်း ၁

ဒီ code ကို run ကြည့်ပါ:

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class Lesson1 extends JFrame {
    public Lesson1() {
        setLayout(new MigLayout());  // constraint ဘာမှမပါ

        add(new JButton("A"));
        add(new JButton("B"));
        add(new JButton("C"));

        pack();
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson1().setVisible(true));
    }
}
```

Run လုပ်ပြီးရင် button A, B, C တွေ ဘယ်လိုပုံစံ ပေါ်လာလဲ ကြည့်ပါ။

### 🤔 မေးခွန်း (ဖြေကြည့်ပါ):

button "A", "B", "C" တွေဟာ ဘယ်လို arrangement ပုံစံနဲ့ ပေါ်လာမလဲ?

## အဖြေ — Lesson 1 ရဲ့ Quiz

Button "A", "B", "C" တွေဟာ **တစ်တန်းတည်း (horizontal) side-by-side** ပေါ်လာမှာပါ။ Wrap constraint မထည့်ရင် MigLayout က default အနေနဲ့ **ဘယ်ကနေညာ တန်းတန်း ချသွားတယ်** — window ကျဉ်းလွန်းရင်တောင် ဆက်ချသွားပါတယ် (auto wrap မလုပ်ဘူး)။

## သင်ခန်းစာ ၂ — "wrap" နဲ့ Row ထိန်းချုပ်ခြင်း

`wrap N` ဆိုတာ **column N ခု ပြည့်တိုင်း row အသစ်ပြောင်း** ပါလို့ ပြောပြီးပြီနော်။ ဒါပေမဲ့ `wrap` ကို component တစ်ခုချင်းစီမှာလည်း သီးသန့်ထည့်လို့ရပါတယ်။

### Practice code:

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class Lesson2 extends JFrame {
    public Lesson2() {
        setLayout(new MigLayout("wrap 3"));  // column 3 ခုပြည့်ရင် wrap

        add(new JButton("1"));
        add(new JButton("2"));
        add(new JButton("3"));
        add(new JButton("4"));
        add(new JButton("5"));

        pack();
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson2().setVisible(true));
    }
}
```

### 🤔 မေးခွန်း:

Button 5 ခုကို `wrap 3` နဲ့ ချမယ်ဆိုရင် — row ဘယ်နှစ်တန်း ဖြစ်မလဲ? Row အနှစ်ဆုံးတန်းမှာ button ဘယ်နှစ်ခုပဲ ကျန်မလဲ?

---

## Component တစ်ခုချင်းစီအတွက် wrap ထားနိုင်ခြင်း

Layout-level `wrap N` မထည့်ဘဲ component တစ်ခုချင်းစီမှာ manual တွန်းချင်ရင်:

```java
add(new JButton("A"));
add(new JButton("B"), "wrap");   // ဒီ button ပြီးရင် row အသစ်ချက်ချင်း
add(new JButton("C"));
```

ဒါက "B ပြီးရင် တန်းအသစ်ပြောင်း" လို့ ညွှန်ပြောတာပါ — layout-level rule မလိုဘဲ တစ်နေရာချင်း control လုပ်ချင်ရင် သုံးပါတယ်။

## အဖြေ — Lesson 2

`wrap 3` နဲ့ button 5 ခုချမယ်ဆိုရင်:

```
[1] [2] [3]
[4] [5]
```

- **Row အရေအတွက် = 2 တန်း**
- **နောက်ဆုံးတန်း (Row 2) မှာ button 2 ခုပဲ ကျန်ပါတယ်** (4, 5) — column 3 မပြည့်လို့ ဘယ်ဘက်ကနေစပြီး ချထားပေးတာပါ (ညာဘက် space က အလွတ်ကျန်နေမှာ)

## သင်ခန်းစာ ၃ — Column & Row Constraints (Size ထိန်းချုပ်ခြင်း)

အခုအထိ column/row **size** ကို ဘာမှမထိန်းသေးပါဘူး — MigLayout က component ရဲ့ natural size ကိုပဲသုံးပါတယ်။ အခု column width ကို manual ထိန်းကြည့်ရအောင်:

```java
new MigLayout(
    layoutConstraints,      // "wrap 2" စသဖြင့်
    columnConstraints,      // column 1, column 2 အတွက်
    rowConstraints          // row 1, row 2 အတွက်
)
```

### Practice code:

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class Lesson3 extends JFrame {
    public Lesson3() {
        setLayout(new MigLayout(
            "wrap 2",              // layout: column 2 ပြည့်ရင် wrap
            "[100!][200!]"         // column: column1=100px fixed, column2=200px fixed
        ));

        add(new JButton("Short"));
        add(new JButton("Long Button Text"));
        add(new JButton("A"));
        add(new JButton("B"));

        pack();
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson3().setVisible(true));
    }
}
```

### အသစ်တွေ့ရမယ့် syntax:

|Syntax|အဓိပ္ပာယ်|
|---|---|
|`[100]`|column width **preferred** 100px (ချဲ့နိုင်/ကျုံ့နိုင်)|
|`[100!]`|column width **fixed** 100px (`!` = exactly, မပြောင်းနိုင်)|
|`[100::200]`|width **min 100, max 200** (range)|
|`[grow]`|space ကျန်ရင် ဒီ column ကို ချဲ့ပေး|
