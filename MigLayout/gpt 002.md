# Lesson 2 — Student Registration UI ကို MigLayout နဲ့ Professional ဖြစ်အောင်တည်ဆောက်မယ်

အခုတော့ MigLayout syntax တွေကို သီးသန့်မလေ့လာတော့ဘဲ **မင်းရဲ့ Student Management System မှာ တကယ်သုံးမယ့် screen တစ်ခု** ဆောက်ရင်းလေ့လာမယ်။

ဒီ Lesson ရဲ့ target UI က—

```text
┌──────────────────────────────────────────────────────────┐
│                 STUDENT REGISTRATION                      │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  Student ID     [____________________________]            │
│  Name           [____________________________]            │
│  Date of Birth  [____________]   Gender [Male ▼]         │
│  Phone          [____________]   Email  [____________]   │
│                                                          │
│  Address        [____________________________________]   │
│                 [____________________________________]   │
│                                                          │
│                         [Save] [Update] [Clear]           │
│                                                          │
├──────────────────────────────────────────────────────────┤
│                      Student Table                       │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

# 2. ပထမဆုံး Rule — UI ကို Section ခွဲ

```text
├── Header
├── Form
│   ├── Personal Information
│   ├── Contact Information
│   └── Address
│
├── Actions
│
└── Table
```

Swing မှာဆို—

```java
JPanel panelHeader;
JPanel panelForm;
JPanel panelActions;
JPanel panelTable;
```

# 3. Header Panel

NetBeans Drag & Drop နဲ့ `JPanel` တစ်ခုထည့်ပြီး `panelHeader` လို့ name ပေး။

ပြီးရင်—

```java
panelHeader.setLayout(
    new MigLayout(
        "insets 15, fillx"
    )
);
```

Label ထည့်—

```java
JLabel lblTitle =
        new JLabel("STUDENT REGISTRATION");

panelHeader.add(lblTitle);
```

FlatLaf သုံးနေတာဆိုရင် font ကို style လုပ်နိုင်တယ်—

```java
lblTitle.putClientProperty(
    "FlatLaf.style",
    "font:bold +4"
);
```

Column 2 ခု—


### Row

```text

...
```

row တစ်ခုနဲ့တစ်ခုကြား gap သတ်မှတ်ထားတယ်။

# 17. ဒါပေမယ့် ဒီမှာ Design Problem တစ်ခုရှိတယ်

မင်း Drag & Drop GUI Builder က already `panelForm` ထဲမှာ—

```text
txtStudentId
txtName
txtDob
...
```

components တွေ add လုပ်ထားရင်၊

```java
panelForm.add(...)
```

နဲ့ ပြန် add လုပ်ရင် duplicate ဖြစ်နိုင်တယ်။

အဲဒီအတွက် **နည်း ၂ ခု** ရှိတယ်။

### Method A — GUI Builder ကို Component Creation အတွက်သုံး

Components ကို NetBeans မှာ create လုပ်၊ layout ကို code က control လုပ်။

### Method B — Form Panel အားလုံးကို code နဲ့ build

Complex screen တွေအတွက် ဒီနည်းက ပို clean ဖြစ်တတ်တယ်။

မင်းအခုတော့ **Method A** နဲ့ ဆက်သွားတာ အလွယ်ဆုံး။

MigLayout မှာ ဒီလိုပြောင်းစဉ်းစား။

### Before

```text
"Column 1, Row 2"
```

### After

```text
"ဒီ component က ဒီ component နောက်မှာ"
"ဒီ component က available width ကိုယူ"
"ဒီ component က row ပြီးရင် wrap"
"ဒီ component က 3 columns span"
```

ဥပမာ—

```java
"growx, wrap"
```

ဆိုရင် coordinate မပြောဘူး။

**Relationship** ပြောတယ်။

# 21. မင်း Project အတွက် Recommended Layout

မင်း Student Management System မှာ ဒီ hierarchy ကို သုံးရင်ကောင်းမယ်—

```text
StudentRegistration JFrame
│
└── MigLayout
    │
    ├── Header
    │
    ├── Content
    │   ├── Student Form
    │   │   └── MigLayout
    │   │
    │   └── Photo Panel
    │       └── MigLayout
    │
    ├── Action Buttons
    │
    └── Student Table
```

Photo ပါလာရင် form နဲ့ photo ကို side-by-side လုပ်လို့ရတယ်။

```text

│                                              │
```

ဒီနေ့ မင်းရဲ့ `StudentRegistration` form ကို ဒီ structure နဲ့ ပြန်ဆောက်ပါ—

```text
Student ID
Name
DOB + Gender
Phone + Email
Address
Save / Update / Clear
```

ပြီးရင် **Photo Panel ကို ညာဘက်မှာ 150×180 အရွယ်ထားပြီး Form Panel နဲ့ side-by-side** ဖြစ်အောင် ဆက်တည်ဆောက်မယ်။ အဲဒီ Lesson မှာ `[][]`, `span`, `dock`, `push`, nested `MigLayout` ကို တကယ်အသုံးချပြီး **responsive-looking Swing UI** တည်ဆောက်နည်းကို သင်မယ်။
