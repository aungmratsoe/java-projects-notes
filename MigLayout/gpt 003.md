# Lesson 3 — Form + Photo Panel ကို MigLayout နဲ့ Professional Layout ချမယ်

အခုတော့ `MigLayout` ရဲ့ **nested panel + column relationship + `span` + `push` + `dock`** ကို လက်တွေ့သုံးမယ်။

Target UI:

```text
┌──────────────────────────────────────────────────────────────┐
│                 STUDENT REGISTRATION                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌────────────────────────────────┐    ┌─────────────────┐   │
│  │ Student ID: [______________]  │    │                 │   │
│  │ Name:       [______________]  │    │                 │   │
│  │ DOB: [________] Gender [____] │    │      PHOTO      │   │
│  │ Phone: [______] Email [______]│    │                 │   │
│  │ Address: [__________________] │    │                 │   │
│  │          [__________________] │    │                 │   │
│  └────────────────────────────────┘    └─────────────────┘   │
│                                                              │
│                                  [Browse] [Remove]            │
│                                                              │
│                         [Save] [Update] [Clear]               │
├──────────────────────────────────────────────────────────────┤
│                       Student Table                           │
└──────────────────────────────────────────────────────────────┘
```

ဒီမှာ အရေးကြီးတာက **JFrame တစ်ခုတည်းမှာ components အားလုံးကို layout မချတော့ဘူး**။

# 2. Main JFrame Layout


# 15. Why Nested JPanel?

ဒီအချက်က architecture အတွက် အရေးကြီးတယ်။

မင်းက ဒီလိုလုပ်လို့ရတယ်—

```java
JFrame
   ↓
MigLayout
   ↓
Photo
   ↓
Button
```

ဒါပေမယ့် UI complexity တက်လာရင် မရှင်းတော့ဘူး။

Nested panel—

```text
Main
│
├── Content
│   ├── Form
│   └── Photo
│       └── PhotoButtons
```

ဆိုတော့ တစ်ခုချင်းစီမှာ **ကိုယ်ပိုင် layout responsibility** ရှိတယ်။

# 22. `grow` vs `push` ကို တစ်ခါထပ်ကြည့်

ဒီနှစ်ခုက MigLayout လေ့လာရင် အရမ်းရှုပ်တတ်တယ်။

### `grow`

Component ကို size ပိုကြီးစေတယ်။

```java
"growx"
```

### `push`

ကျန်တဲ့ free space ကို component ရဲ့ဘက်ဆီ သယ်ပေးတယ်။

ဥပမာ button—

```java
panel.add(
    btnSave,
    "pushx"
);
```

ဒါကြောင့်—

```text
[                     Save]
```

လို position ကို ပြောင်းနိုင်တယ်။

# 24. Real `setupLayout()`

အခု အားလုံးပေါင်းပြီး structure ကိုကြည့်။

```java
private void setupLayout() {

    // Main frame
    setLayout(
        new MigLayout(
            "fill, insets 0",
            "[grow]",
            "[]10[grow]10[]10[grow]"
        )
    );


    // Header
    panelHeader.setLayout(
        new MigLayout(
            "insets 15, fillx"
        )
    );

    add(
        panelHeader,
        "growx, wrap"
    );


    // Content
    panelContent.setLayout(
        new MigLayout(
            "insets 10, fill",
            "[grow]20[180!]",
            "[grow]"
        )
    );

    add(
        panelContent,
        "growx, wrap"
    );


    // Form
    panelForm.setLayout(
        new MigLayout(
            "insets 10, fillx",
            "[][grow]20[][grow]",
            "[]10[]10[]10[]10[]10[]"
        )
    );

    panelContent.add(
        panelForm,
        "grow"
    );


    // Photo
    panelPhoto.setLayout(
        new MigLayout(
            "insets 10, fill",
            "[grow]",
            "[][grow][]"
        )
    );

    panelContent.add(
        panelPhoto,
        "growy"
    );


    // Actions
    panelActions.setLayout(
        new MigLayout(
            "insets 10",
            "push[][]10[]",
            "[]"
        )
    );

    add(
        panelActions,
        "growx, wrap"
    );


    // Table
    panelTable.setLayout(
        new MigLayout(
            "insets 10, fill"
        )
    );

    add(
        panelTable,
        "grow, push"
    );
}
```

# 27. `MigLayout` ကို ဒီလို Mental Model ထား

ဒီ 3 layers ကို မမေ့နဲ့။

```text
Layer 1 — JFrame
    ↓
Panel relationships

Layer 2 — JPanel
    ↓
Component relationships

Layer 3 — Component Constraint
    ↓
grow / span / wrap / push / align
```

ဥပမာ—

```java
panelContent
```

က

```text

```

relationship ကို handle တယ်။

```text
Label ←→ Field
```

relationship ကို handle တယ်။

ပြီးတော့ component constraint က

```text
growx
wrap
span
```

တို့နဲ့ **component behavior** ကို handle တယ်။

ဒီလို စဉ်းစားနိုင်ရင် MigLayout syntax ကို memorize လုပ်စရာ အများကြီးမလိုတော့ဘူး။

# 29. နောက်တစ်ဆင့် — Responsive Form Thinking

အခု UI က desktop size တစ်ခုမှာ အဆင်ပြေပြီ။

ဒါပေမယ့် JFrame ကို—

```text
1200 × 800
```

ကနေ—

```text
800 × 600
```

ပြောင်းလိုက်ရင် ဘယ်လို behave လုပ်မလဲ?

ဒီနေရာက MigLayout ရဲ့ တကယ့်အားသာချက်ကို စတင်မြင်ရမယ့်အပိုင်း။

နောက် Lesson မှာ **`grow`, `push`, `min/max width`, `hideMode`, `wrap`, `platform`, component priority** စတာတွေကို သုံးပြီး **window size ပြောင်းသွားလည်း UI မပျက်အောင်** layout ချတဲ့နည်းကို လက်တွေ့ဆက်သွားမယ်။
