# Lesson 4 — MigLayout Responsive UI Thinking

အခု lesson က MigLayout ကို syntax သိရုံကနေ **UI ကို window size ပြောင်းလဲတဲ့အခါ ဘယ်လို adapt ဖြစ်အောင် design လုပ်မလဲ** ဆိုတာကို လေ့လာမယ့်အပိုင်းပါ။

မင်းရဲ့ Student Registration screen ကို—

```text
1200 × 800
```

ကနေ

```text
800 × 600
```

ဒါမှမဟုတ်

```text
600 × 800
```

ပြောင်းလိုက်ရင် component တွေ မပျက်ဘဲ အတတ်နိုင်ဆုံး သင့်တော်အောင် ပြောင်းဖို့လိုတယ်။

---

# 1. Responsive Layout ဆိုတာဘာလဲ?

ဥပမာ fixed width ပဲထားရင်—

```text
1200px

Student ID: [____________________________]
```

ကောင်းတယ်။

Window ကို 800px လျှော့လိုက်ရင်—

```text
Student ID: [____________________________]
                         ← overflow / cramped
```

ဖြစ်နိုင်တယ်။

Responsive layout ဆိုတာ—

```text
Window ကြီး
   ↓
Input ကြီး

Window သေး
   ↓
Input သေး

Space မလောက်
   ↓
layout ကို ပြောင်း
```

ဆိုတဲ့ thinking ဖြစ်တယ်။

---

# 2. MigLayout မှာ အဓိက Rule

ဒီလို hard-code မလုပ်နဲ့—

```java
panel.add(txtName, "w 500!");
```

`500!` ဆိုတာ fixed width ဖြစ်သွားတယ်။

ပိုကောင်းတာ—

```java
panel.add(txtName, "growx");
```

ဒါဆို available width အတိုင်း input က grow လုပ်နိုင်တယ်။

# 3. `growx` ကို တကယ်နားလည်

ဥပမာ—

```java
new MigLayout(
    "fillx",
    "[][grow]",
    "[]"
);
```

ဆိုပါစို့။

```text
Label          Input
─────          ───────────────────
```

Window width 1200:

```text
Name:          [_______________________________]
```

Window width 700:

```text
Name:          [________________]
```

Input က ကျန်တဲ့ width ကိုလိုက်ယူမယ်။

ဒါက responsive layout ရဲ့ အခြေခံပဲ။

# 4. `grow` vs `growx` vs `growy`

ဒီ 3 ခုကို သေချာခွဲပါ။

### `growx`

Horizontal ပဲ grow။

```java
"growx"
```

### `growy`

Vertical ပဲ grow။

```java
"growy"
```

### `grow`

X + Y နှစ်ခုလုံး grow။

```java
"grow"
```

ဥပမာ JTable scroll pane:

```java
panel.add(
    scrollPane,
    "grow"
);
```

က အရမ်းသင့်တော်တယ်။

# 5. Column Constraint က Responsive Behavior ကို အဓိကဆုံးဆုံးဖြတ်တယ်

ဒီဟာ—

```java
"[][grow]"
```

နဲ့

```java
"[][500!]"
```

ကြား ကွာခြားချက်က အရမ်းကြီးတယ်။

### `[][grow]`

```text

```

### `[][500!]`

```text
Label | exactly 500px
```

Responsive UI အတွက် အများအားဖြင့်—

```java
[][grow]
```

လို flexible constraint သုံးမယ်။

# 6. `min` / `max` Width

တချို့ component ကို အရမ်းသေးသွားတာလည်း မလိုချင်ဘူး။

ဥပမာ Name field:

```java
"[100:grow:500]"
```

ဒီ syntax ကို ဒီလိုနားလည်ပါ—

```text
minimum : grow : maximum
```

ဆိုတော့—

```text
min = 100
preferred = grow
max = 500
```

လို စဉ်းစား။

ဥပမာ column—

```java
new MigLayout(
    "",
    "[][100:grow:500]"
);
```

ဒါဆို input က—

```text
100px ထက် မသေး
500px ထက် မကြီး
အလယ်မှာ available space ကိုလိုက်
```

ဖြစ်မယ်။

ဒါက professional UI မှာ တော်တော်အသုံးဝင်တယ်။

# 7. Student Form မှာ Min / Max သုံးမယ်

အရင်က—

```java
"[][grow]20[][grow]"
```

အခု—

```java
"[][100:grow:500]20[][100:grow:500]"
```

လိုလုပ်လို့ရတယ်။

```text
Window too small
   ↓

```

# 12. Responsive Method

```java
private boolean compactMode = false;

private void updateResponsiveLayout() {

    int width = getWidth();

    if (width < 900 && !compactMode) {

        compactMode = true;

        setupCompactForm();

    } else if (width >= 900 && compactMode) {

        compactMode = false;

        setupDesktopForm();
    }
}
```

ဒါက simple breakpoint system ပါ။

# 18. Responsive Layout ကို အကုန်တစ်နေရာတည်းမရေး

ဒီလို မလုပ်နဲ့—

```java
if (...) {
    // 100 lines
}
else {
    // another 100 lines
}
```

Better—

```java
private void updateResponsiveLayout() {

    if (isCompactMode()) {
        applyCompactLayout();
    } else {
        applyDesktopLayout();
    }
}
```

ပြီးတော့—

```java
private void applyDesktopLayout() {
    setupDesktopContent();
    setupDesktopForm();
}
```

```java
private void applyCompactLayout() {
    setupCompactContent();
    setupCompactForm();
}
```

ဒီလို structure က ဖတ်လို့ကောင်းတယ်။

# 19. `hideMode` ကို လေ့လာမယ်

Photo ကို small mode မှာ မပြချင်ဘူးဆိုပါစို့။

Swing component ကို—

```java
panelPhoto.setVisible(false);
```

လုပ်လို့ရတယ်။

ဒါပေမယ့် MigLayout မှာ hidden component က space ဘယ်လိုယူမလဲဆိုတာကို `hidemode` နဲ့ control လုပ်နိုင်တယ်။ MigLayout မှာ component visibility အလိုက် layout behavior ကို ထိန်းချုပ်ဖို့ `hidemode` constraint ရှိတယ်။

ဥပမာ—

```java
panelContent.add(
    panelPhoto,
    "growy, hidemode 3"
);
```

အခု detail ကို မှတ်ဖို့ထက် concept ကို မှတ်:

```text
Visible
   ↓
takes space

Hidden
   ↓
can keep or remove space
depending on hidemode
```

---

# 20. MigLayout `hidemode` Mental Model

အလွယ်ဆုံး—

```text
hidemode 0
    hidden → still behaves mostly like normal

hidemode 1
    hidden → no size but gaps may remain

hidemode 2
    hidden → no size, gaps adjusted

hidemode 3
    hidden → completely removed from layout
```

ဒါကြောင့်—

```java
"growy, hidemode 3"
```

ဆိုရင် Photo panel မမြင်ရတော့ရင် layout ထဲက space ကိုလည်း ဖယ်ပေးနိုင်တယ်။

# 23. `priority` နဲ့ `shrink priority`
