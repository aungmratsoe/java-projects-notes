JTable ရဲ့ internal column width တွေကို **MigLayout က တိုက်ရိုက် control မလုပ်နိုင်ပါ**။ အကြောင်းက MigLayout သည် panel ပေါ်က component (scrollPane) ရဲ့ size/position ကိုပဲ manage လုပ်တာဖြစ်ပြီး၊ scrollPane ထဲက table ရဲ့ column တွေကတော့ Swing ရဲ့ `TableColumnModel` က သီးခြား manage လုပ်ပါတယ်။ ဒါကြောင့် column width ချင့်ချိန်ဖို့ `TableColumn` API ကို သုံးရပါမယ်။

## Column width သတ်မှတ်နည်း

```java
TableColumn itemCol = orderTable.getColumnModel().getColumn(0); // "Item" column
itemCol.setPreferredWidth(200);   // ကျယ်အောင်

TableColumn qtyCol = orderTable.getColumnModel().getColumn(1);
qtyCol.setPreferredWidth(50);     // သေးအောင်

TableColumn priceCol = orderTable.getColumnModel().getColumn(2);
priceCol.setPreferredWidth(80);

TableColumn subtotalCol = orderTable.getColumnModel().getColumn(3);
subtotalCol.setPreferredWidth(80);
```

**သတိထားရမှာ** — `setPreferredWidth()` က "အကြံပြုချက်" (hint) လိုမျိုးပါ။ Table ရဲ့ `autoResizeMode` ပေါ်မူတည်ပြီး အလိုအလျောက် ချိန်ညှိတတ်ပါတယ်။

## Auto-resize mode ကို နားလည်ဖို့

```java
orderTable.setAutoResizeMode(JTable.AUTO_RESIZE_ALL_COLUMNS); // default
```

Mode ရွေးစရာတွေ:

|Mode|ဘယ်လိုအလုပ်လုပ်လဲ|
|---|---|
|`AUTO_RESIZE_OFF`|column width fix ထားချင်ရင် — window resize လုပ်ရင်တောင် မပြောင်း|
|`AUTO_RESIZE_ALL_COLUMNS`|(default) column အားလုံး proportion အတိုင်း ချဲ့/ကျုံ့|
|`AUTO_RESIZE_LAST_COLUMN`|နောက်ဆုံး column တစ်ခုတည်း space အားလုံးယူ|

POS app မှာ "Item" column ကို အမြဲကျယ်အောင် ထားချင်ရင် — column အားလုံးကို preferred width သတ်မှတ်ပြီး `AUTO_RESIZE_OFF` (fix လုပ်ချင်ရင်) ဒါမှမဟုတ် `AUTO_RESIZE_ALL_COLUMNS` (proportion အတိုင်း ချဲ့စေချင်ရင်) ရွေးလို့ရပါတယ်။

## Full example (POS Order table)

```java
String[] columns = {"Item", "Qty", "Price", "Subtotal"};
model = new DefaultTableModel(columns, 0);
orderTable = new JTable(model);

// column width ချိန်ညှိ
orderTable.getColumnModel().getColumn(0).setPreferredWidth(220); // Item - ကျယ်
orderTable.getColumnModel().getColumn(1).setPreferredWidth(50);  // Qty - သေး
orderTable.getColumnModel().getColumn(2).setPreferredWidth(70);  // Price
orderTable.getColumnModel().getColumn(3).setPreferredWidth(70);  // Subtotal

orderTable.setAutoResizeMode(JTable.AUTO_RESIZE_ALL_COLUMNS);

JScrollPane scrollPane = new JScrollPane(orderTable);
panel.add(scrollPane, "grow, push"); // MigLayout ကတော့ scrollPane ကိုပဲ manage
```

ဒီမှာ layer နှစ်ခု ခွဲပြထားတာသတိထားပါ — **MigLayout** က scrollPane ရဲ့ outer size ကို control လုပ်ပြီး၊ **TableColumnModel** က ၄င်း scrollPane အတွင်းက column width တွေကို control လုပ်ပါတယ်။ ဒီနှစ်ခု အပြန်အလှန် မထိခိုက်ပါဘူး။
