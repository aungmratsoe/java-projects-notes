# Lesson 8 — MigLayout + FlatLaf + CardLayout နဲ့ Real Dashboard

အခုကစပြီး MigLayout ကို သီးသန့်မလေ့လာတော့ဘူး။ **Layout + Theme + Page Navigation** သုံးခုကို ပေါင်းပြီး တကယ်အသုံးဝင်တဲ့ Swing Dashboard architecture တစ်ခု တည်ဆောက်မယ်။

Target—

```text
┌──────────────────────────────────────────────────────────────┐
│  ☰  STUDENT MANAGEMENT SYSTEM              Aung Mrat ▼      │
├───────────────┬──────────────────────────────────────────────┤
│               │                                              │
│ Dashboard     │                                              │
│ Students      │              CURRENT PAGE                   │
│ Courses       │                                              │
│ Teachers      │                                              │
│ Reports       │                                              │
│               │                                              │
│               │                                              │
│ Logout        │                                              │
└───────────────┴──────────────────────────────────────────────┘
```


# 1. Technology တစ်ခုချင်းစီရဲ့ တာဝန်

ဒီ ၃ ခုကို မရောနဲ့။

```text
MigLayout
    ↓
Component တွေ ဘယ်နေရာမှာရှိမလဲ?

FlatLaf
    ↓
Component တွေ ဘယ်လိုမြင်ရမလဲ?

CardLayout
    ↓
ဘယ် page ကို လက်ရှိပြမလဲ?
```

ဒီ separation ကို နားလည်ရင် Swing architecture က အများကြီးရှင်းသွားမယ်။

# 9. `updateActiveMenu()`

လွယ်လွယ်—

```java
private void updateActiveMenu(
        String pageName) {

    resetMenuButtons();

    switch (pageName) {

        case "dashboard" ->
                styleActive(btnDashboard);

        case "students" ->
                styleActive(btnStudents);

        case "courses" ->
                styleActive(btnCourses);
    }
}
```

`resetMenuButtons()`—

```java
private void resetMenuButtons() {

    btnDashboard.putClientProperty(
            "FlatLaf.style",
            null
    );

    btnStudents.putClientProperty(
            "FlatLaf.style",
            null
    );

    btnCourses.putClientProperty(
            "FlatLaf.style",
            null
    );
}
```

Active—

```java
private void styleActive(
        JButton button) {

    button.putClientProperty(
            "FlatLaf.style",
            "background:#2563EB; foreground:#FFFFFF; arc:10"
    );
}
```

ဒီမှာ **MigLayout မပါဘူး**။

ဘာကြောင့်လဲ?

Active button ရဲ့ **appearance** ပဲပြောင်းတာမို့။

# 25. Navigation Class သီးခြားလုပ်လို့ရတယ်

Project ကြီးလာရင်—

```text
navigation/
    NavigationManager.java
```

လုပ်နိုင်တယ်။

```java
public class NavigationManager {

    private final CardLayout cardLayout;
    private final JPanel container;

    public NavigationManager(
            CardLayout cardLayout,
            JPanel container) {

        this.cardLayout = cardLayout;
        this.container = container;
    }

    public void show(String page) {

        cardLayout.show(
                container,
                page
        );
    }
}
```

DashboardFrame မှာ—

```java
NavigationManager navigation =
        new NavigationManager(
                cardLayout,
                pageContainer
        );
```

ပြီးရင်—

```java
navigation.show("students");
```

ဆိုရုံပဲ။
