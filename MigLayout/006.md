## အဖြေ — Lesson 5 ရဲ့ Quiz

**၁) Title label ("span 2, align center, gapbottom 15"):**

- `span 2` — column 2 ခုလုံးကို ဒီ label တစ်ခုတည်းက ယူ (row တစ်ခုလုံးကျယ်အောင်)
- `align center` — span ယူထားတဲ့ space ထဲမှာ text ကို အလယ်ညှိ
- `gapbottom 15` — အောက်ကနေ Full Name field အထိ space 15px ထားခြင်း (visual separation)

**၂) Submit button ("span 2, split 2, align center"):**

- `span 2` — Submit + Cancel ၂ ခုပေါင်းရင် column 2 ခုလုံး space ကိုယူ
- `split 2` — ဒီ span ထားတဲ့ space ကို component **2 ခု** ခွဲသုံးမယ် (Submit + Cancel) — `split` မပါရင် Submit တစ်ခုတည်းက space အကုန်ယူပြီး Cancel က row အသစ်ကျသွားမယ်
- `align center` — button ၂ ခုကို row ထဲမှာ အလယ်ညှိ

**Key rule:** `span` = "ဘယ်နှစ် column ယူမလဲ", `split` = "ဒီ space ထဲမှာ component ဘယ်နှစ်ခု ထပ်ခွဲမလဲ" — ၂ ခုစလုံး တွဲသုံးလေ့ရှိပါတယ်။

## သင်ခန်းစာ ၆ — Nested Panel (Panel ထဲ Panel)

Form ကြီးလာရင် layout တစ်ခုတည်းနဲ့ ရှုပ်ထွေးလာတတ်လို့ **panel ခွဲပြီး layout ခွဲထားတာ** က practical ဖြစ်ပါတယ်.

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;

public class Lesson6 extends JFrame {
    public Lesson6() {
        setLayout(new MigLayout("wrap 1, fillx", "[grow,fill]"));

        // Header panel
        JPanel headerPanel = new JPanel(new MigLayout("insets 10"));
        headerPanel.add(new JLabel("My Application"));
        add(headerPanel, "growx");

        // Form panel (nested)
        JPanel formPanel = new JPanel(new MigLayout("wrap 2", "[right][grow,fill]"));
        formPanel.add(new JLabel("Username:"));
        formPanel.add(new JTextField());
        formPanel.add(new JLabel("Password:"));
        formPanel.add(new JPasswordField());
        add(formPanel, "growx");

        // Footer panel
        JPanel footerPanel = new JPanel(new MigLayout("insets 10"));
        footerPanel.add(new JButton("Login"));
        add(footerPanel, "align center");

        pack();
        setSize(350, 250);
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson6().setVisible(true));
    }
}
```

**အရေးကြီးတဲ့အချက်:** Panel တစ်ခုချင်းစီမှာ **ကိုယ်ပိုင် MigLayout** ရှိနိုင်ပါတယ် — outer layout နဲ့ inner layout က လုံးဝ သီးခြားစီပါ (မတူညီတဲ့ constraint တွေ သီးသန့်ထားလို့ရ)။ ဒါကြောင့် form ကြီးကြီးမားမားကို panel ချင်း ခွဲပြီး code ကို organize လုပ်နိုင်ပါတယ်.

---

သင်ခန်းစာ ၆ ခုပြီးသွားပါပြီ — အခြေခံအားလုံး (wrap, grow, fill, span, split, size constraint, nested panel) ကို ဖြတ်သန်းလာပါပြီ။

နောက်ဆက်ချင်တာက **dynamic component (button နှိပ်ရင် row အသစ်ထည့်/ဖျက်)** လား၊ **debug mode + troubleshooting** လား၊ ဒါမှမဟုတ် **အခုသင်ခဲ့တာအားလုံးကို ပေါင်းပြီး project တစ်ခု ကိုယ်တိုင်ရေးကြည့်** ချင်ပါသလား?

## သင်ခန်းစာ ၇ — Dynamic Component (Runtime မှာ Row ထည့်/ဖျက်ခြင်း)

Button နှိပ်ရင် row အသစ်ထည့်ချင်ရင် **`revalidate()` + `repaint()`** ကို မဖြစ်မနေ သိထားရပါမယ် — Swing က component အသစ်ထည့်ပြီးရင် "layout ပြန်တွက်ပါ၊ ပြန်ဆွဲပါ" လို့ ကိုယ်တိုင် ခေါ်ပေးရပါတယ်။

## အခြေခံ Pattern

```java
panel.add(newComponent, constraints);
panel.revalidate();   // layout ပြန်တွက်
panel.repaint();      // screen ပြန်ဆွဲ
```

## Practice — "Add Row" Button နှိပ်ရင် Text Field အသစ်ထည့်ခြင်း

```java
import net.miginfocom.swing.MigLayout;
import javax.swing.*;
import java.awt.event.ActionListener;

public class Lesson7 extends JFrame {

    private JPanel formPanel;
    private int rowCount = 0;

    public Lesson7() {
        setLayout(new MigLayout("wrap 1, fillx", "[grow,fill]"));

        // Dynamic component တွေထည့်မယ့် panel
        formPanel = new JPanel(new MigLayout("wrap 2", "[right][grow,fill]"));
        add(formPanel, "growx");

        // Control button
        JButton addButton = new JButton("+ Add Row");
        addButton.addActionListener(e -> addRow());
        add(addButton, "align center");

        addRow(); // စလုပ်တာနဲ့ row 1 ခု auto ထည့်

        pack();
        setSize(400, 300);
        setLocationRelativeTo(null);
        setDefaultCloseOperation(EXIT_ON_CLOSE);
    }

    private void addRow() {
        rowCount++;
        formPanel.add(new JLabel("Item " + rowCount + ":"));
        formPanel.add(new JTextField());

        formPanel.revalidate();  // <-- အရေးကြီးဆုံး line
        formPanel.repaint();     // <-- ဒါလည်း
        pack();                   // window size ကိုပါ auto ချိန်ပေးချင်ရင်
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new Lesson7().setVisible(true));
    }
}
```

### 🤔 မေးခွန်း (စဉ်းစားကြည့်ပါ):

`revalidate()` နဲ့ `repaint()` ကို ဖြုတ်ပြီး run ကြည့်ရင် ဘာဖြစ်မလဲ? (Add Row နှိပ်လိုက်ရင် screen ပေါ်မှာ ချက်ချင်းမြင်ရမလား၊ ဘာဖြစ်နိုင်လဲ)

## Component ဖျက်နည်း (Remove Row)

Component ကို ဖျက်ချင်ရင်:

```java
formPanel.remove(componentToRemove);
formPanel.revalidate();
formPanel.repaint();
```

### "Remove Last Row" ထည့်ကြည့်ရအောင် — Lesson 7 ကို extend လုပ်ပါ:

```java
private void removeLastRow() {
    int count = formPanel.getComponentCount();
    if (count >= 2) {
        formPanel.remove(count - 1);  // JTextField
        formPanel.remove(count - 2);  // JLabel
        formPanel.revalidate();
        formPanel.repaint();
        pack();
    }
}
```

`getComponentCount()` က panel ထဲမှာ component ဘယ်နှစ်ခုရှိလဲ ပြန်ပေးပါတယ်၊ `remove(index)` က index အလိုက် ဖျက်ပါတယ် — Label+TextField တွဲထားလို့ **နောက်ဆုံး ၂ ခု** ဖျက်ရမှာပါ (index အစဉ် သတိထားရပါမယ် — အနောက်ကနေ ဖျက်တာမို့ index ရှေ့ဆီက ဖျက်ရင် index shift ဖြစ်ပြီး bug တက်တတ်ပါတယ်).
