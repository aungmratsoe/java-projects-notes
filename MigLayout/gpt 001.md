ဟုတ်ပြီ။ **MigLayout** ကို Java Swing + Maven + NetBeans Drag & Drop project မှာ ဘယ်လိုသုံးရမလဲကို အခြေခံကနေ တကယ်အသုံးချနိုင်တဲ့အထိ Burmese နဲ့သင်မယ်။

## 1. MigLayout ဆိုတာဘာလဲ?

Swing ရဲ့ default layouts ဖြစ်တဲ့

```java
FlowLayout
BorderLayout
GridLayout
GridBagLayout
```

တွေထက် **UI layout ကို စာနဲ့တိတိကျကျ control လုပ်နိုင်တဲ့ third-party layout manager** တစ်ခုက MigLayout ပါ။

ဥပမာ—

```text
┌─────────────────────────────────────────┐
│ Student Registration                    │
│                                         │
│ Student ID:    [______________]         │
│ Name:          [______________]         │
│ Date of Birth: [______________]         │
│ Gender:        [ Male ▼ ]               │
│                                         │
│                 [Save] [Update]         │
└─────────────────────────────────────────┘
```

ဒီလို UI ကို `GridBagLayout` နဲ့ရေးရင် code တော်တော်ရှုပ်နိုင်တယ်။ MigLayout မှာတော့ constraint တွေနဲ့ တိုတောင်းစွာရေးနိုင်တယ်။

---

# 2. Maven Dependency

Maven project ရဲ့ `pom.xml` မှာ MigLayout Swing dependency ထည့်ပါ။

```xml
<dependency>
    <groupId>com.miglayout</groupId>
    <artifactId>miglayout-swing</artifactId>
    <version>11.4</version>
</dependency>
```

ပြီးရင် NetBeans မှာ project ကို reload လုပ်ပါ။

Maven dependency ကတော့:

```text
Maven
   ↓
miglayout-swing
   ↓
javax.swing / java.awt components
```

# 4. Component ထည့်တဲ့နည်း

```java
JLabel lblName = new JLabel("Name:");

panel.add(lblName);

```

MigLayout က components တွေကို default အနေနဲ့ row တစ်ကြောင်းထဲ arrange ပေးမယ်။

# 5. `wrap` ကိုနားလည်မယ်

ဒါက MigLayout ရဲ့ အရေးကြီးဆုံး constraint တစ်ခု။

```java
panel.add(new JLabel("Name:"));
panel.add(new JTextField(20), "wrap");

panel.add(new JLabel("Phone:"));
panel.add(new JTextField(20), "wrap");
```

Result:

```text
Name:     [________________]
Phone:    [________________]
```

`wrap` ဆိုတာ—

> ဒီ component ပြီးရင် နောက် row ကို ဆင်းပါ။

# 7. Column ကို သတ်မှတ်မယ်

MigLayout ရဲ့ အားသာချက်က **column constraints** ကို တိုက်ရိုက်ရေးလို့ရတာ။

```java
JPanel panel = new JPanel(
    new MigLayout(
        "[][]"
    )
);
```

`[][]` ဆိုတာ column ၂ ခုလို့ စဉ်းစားပါ။

```text
Column 1      Column 2
────────      ────────
Label         TextField
Label         TextField
Label         TextField
```

ဒါကြောင့်—

```java
panel.add(new JLabel("Name"));
panel.add(new JTextField());

panel.add(new JLabel("Phone"));
panel.add(new JTextField());
```

လို row အလိုက် အလုပ်လုပ်တယ်။

# 9. `growx`

ဒီ constraint ကို **မင်းအများဆုံးသုံးမယ်**။

```java

    new JTextField();

    txtName,
    "growx"
```

`growx` ဆိုတာ—

> horizontal direction မှာ available space ရရင် ကြီးပါ။

ဒါပေမယ့် `pushx` နဲ့လည်း relationship ရှိတယ်။ အခုတော့ simple အနေနဲ့ `growx` ကိုပဲမှတ်။

# 10. `fillx`

# 11. `span`

ဒါက **column အများကြီးကို component တစ်ခုတည်းသုံးချင်တဲ့အခါ** သုံးတယ်။

# 24. MigLayout vs GridBagLayout

မင်းက architecture ကိုလေ့လာနေတဲ့အတွက် ဒီ comparison သိထားရမယ်။

### GridBagLayout

```java
GridBagConstraints gbc =
    new GridBagConstraints();

gbc.gridx = 1;
gbc.gridy = 0;
gbc.weightx = 1;
gbc.fill =
    GridBagConstraints.HORIZONTAL;

panel.add(
    txtName,
    gbc
);
```

### MigLayout

```java
panel.add(
    txtName,
    "growx, wrap"
);
```

တူညီတဲ့ layout requirement ကို MigLayout က ပိုဖတ်လို့လွယ်တယ်။

# 27. အခု မင်း MigLayout ကို ဒီလိုမှတ်

MigLayout ကို **"component တွေကို absolute x,y နဲ့နေရာချတဲ့ library"** လို့ မစဉ်းစားနဲ့။

အစား—

> **"UI ရဲ့ relationship ကိုပြောတဲ့ layout language"**

လို့ စဉ်းစား။

ဥပမာ—

```java
"[][grow]"
```

က

> "ဘယ်ဘက် label ကို သူလိုအပ်သလောက်ထား၊ ညာဘက် component က ကျန်တဲ့ space ယူ"

လို့ ပြောတာ။

ပြီးတော့—

```java
"growx, wrap"
```

က

> "ဒီ component ကို horizontal အနေနဲ့ကြီးစေပြီး နောက် row ဆင်း"

လို့ ပြောတာ။

ဒါကြောင့် MigLayout ကို ကျွမ်းလာတာနဲ့ **UI design ကို code နဲ့ စဉ်းစားနိုင်တဲ့အရည်အချင်း** ပိုကောင်းလာမယ်။

မင်းရဲ့ **Student Registration Swing screen ကို NetBeans Drag & Drop + MigLayout + FlatLaf** သုံးပြီး production-style layout အဖြစ်တစ်ဆင့်ချင်းပြောင်းတဲ့ lesson ကို ဆက်သင်မယ်။
