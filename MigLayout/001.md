# Method 2 — NetBeans Design View လုံးဝမသုံးဘဲ Code ကနေ Form တည်ဆောက်နည်း

## အဆင့် ၁: Project အသစ် (သို့) Class အသစ် ဖန်တီးခြင်း

NetBeans မှာ Form (JFrame Form) အသစ်ဆောက်မယ့်အစား **plain Java Class** ကိုပဲ ဆောက်ပါ:

1. Project ကို right-click → **New → Java Class** (JFrame Form **မဟုတ်ပါ**)
2. နာမည်ပေးပါ ဥပမာ `MainForm`
3. **JFrame Form** ကို မရွေးပါနဲ့ — ရွေးရင် Design view auto ဖွင့်ပြီး guarded block ပါလာမှာပါ

## အဆင့် ၂: Class ကို JFrame extends လုပ်ပါ

```java
package com.example.myapp;

import net.miginfocom.swing.MigLayout;
import javax.swing.*;
import java.awt.event.ActionListener;

public class MainForm extends JFrame {

    // Component တွေကို field အနေနဲ့ ကြေညာ
    private JTextField nameField;
    private JTextField emailField;
    private JPasswordField passwordField;
    private JButton submitButton;
    private JButton cancelButton;

    public MainForm() {
        initUI();
        initEvents();
    }

    private void initUI() {
        setTitle("Registration Form");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        // MigLayout ချမှတ်
        setLayout(new MigLayout(
            "insets 20, wrap 2",       // layout constraints: margin 20, column 2 ခုပြည့်ရင် row အသစ်
            "[right][grow,fill 250]",   // column: ဘယ်ဘက် label align right, ညာဘက် field ချဲ့
            "[]10[]10[]20[]"            // row: gap 10px, 10px, 20px
        ));

        // Name row
        add(new JLabel("Name:"));
        nameField = new JTextField();
        add(nameField);

        // Email row
        add(new JLabel("Email:"));
        emailField = new JTextField();
        add(emailField);

        // Password row
        add(new JLabel("Password:"));
        passwordField = new JPasswordField();
        add(passwordField);

        // Buttons row
        submitButton = new JButton("Submit");
        cancelButton = new JButton("Cancel");
        add(submitButton, "split 2, span 2, align center");
        add(cancelButton);

        pack();                          // component size အလိုက် window size ကို auto ချိန်
        setLocationRelativeTo(null);      // screen အလယ်မှာ ပေါ်
    }

    private void initEvents() {
        submitButton.addActionListener(e -> {
            String name = nameField.getText();
            String email = emailField.getText();
            JOptionPane.showMessageDialog(this,
                "Name: " + name + "\nEmail: " + email);
        });

        cancelButton.addActionListener(e -> dispose());
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            MainForm form = new MainForm();
            form.setVisible(true);
        });
    }
}
```

## အဆင့် ၃: Run လုပ်ကြည့်ပါ

`MainForm.java` ကို right-click → **Run File** (Shift+F6) နှိပ်ပြီး စမ်းကြည့်ပါ။

## Component ခွဲထုတ်ချင်ရင် (Reusable Panel)

Form ကြီးလာရင် panel တွေကို class ခွဲရေးနိုင်ပါတယ်:

```java
public class FormPanel extends JPanel {
    public FormPanel() {
        setLayout(new MigLayout("wrap 2", "[right][grow,fill]"));
        add(new JLabel("Username:"));
        add(new JTextField(15));
        // ...
    }
}
```

ပြီးရင် `MainForm` ထဲမှာ:

```java
add(new FormPanel());
```

## အဓိက မှတ်ထားရမယ့်အချက်

|အချက်|ရှင်းလင်းချက်|
|---|---|
|**JFrame Form မဆောက်ပါနဲ့**|ဆောက်ရင် NetBeans က guarded block အလိုအလျောက် ထည့်တာမို့ manual edit ခက်ပါတယ်|
|**field declaration**|component တွေကို class-level field လုပ်ထားရင် event listener ထဲက access လုပ်ရလွယ်ပါတယ်|
|**pack()**|component sizes အလိုက် window ကို auto-resize လုပ်ပေးတာမို့ manual size သတ်မှတ်စရာမလိုပါ|
|**MigLayout debug**|Layout မှားနေရင် `MigLayout("debug")` လို့ ပထမ parameter ထဲထည့်ကြည့်ပါ — visual grid ပြပေးပါလိမ့်မယ်|

---

Form ဒီဇိုင်း ဘယ်လိုပုံစံ (login, registration, dashboard, စသည်) လုပ်ချင်လဲ ပြောပြရင် ပိုတိကျတဲ့ layout constraint တွေ ချရေးပေးနိုင်ပါတယ်။
