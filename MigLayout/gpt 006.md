# Lesson 6 — MigLayout နဲ့ Login + Dashboard + CRUD Screen Architecture

အခုတော့ MigLayout syntax သင်တာထက် **screen တစ်ခုချင်းစီရဲ့ layout problem ကို ဘယ်လိုစဉ်းစားမလဲ** ကို လေ့လာမယ်။

မင်း Java Swing Project တွေမှာ အများဆုံးတွေ့ရမယ့် screen ၃ မျိုးက—

```text
1. Login Screen
2. Dashboard
3. CRUD Form
```

ဒီ ၃ ခုကို MigLayout တစ်ခုတည်းနဲ့ ဆောက်နိုင်ပေမယ့် **layout thinking မတူဘူး**။

---

# 2. Login Root Layout

```java
        "[grow]",
        "[grow]"

```


# 22. Reusable Panel Design

မင်း project ကြီးလာရင် `JPanel` တစ်ခုချင်းစီကို reusable component လုပ်တာကောင်းတယ်။

ဥပမာ—

```java
public class StudentFormPanel extends JPanel {
}
```

အတွင်း—

```java
public StudentFormPanel() {

    initComponents();
    setupLayout();
}
```

`setupLayout()` မှာ MigLayout သုံး။

ဒါဆို JFrame ထဲမှာ—

```java
StudentFormPanel formPanel =
        new StudentFormPanel();
```

ဆိုရုံနဲ့ ရပြီ။

```java

    new MigLayout(...)
```

အရေးကြီးတာက generated `GroupLayout` code ကို ကိုယ်တိုင်အများကြီးမပြင်ဘဲ **UI shell ကို GUI Builder နဲ့တည်ဆောက်ပြီး layout behavior ကို code ဘက်မှာရှင်းရှင်းလင်းလင်းထားတာ**။

# 26. MigLayout ရဲ့ အကြီးဆုံးအားသာချက်

ဒီလို code—

```java
panel.add(
    txtName,
    "growx, wrap"
);
```

က coordinate မပြောဘူး။

အစား relationship ကိုပြောတယ်—

> "Name field ကို available width ကိုလိုက်ယူစေပြီး row ပြီးတဲ့အခါ နောက် row သွားပါ။"

ဒါကြောင့် window size ပြောင်းလဲမှုကို layout manager က handle လုပ်နိုင်တယ်။

# 29. လက်တွေ့ Challenge

ဒီနေ့ မင်းကို layout problem တစ်ခုပေးမယ်။

Student Dashboard မှာ—

```text
┌─────────────────────────────────────────────────────┐
│ Student Management                     [Admin ▼]   │
├──────────────┬──────────────────────────────────────┤
│ Dashboard    │                                      │
│ Students     │  Students                            │
│ Courses      │                                      │
│ Teachers     │  Search [_____________] [Search]    │
│ Reports      │                                      │
│ Settings     │  ┌────────────────────────────────┐  │
│              │  │         JTable                 │  │
│              │  │                                │  │
│              │  │                                │  │
│              │  └────────────────────────────────┘  │
│              │                          125 Students│
│ Logout       │                                      │
└──────────────┴──────────────────────────────────────┘
```

ကို MigLayout နဲ့ layout ချကြည့်။

အဓိကစဉ်းစားရမယ့်အရာက—

```text
1. Header က column ဘယ်နှစ်ခု span လုပ်မလဲ?
2. Sidebar က fixed width လား?
3. Content က ဘယ်နေရာ grow လုပ်မလဲ?
4. JTable က ဘာကြောင့် grow + push ဖြစ်သင့်လဲ?
5. Logout ကို ဘယ်လို bottom မှာထားမလဲ?
6. Search bar ကို ဘယ် column grow လုပ်စေမလဲ?
```

ဒီ 6 ခုကို code မရေးခင် **paper ပေါ်မှာ layout tree အရင်ဆွဲပါ**။

အဲ့ဒီအလေ့အကျင့်က မင်းအရင်လေ့လာနေတဲ့ architectural thinking နဲ့ တိုက်ရိုက်ချိတ်သွားတယ်။
