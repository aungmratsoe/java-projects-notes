## 1. ui/SidebarPanel.java — icon + text per menu item

```java
package com.example.dashboard.ui;

import net.miginfocom.swing.MigLayout;
import org.kordamp.ikonli.materialdesign2.*;
import org.kordamp.ikonli.swing.FontIcon;

import javax.swing.*;
import java.awt.*;
import java.util.function.Consumer;

public class SidebarPanel extends JPanel {

    private final Consumer<String> onMenuSelected;

    public SidebarPanel(Consumer<String> onMenuSelected) {
        this.onMenuSelected = onMenuSelected;

        setLayout(new MigLayout("insets 20 10 20 10, wrap 1, gap 4", "[grow]"));
        setBackground(new Color(0x0F1E5B));

        addMenuButton("Dashboard", MaterialDesignV.VIEW_DASHBOARD);
        addMenuButton("Students", MaterialDesignA.ACCOUNT);
        addMenuButton("Teachers", MaterialDesignA.ACCOUNT_TIE);
    }

    private void addMenuButton(String name, org.kordamp.ikonli.Ikon icon) {
        JButton button = new JButton(name);
        button.setIcon(FontIcon.of(icon, 20, Color.WHITE));
        button.setIconTextGap(14);
        button.setFocusPainted(false);
        button.setHorizontalAlignment(SwingConstants.LEFT);
        button.setForeground(Color.WHITE);
        button.setBackground(new Color(0x0F1E5B));
        button.setBorder(BorderFactory.createEmptyBorder(10, 16, 10, 16));
        button.setFont(new Font("Segoe UI", Font.PLAIN, 14));

        button.addMouseListener(new java.awt.event.MouseAdapter() {
            public void mouseEntered(java.awt.event.MouseEvent e) {
                button.setBackground(new Color(0x1B2E7A));
            }
            public void mouseExited(java.awt.event.MouseEvent e) {
                button.setBackground(new Color(0x0F1E5B));
            }
        });

        button.addActionListener(e -> onMenuSelected.accept(name));

        add(button, "growx, height 40!");
    }
}
```

Notes:

- `FontIcon.of(icon, size, color)` is the core API — works with any Ikonli pack.
- Ikon names are enums per icon family. Material Design 2 splits icons alphabetically into classes like `MaterialDesignV` (V... icons), `MaterialDesignA` (A... icons), etc. — check the [Ikonli cheat sheet](https://kordamp.org/ikonli/cheat-sheet-materialdesign2.html) to find exact names for icons like Library, Class, Notice, etc.
- Since the button's `setBackground` still needs to change on hover, the icon color stays fixed white — that matches your screenshot where the icon doesn't change color on hover, only the row background does.

## 2. ui/TopBarPanel.java — bell/mail icons with a badge count

Icon-only buttons with a small red circle overlay for the count:

```java
package com.example.dashboard.ui;

import net.miginfocom.swing.MigLayout;
import org.kordamp.ikonli.materialdesign2.MaterialDesignB;
import org.kordamp.ikonli.materialdesign2.MaterialDesignE;
import org.kordamp.ikonli.swing.FontIcon;

import javax.swing.*;
import java.awt.*;

public class TopBarPanel extends JPanel {

    public TopBarPanel() {
        setLayout(new MigLayout("insets 16 20 16 20", "[grow][pref!][pref!][pref!]"));
        setBackground(Color.WHITE);

        JTextField searchField = new JTextField();
        searchField.putClientProperty("JTextField.placeholderText", "Search...");
        add(searchField, "growx, width 300!, height 34!");

        add(iconWithBadge(MaterialDesignE.EMAIL_OUTLINE, 3, new Color(0xF59E0B)), "gapleft 30");
        add(iconWithBadge(MaterialDesignB.BELL_OUTLINE, 5, new Color(0xEF4444)), "gapleft 16");

        JLabel profile = new JLabel("Steve (Admin)");
        profile.setFont(new Font("Segoe UI", Font.BOLD, 14));
        add(profile, "gapleft 16");
    }

    private JPanel iconWithBadge(org.kordamp.ikonli.Ikon icon, int count, Color badgeColor) {
        JPanel wrapper = new JPanel(null); // absolute positioning for the badge overlay
        wrapper.setOpaque(false);
        wrapper.setPreferredSize(new Dimension(30, 30));

        JLabel iconLabel = new JLabel(FontIcon.of(icon, 22, new Color(0x4B5563)));
        iconLabel.setBounds(0, 2, 26, 26);
        wrapper.add(iconLabel);

        JLabel badge = new JLabel(String.valueOf(count), SwingConstants.CENTER) {
            @Override
            protected void paintComponent(Graphics g) {
                Graphics2D g2 = (Graphics2D) g.create();
                g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);
                g2.setColor(badgeColor);
                g2.fillOval(0, 0, getWidth(), getHeight());
                g2.dispose();
                super.paintComponent(g);
            }
        };
        badge.setForeground(Color.WHITE);
        badge.setFont(new Font("Segoe UI", Font.BOLD, 9));
        badge.setBounds(16, 0, 16, 16);
        wrapper.add(badge);

        return wrapper;
    }
}
```

## 3. ui/StatCardPanel.java — icon inside the colored circle badge

Replace the plain filled oval with an oval **plus** a centered icon, matching the screenshot exactly:

```java
package com.example.dashboard.ui;

import net.miginfocom.swing.MigLayout;
import org.kordamp.ikonli.Ikon;
import org.kordamp.ikonli.swing.FontIcon;

import javax.swing.*;
import java.awt.*;

public class StatCardPanel extends JPanel {

    public StatCardPanel(String title, String number, Color badgeColor, Ikon icon) {
        setLayout(new MigLayout("insets 18, gap 14", "[pref!][grow]"));
        setBackground(Color.WHITE);
        setBorder(BorderFactory.createLineBorder(new Color(0xE5E7EB), 1, true));

        JPanel badge = new JPanel(new GridBagLayout()) {
            @Override
            protected void paintComponent(Graphics g) {
                Graphics2D g2 = (Graphics2D) g.create();
                g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);
                g2.setColor(badgeColor);
                g2.fillOval(0, 0, getWidth(), getHeight());
                g2.dispose();
            }
        };
        badge.setOpaque(false);
        badge.add(new JLabel(FontIcon.of(icon, 22, Color.WHITE)));
        add(badge, "width 48!, height 48!");

        JPanel textPanel = new JPanel(new MigLayout("insets 0, wrap 1, gap 2"));
        textPanel.setOpaque(false);

        JLabel titleLabel = new JLabel(title);
        titleLabel.setFont(new Font("Segoe UI", Font.PLAIN, 14));
        titleLabel.setForeground(Color.GRAY);

        JLabel numberLabel = new JLabel(number);
        numberLabel.setFont(new Font("Segoe UI", Font.BOLD, 26));

        textPanel.add(titleLabel);
        textPanel.add(numberLabel);
        add(textPanel);
    }
}
```

## Finding icon names

Ikonli's Material Design 2 pack has ~7,000 icons split across ~26 classes (`MaterialDesignA` through `MaterialDesignZ`, by first letter). Rather than guessing names, check the searchable list here:Use this cheat sheet to browse and search icon names for `ikonli-materialdesign2-pack`:

**https://kordamp.org/ikonli/cheat-sheet-materialdesign2.html**

It lists every enum name (`MaterialDesignV.VIEW_DASHBOARD`, `MaterialDesignA.ACCOUNT_TIE`, etc.) grouped by first letter — just Ctrl+F for what you need (e.g. "library" for the Library menu item, "book" for Class, "calendar" for Routine, "bus" for Transport).

Some icon mappings for your remaining sidebar items, so you don't have to hunt for all of them:

|Menu item|Class|Enum|
|---|---|---|
|Library|`MaterialDesignL`|`LIBRARY`|
|Account|`MaterialDesignA`|`ACCOUNT_COG`|
|Class|`MaterialDesignG`|`GOOGLE_CLASSROOM` (or `MaterialDesignB.BOOK_OPEN_VARIANT`)|
|Subject|`MaterialDesignB`|`BOOK_OPEN_PAGE_VARIANT`|
|Routine|`MaterialDesignC`|`CALENDAR_CLOCK`|
|Attendance|`MaterialDesignC`|`CLIPBOARD_CHECK_OUTLINE`|
|Exam|`MaterialDesignP`|`PENCIL_BOX_OUTLINE`|
|Notice|`MaterialDesignB`|`BULLHORN_OUTLINE`|
|Transport|`MaterialDesignB`|`BUS`|
|Dormitory|`MaterialDesignH`|`HOME_CITY_OUTLINE`|

One thing worth flagging: icon names occasionally get renamed or dropped between Ikonli versions, so if a specific enum constant doesn't compile, that's the fastest way to find its current name rather than guessing variants.
