## What I looked at and rejected: SwingX for shadows

I checked whether `swingx-core` (which has a built-in `ShadowRenderer` class for exactly this drop-shadow effect) would be worth adding. It would give a nicer shadow with less code — but the project's last real release was around 2013, it's unmaintained, and pulling in an abandoned library just for one visual effect is a real risk for something you'll keep building on (dependency conflicts, no fixes if something breaks on a newer JDK). Not worth it here.

Instead, here's a small custom-painted shadow for `DashboardCard` — no extra dependency, and it matches the screenshot's soft-shadow-under-white-card look:

```java
package com.example.dashboard.ui;

import net.miginfocom.swing.MigLayout;

import javax.swing.*;
import java.awt.*;

public class DashboardCard extends JPanel {

    private final JPanel bodyPanel = new JPanel(new BorderLayout());
    private static final int SHADOW_SIZE = 6;
    private static final int ARC = 14;

    public DashboardCard(String title) {
        setOpaque(false);
        setLayout(new MigLayout(
                "insets " + (16 + SHADOW_SIZE) + " 18 " + (16 + SHADOW_SIZE) + " 18, wrap 1, fill",
                "[grow]", "[pref!][grow]"));

        JLabel titleLabel = new JLabel(title);
        titleLabel.setFont(new Font("Segoe UI", Font.BOLD, 16));
        add(titleLabel, "growx");

        bodyPanel.setOpaque(false);
        add(bodyPanel, "grow, gaptop 10");
    }

    public void setBody(JComponent content) {
        bodyPanel.removeAll();
        bodyPanel.add(content, BorderLayout.CENTER);
        bodyPanel.revalidate();
        bodyPanel.repaint();
    }

    @Override
    protected void paintComponent(Graphics g) {
        Graphics2D g2 = (Graphics2D) g.create();
        g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);

        int w = getWidth(), h = getHeight();

        // Layered soft shadow: several shrinking, increasingly transparent rounded rects
        for (int i = SHADOW_SIZE; i > 0; i--) {
            int alpha = 12 - (i * 12 / SHADOW_SIZE); // fades out toward the edge
            g2.setColor(new Color(0, 0, 0, Math.max(alpha, 2)));
            g2.fillRoundRect(i, i + 2, w - i * 2, h - i * 2, ARC, ARC);
        }

        // The white card itself, on top of the shadow
        g2.setColor(Color.WHITE);
        g2.fillRoundRect(0, 0, w - SHADOW_SIZE, h - SHADOW_SIZE, ARC, ARC);

        g2.setColor(new Color(0xE5E7EB));
        g2.drawRoundRect(0, 0, w - SHADOW_SIZE - 1, h - SHADOW_SIZE - 1, ARC, ARC);

        g2.dispose();
        super.paintComponent(g);
    }
}
```

The trick: instead of one flat shadow rectangle, it draws several rounded rects of decreasing size and increasing transparency stacked on top of each other — that's what fakes a Gaussian blur without a graphics library. `StatCardPanel` can use the exact same `paintComponent` override if you want the shadow on stat cards too.

Everything else (Ikonli icons, MigLayout structure, JFreeChart donut/bar) stays exactly as built in the previous steps — those choices were already solid, so no changes needed there.
