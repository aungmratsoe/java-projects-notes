ဒီ dashboard ကို Java Swing + Maven နဲ့ ပြန်လုပ်ချင်ရင် အောက်ပါအတိုင်း ခွဲပြပေးပါမယ် — dependencies တွေ၊ layout strategy၊ ပြီးတော့ screenshot ထဲက component တစ်ခုချင်းစီကို Swing ဘယ်လို map လုပ်မလဲဆိုတာ။

## 1. Maven Dependencies

```xml
<dependencies>
    <!-- Modern flat look and feel -->
    <dependency>
        <groupId>com.formdev</groupId>
        <artifactId>flatlaf</artifactId>
        <version>3.7.2</version>
    </dependency>
    <dependency>
        <groupId>com.formdev</groupId>
        <artifactId>flatlaf-extras</artifactId>
        <version>3.7.2</version>
    </dependency>

    <!-- Flexible layout manager (dashboard အတွက် အရေးကြီးဆုံး) -->
    <dependency>
        <groupId>com.miglayout</groupId>
        <artifactId>miglayout-swing</artifactId>
        <version>11.4.2</version>
    </dependency>

    <!-- Icon font (Material/FontAwesome) -->
    <dependency>
        <groupId>org.kordamp.ikonli</groupId>
        <artifactId>ikonli-swing</artifactId>
        <version>12.4.0</version>
    </dependency>
    <dependency>
        <groupId>org.kordamp.ikonli</groupId>
        <artifactId>ikonli-materialdesign2-pack</artifactId>
        <version>12.4.0</version>
    </dependency>

    <!-- Chart: donut, bar chart -->
    <dependency>
        <groupId>org.jfree</groupId>
        <artifactId>jfreechart</artifactId>
        <version>1.5.6</version>
    </dependency>

    <!-- Optional: calendar widget ကို လက်နဲ့မဆွဲချင်ရင် -->
    <dependency>
        <groupId>com.github.lgooddatepicker</groupId>
        <artifactId>LGoodDatePicker</artifactId>
        <version>11.2.1</version>
    </dependency>
</dependencies>
```

တစ်ခုချင်းစီရဲ့ အကြောင်းအရာ —

- **FlatLaf** — flat white/blue theme, rounded corner, border တွေကို free ရနေပြီးသားပါ။
- **MigLayout** — ဒါက အရေးအကြီးဆုံးပါ။ ဒီ UI ကို BorderLayout/GridBagLayout နဲ့ပဲ တည်ဆောက်ဖို့ ခက်ခဲပါလိမ့်မယ်။ card တစ်ခုချင်းစီ၊ sidebar၊ top bar အားလုံးကို MigLayout ရဲ့ `"wrap"`, `"grow"`, `"span"` syntax နဲ့ ပိုလွယ်ပါတယ်။
- **Ikonli** — icon PNG ရှာစရာမလိုဘဲ scalable vector icon (dashboard, students icon) တွေ ရနိုင်ပါတယ်။
- **JFreeChart** — donut (ring) chart နဲ့ grouped bar chart နှစ်ခုလုံးကို တိုက်ရိုက် ကိုင်တွယ်ပေးပါတယ်။ `Graphics2D` နဲ့ လက်ဆွဲမဆွဲပါနဲ့၊ ပိုပင်ပန်းမှာပါ။
- **LGoodDatePicker** — optional ပါ၊ "Event Calendar" grid ကို လက်နဲ့မဆောက်ချင်ရင်သာ သုံးပါ။

## 2. Overall Structure

Window တစ်ခုလုံးကို **JFrame တစ်ခု** ပေါ်မှာ MigLayout root layout ချပြီး region ၂ ခုခွဲပါ —

```
JFrame
 ├── Sidebar (JPanel, fixed width, dark navy background)
 └── Content area (JPanel, MigLayout)
      ├── Top bar (search + notifications + profile)
      ├── Row 1: stat card 3 ခု (Students / Teachers / Parents)
      ├── Row 2: Students donut card | Notice Board card
      └── Row 3: Event Calendar card | Expense bar chart card
```

Root layout ဥပမာ —

```java
setLayout(new MigLayout("insets 0, fill", "[240!][grow]", "[grow]"));
add(sidebar, "grow");
add(contentPanel, "grow");
```

## 3. Sidebar (ဘယ်ဘက် navy panel)

- `JPanel` တစ်ခု `setBackground(new Color(0x0F1E5B))` လို navy color ချပါ။
- Nav item ("Dashboard", "Students" စသည်) တစ်ခုချင်းစီကို custom `JButton` သို့မဟုတ် `JPanel` အနေနဲ့ လုပ်ပါ —
    - ဘယ်ဘက်မှာ Ikonli icon
    - text label
    - border မရှိ၊ background transparent၊ `MouseListener` နဲ့ hover effect (mouse ဝင်/ထွက်တာနဲ့ background ပြောင်း)
    - ရွေးထားတဲ့ item အတွက် ပိုပြီး light/rounded highlight background
- Dropdown arrow ပါတဲ့ item တွေ (Dashboard, Students, Teachers...) ကတော့ `JLabel`/icon တစ်ခုကို click လုပ်တာနဲ့ အောက်က sub-`JPanel` ကို visible/invisible toggle လုပ်ရုံပါပဲ — real tree component မလိုပါဘူး။

Tip: Menu item တစ်ခုချင်းစီအတွက် code ထပ်ရေးမနေဘဲ **reusable `SidebarItem` class** တစ်ခု (extends `JPanel`, implements `MouseListener`) တည်ဆောက်ပါ။

## 4. Top Bar

- MigLayout row: `"[grow][pref!][pref!][pref!]"` — search box ကို grow ပေးပြီး notification bell, mail icon, avatar+name ကို ညာဘက်စွန်းတွင်ချပါ။
- Search box: `JTextField` ကို FlatLaf client property နဲ့ style လုပ်ပါ —
    
    ```java
    searchField.putClientProperty("JTextField.placeholderText", "Search...");searchField.putClientProperty("JTextField.showClearButton", true);
    ```
    
- Notification/mail icon ပေါ်က ကြက်ဥနီ badge count — `JLayeredPane` သုံးနိုင်တယ်၊ ဒါမှမဟုတ် icon button ရဲ့ ညာအပေါ်ထောင့်ပေါ်မှာ number ပါတဲ့ oval red label တစ်ခု custom-paint လုပ်ပြီး overlay တင်ပါ။
- Avatar: circular photo — `Graphics2D` + `Ellipse2D` နဲ့ `BufferedImage` ကို clip လုပ်ပါ။

## 5. Stat Cards (Students/Teachers/Parents row)

တစ်ခုချင်းစီက "card" style `JPanel` —

```java
card.putClientProperty("FlatLaf.style", "arc: 12; background: #FFFFFF");
card.setBorder(new MatteBorder(1,1,1,1, new Color(0xE5E7EB)));
```

အထဲမှာ — MigLayout နဲ့ color icon badge (custom `JPanel` က circle filled ဆွဲထားတာ) + stacked `JLabel` ၂ ခု (title, ကြီးမားတဲ့ bold number)။

ဒီ "rounded white card + soft border" pattern ကတော့ screenshot ထဲက box **တိုင်း**မှာ ထပ်ခါထပ်ခါ ပါနေပါတယ် (stat card, chart panel, notice board, calendar) — ဒါကြောင့် `DashboardCard` component တစ်ခု (extends `JPanel`, title + content panel + optional "..." menu icon လက်ခံတယ်) တည်ဆောက်ပြီး နေရာတိုင်းမှာ ပြန်သုံးပါ။ ဒါက အချိန်အများဆုံး ချွေတာနိုင်တဲ့ ချက်ပါ။

## 6. Students Donut Chart

JFreeChart ရဲ့ `RingPlot` သုံးပါ —

```java
DefaultPieDataset<String> dataset = new DefaultPieDataset<>();
dataset.setValue("Female Students", 45000);
dataset.setValue("Male Students", 55000);

RingPlot plot = new RingPlot(dataset);
plot.setSectionPaint("Female Students", new Color(0x14B8C4));
plot.setSectionPaint("Male Students", new Color(0x0891A0));
plot.setSectionDepth(0.35); // ring အထူကို ချုပ်ကိုင်တယ်
plot.setLabelGenerator(null); // default label ဖျောက်၊ legend ကိုယ်တိုင်ဆွဲမယ်

JFreeChart chart = new JFreeChart(plot);
chart.removeLegend();
ChartPanel chartPanel = new ChartPanel(chart);
```

Chart အောက်မှာ screenshot ထဲကအတိုင်း legend row (color line + "Female Students / 45,000") ကို `JLabel` သီးသန့်ချရေးပါ — ဒါက JFreeChart ရဲ့ built-in legend မဟုတ်ဘူး၊ custom ပါ။

## 7. Notice Board (list items)

ဒါက MigLayout `"wrap"` ပါတဲ့ `JPanel` တစ်ခုမှာ **notice item component** ထပ်ခါထပ်ခါထည့်ရုံပါပဲ — colored pill `JLabel` (date badge — rounded rect, custom paint သို့ FlatLaf `arc` style)၊ bold title `JLabel`၊ small gray subtitle `JLabel`၊ ကြားထဲမှာ `JSeparator` slim တစ်ခု။ List ကြီးလာနိုင်ရင် `JScrollPane` နဲ့ ပတ်ထားပါ။

## 8. Event Calendar

Option နှစ်ခု —

1. **အလွယ်ဆုံး**: `LGoodDatePicker` ရဲ့ `CalendarPanel` ကို သုံးပြီး color ပြန် style လုပ်ပါ။
2. **Full control** (screenshot နဲ့ တိတိကျကျ တူအောင်၊ Day/Week/Month toggle button တွေအပါအဝင်) — ကိုယ်တိုင်ဆောက်ပါ — `JPanel` တစ်ခု `GridLayout(7, 7)` နဲ့ ရက်တစ်ခုချင်းစီအတွက် (`JLabel`/button သေးသေး၊ ရွေးထားတဲ့ ရက်က navy circle background custom-paint)၊ Day/Week/Month အတွက် `ButtonGroup` သုံးထားတဲ့ segmented `JToggleButton` row တစ်ခု ထည့်ပါ။

## 9. Expense Bar Chart

JFreeChart `CategoryDataset` + `JFreeChart.createBarChart(...)`, သို့မဟုတ် `ChartFactory.createBarChart` နဲ့ `BarRenderer` သုံးပြီး series (2020/2021/2022) တစ်ခုချင်းစီကို screenshot ထဲက teal/blue/orange color နဲ့ ကိုက်အောင် custom color ချပါ —

```java
CategoryPlot plot = chart.getCategoryPlot();
plot.setBackgroundPaint(Color.WHITE);
plot.setRangeGridlinePaint(new Color(0xF0F0F0));
BarRenderer renderer = (BarRenderer) plot.getRenderer();
renderer.setSeriesPaint(0, new Color(0x2DD4BF));
renderer.setSeriesPaint(1, new Color(0x3B82F6));
renderer.setSeriesPaint(2, new Color(0xF59E0B));
renderer.setMaximumBarWidth(0.12);
```
